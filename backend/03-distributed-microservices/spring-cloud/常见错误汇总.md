# Spring Cloud - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南章节提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 过度拆分微服务导致运维复杂度激增、跨服务调用延迟增加 | 服务粒度太细，服务数量失控 | 团队规模5-8人维护一个服务，服务数量控制在10-20个以内 | [Spring Cloud Alibaba深度](./01-Spring-Cloud-Alibaba深度-导览.md) |
| 配置中心明文存储数据库密码、API Key等敏感信息导致泄露 | 敏感信息未加密存储 | 使用Jasypt加密：`password: ENC(加密后的密文)` | [Spring Cloud Alibaba深度](./01-Spring-Cloud-Alibaba深度-导览.md) |
| Nacos集群少于3个节点导致单点故障、集群不可用 | 不满足Raft半数以上存活要求 | 生产环境至少3个节点，使用外部MySQL做持久化 | [Spring Cloud Alibaba深度](./01-Spring-Cloud-Alibaba深度-导览.md) |
| Sentinel规则重启后丢失 | Sentinel默认规则存储在内存中 | 配置规则持久化到Nacos配置中心 | [Spring Cloud Alibaba深度](./01-Spring-Cloud-Alibaba深度-导览.md) |
| Gateway做复杂业务逻辑导致网关性能下降成为瓶颈 | 网关应专注于横切关注点 | 复杂业务逻辑放在后端服务中，网关仅做路由、鉴权、限流 | [Gateway网关与负载均衡](./03-Gateway网关与负载均衡-导览.md) |
| 生产环境使用嵌入式Derby导致无法支持集群、数据丢失风险 | 嵌入式Derby只能用于单机开发测试 | 生产环境必须使用外部MySQL | [Nacos服务注册与配置中心](./02-Nacos服务注册与配置中心-导览.md) |
| namespace配置不生效 | namespace配置项填写的是命名空间的UUID，不是名称 | 从Nacos控制台复制命名空间的UUID | [Nacos服务注册与配置中心](./02-Nacos服务注册与配置中心-导览.md) |
| @Value配置修改后不生效 | @Value不会自动刷新 | 添加@RefreshScope注解；或使用@ConfigurationProperties（天然支持动态刷新） | [Nacos服务注册与配置中心](./02-Nacos服务注册与配置中心-导览.md) |
| 配置中心存放超大文件导致配置加载慢、网络传输大 | 单个配置过大 | 单个配置内容建议不超过100KB | [Nacos服务注册与配置中心](./02-Nacos服务注册与配置中心-导览.md) |
| Filter执行顺序错误导致鉴权在路由之后执行 | 未通过getOrder()控制优先级 | 鉴权Filter设置高优先级（值越小越先执行） | [Gateway网关与负载均衡](./03-Gateway网关与负载均衡-导览.md) |
| 引入spring-boot-starter-web导致应用启动失败 | Gateway依赖WebFlux，与spring-boot-starter-web冲突 | 使用spring-boot-starter-webflux，不引入web依赖 | [Gateway网关与负载均衡](./03-Gateway网关与负载均衡-导览.md) |
| 限流不生效 | RequestRateLimiter依赖Redis | 配置Redis连接信息 | [Gateway网关与负载均衡](./03-Gateway网关与负载均衡-导览.md) |
| 生产环境未配置熔断降级导致后端服务故障拖垮网关 | 网关未集成熔断降级机制 | 集成Sentinel或Resilience4j防止故障扩散 | [Gateway网关与负载均衡](./03-Gateway网关与负载均衡-导览.md) |
| AT模式分布式事务失败 | 每个参与分布式事务的数据库都需要undo_log表 | 在每个业务数据库创建undo_log表 | [分布式事务与Seata](./04-分布式事务与Seata-导览.md) |
| Seata Server嵌入业务应用导致部署耦合 | Seata Server需要独立部署 | Seata Server必须独立部署，不能嵌入业务应用 | [分布式事务与Seata](./04-分布式事务与Seata-导览.md) |
| 非关系型数据库使用AT模式导致事务回滚失败 | AT模式依赖数据库事务（ACID） | 非关系型数据库使用TCC或Saga模式 | [分布式事务与Seata](./04-分布式事务与Seata-导览.md) |
| 并发性能下降 | 全局事务时间过长，长时间持有锁影响其他事务 | 避免长事务，缩短全局事务持有锁的时间 | [分布式事务与Seata](./04-分布式事务与Seata-导览.md) |
| Seata Server单点故障导致全局事务无法协调 | 单节点故障无备选 | 生产环境配置Seata Server集群 | [分布式事务与Seata](./04-分布式事务与Seata-导览.md) |
| 配置了logger-level但看不到日志 | 未将接口包logging.level设为DEBUG | 同时配置feign logger-level和logging.level.package=debug | [OpenFeign声明式调用](./06-OpenFeign声明式调用-导览.md) |
| 服务异常时未触发降级 | 降级类未注册为Spring Bean，或未引入熔断器依赖 | 降级类加@Component；Spring Cloud 2020.0+需引入spring-cloud-starter-circuitbreaker-sentinel | [OpenFeign声明式调用](./06-OpenFeign声明式调用-导览.md) |
| GET请求传对象参数报错、参数丢失或返回400错误 | Feign对GET请求的对象参数默认不展开为query参数 | 使用@RequestParam逐个标注参数，或配置queryMapEncoder | [OpenFeign声明式调用](./06-OpenFeign声明式调用-导览.md) |
| 同一服务多个FeignClient启动报BeanDefinitionStoreException | 多个接口name相同，Bean名称冲突 | 为不同接口设置不同contextId | [OpenFeign声明式调用](./06-OpenFeign声明式调用-导览.md) |
| 调用偶发超时但未触发降级 | read-timeout设置过大，请求长时间阻塞线程 | 区分connect-timeout（建立连接）和read-timeout（读取数据），按业务场景分别设置 | [OpenFeign声明式调用](./06-OpenFeign声明式调用-导览.md) |
| 偶发网络抖动导致调用失败 | Spring Cloud默认NEVER_RETRY | 评估后手动配置Retryer Bean，注意只对幂等接口启用重试 | [OpenFeign声明式调用](./06-OpenFeign声明式调用-导览.md) |
| 生产环境使用FULL日志导致性能下降、敏感信息泄露 | FULL级别输出请求/响应完整内容 | 生产环境使用BASIC级别，调试时临时开启FULL | [OpenFeign声明式调用](./06-OpenFeign声明式调用-导览.md) |
| 后端存储暴增、应用性能下降 | 生产环境采样率设置过高 | 生产环境采样率设为0.1-0.5，仅排障期临时调高 | [链路追踪与可观测性](./07-链路追踪与可观测性-导览.md) |
| SkyWalking UI无数据 | -javaagent参数位置错误或路径不对 | -javaagent必须在-jar之前，确认jar路径正确，查看agent.log确认启动 | [链路追踪与可观测性](./07-链路追踪与可观测性-导览.md) |
| 日志中traceId为空 | 未在logback pattern中配置%X{traceId} | 在logback-spring.xml的pattern中添加[%X{traceId},%X{spanId}] | [链路追踪与可观测性](./07-链路追踪与可观测性-导览.md) |
| 异步线程中traceId消失 | Sleuth默认只对@Async和线程池自动传播 | 使用Sleuth的TraceableExecutorService包装线程池，或手动传播SpanContext | [链路追踪与可观测性](./07-链路追踪与可观测性-导览.md) |
| Zipkin中链路不连续 | Feign未集成Sleuth或上下文Header未透传 | 确认引入spring-cloud-starter-sleuth，Sleuth自动通过RequestInterceptor传播上下文 | [链路追踪与可观测性](./07-链路追踪与可观测性-导览.md) |
| 外部HTTP调用不在链路中 | RestTemplate未被Sleuth包装 | Sleuth自动包装RestTemplate和WebClient，确保正确创建Bean并注入使用 | [链路追踪与可观测性](./07-链路追踪与可观测性-导览.md) |
