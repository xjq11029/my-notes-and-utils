# Linux - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南章节提取。

---

## 一、核心命令与 Shell 脚本

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| `rm -rf /tmp/$APP` 变量为空时误删根目录 | 变量未初始化或为空，`rm -rf /tmp/$APP` 变成 `rm -rf /tmp/ /` | `rm -rf /tmp/"$APP"/*` 或先判断 `if [ -z "$APP" ]; then exit 1; fi` | [01-导览](./01-Linux核心命令与Shell脚本-导览.md) |
| 变量不加引号导致空格分词错误 | `FILE="my file.txt"; cat $FILE` 被拆成 `cat "my" "file.txt"` | 变量始终加双引号：`cat "$FILE"` | [01-导览](./01-Linux核心命令与Shell脚本-导览.md) |
| `rm -rf *.log` 无匹配文件时当作字面量删除 | Bash 默认不展开 null glob，`*` 不展开 | `shopt -s nullglob` 或 `find . -name "*.log" -delete` | [01-导览](./01-Linux核心命令与Shell脚本-导览.md) |
| `tar` 命令 f 参数不在最后导致解压失败 | f 必须放在最后，其后紧跟文件名 | `tar -czf archive.tar.gz project`（f 在最后） | [01-导览](./01-Linux核心命令与Shell脚本-导览.md) |
| `sed -i` 在 Mac 上报错 | Mac BSD sed 需要备份后缀参数 | Linux：`sed -i 's/.../.../g'`；Mac：`sed -i '' 's/.../.../g'` | [01-导览](./01-Linux核心命令与Shell脚本-导览.md) |
| 判断字符串相等漏了空格导致 `[` 命令报错 | `[` 是命令，前后需要空格 | `[ "$1" = "yes" ]` | [01-导览](./01-Linux核心命令与Shell脚本-导览.md) |
| `for` 循环遍历含空格文件名出错 | find 输出按换行分割，for 按空白分割 | `find ... -print0 \| xargs -0 ...` 或 `while IFS= read -r f` | [01-导览](./01-Linux核心命令与Shell脚本-导览.md) |
| 后台进程输出导致脚本挂起 | 后台进程持有终端，SSH 断开后脚本收到 SIGHUP 退出 | `nohup command >> output.log 2>&1 &` | [01-导览](./01-Linux核心命令与Shell脚本-导览.md) |
| 在根目录执行 `chmod 777 -R .` 导致严重安全问题 | 所有人可读写所有文件，敏感文件可被任意修改 | 合理设置权限：文件 644，目录 755，可执行文件 755 | [01-导览](./01-Linux核心命令与Shell脚本-导览.md) |
| `find -exec rm {} \;` 逐个删除效率低 | 每找到一个文件 fork 一次 `rm` | `find ... -delete`（find 自带）或 `find ... -exec rm {} +` 批量删除 | [01-导览](./01-Linux核心命令与Shell脚本-导览.md) |

## 二、系统管理与服务部署

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 以 root 用户运行 Java 应用 | 安全风险，一旦被攻击可获取 root 权限 | 创建专用应用用户（`useradd -m appuser`），以 appuser 身份运行 | [02-导览](./02-Linux系统管理与服务部署-导览.md) |
| 使用 kill -9 直接杀进程导致数据丢失 | 未给进程优雅关闭的机会，连接泄漏、注册中心未下线 | 先发 `kill -15`，等待 10-30 秒，仍不退出再发 `kill -9` | [02-导览](./02-Linux系统管理与服务部署-导览.md) |
| 防火墙未开放端口导致外部无法访问 | 忘记配置防火墙规则 | 部署后检查：`firewall-cmd --add-port=8080/tcp --permanent` 并 `--reload` | [02-导览](./02-Linux系统管理与服务部署-导览.md) |
| 数据库端口对外暴露被暴力破解 | 防火墙配置过于宽松 | MySQL/Redis 只监听内网 IP，或使用防火墙富规则限制来源 IP | [02-导览](./02-Linux系统管理与服务部署-导览.md) |
| 未配置日志轮转导致磁盘被占满 | 日志文件无限增长 | 配置 `logrotate` 或使用 `journalctl` 的日志大小限制 | [02-导览](./02-Linux系统管理与服务部署-导览.md) |
| 未设置 JVM 内存限制导致 OOM Killer 杀死进程 | 默认堆内存可能过大 | 设置 `-Xms` 和 `-Xmx`，如 `-Xms512m -Xmx1024m` | [02-导览](./02-Linux系统管理与服务部署-导览.md) |
| 使用弱密码或无密码导致数据库/Redis 被入侵 | 忽视安全配置 | MySQL 使用强密码，Redis 设置 `requirepass` | [02-导览](./02-Linux系统管理与服务部署-导览.md) |
| nohup 输出未重定向导致 nohup.out 不断增长 | 忽略输出重定向 | `nohup ... > /dev/null 2>&1 &` 或重定向到日志文件 | [02-导览](./02-Linux系统管理与服务部署-导览.md) |
| 未设置服务开机自启导致重启后应用未启动 | 忘记 `systemctl enable` | 部署后执行 `systemctl enable app` | [02-导览](./02-Linux系统管理与服务部署-导览.md) |
| 错误修改系统关键文件权限导致系统异常 | 误操作 `chmod -R 777 /` | 永远不对 `/usr`、`/etc`、`/bin` 等系统目录递归修改权限，使用 `chmod` 前先确认目标路径 | [02-导览](./02-Linux系统管理与服务部署-导览.md) |
