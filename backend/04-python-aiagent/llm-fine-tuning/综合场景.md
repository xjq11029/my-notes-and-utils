## 场景一：用LoRA微调大模型

### 场景描述
某团队需要在单张A100（80GB）上对LLaMA-3-8B模型进行领域适配微调，使其精通医疗问答场景。训练数据约5000条高质量医生-患者对话。需求是：微调后模型在医疗领域回答准确率显著提升，同时保持通用对话能力不退化，推理延迟不增加。

### 涉及知识点
- [Transformer架构导览](./01-大模型基础与Transformer架构-导览.md)：模型架构理解、分词器选择
- [微调技术与LoRA原理导览](./02-微调技术与LoRA原理-导览.md)：LoRA配置、训练参数、灾难性遗忘应对

### 协作流程
1. 数据准备：将5000条对话格式化为instruction-input-output三元组，8:1:1划分训练/验证/测试集。
2. 模型加载：用transformers加载LLaMA-3-8B基座模型，使用bf16精度加载。
3. LoRA配置：target_modules设为q_proj、k_proj、v_proj、o_proj四个注意力投影层，rank=16，alpha=32，dropout=0.05。
4. 训练设置：学习率2e-4（LoRA可用更高学习率），cosine调度，batch_size=4配合梯度累积达到有效batch=32，训练3个epoch。
5. 验证监控：每个epoch后在验证集上计算困惑度（PPL）和医疗领域准确率，同时监控通用benchmark（MMLU）防止遗忘。
6. 推理部署：训练完成后执行`model.merge_and_unload()`将LoRA权重合并到基座，导出为标准模型格式。

### 关键要点
- LoRA的target_modules选择影响效果：仅attention层性价比最高，加上FFN层效果更好但参数翻倍
- 学习率2e-4是LoRA的常见起点，全量微调通常用1e-5，相差约20倍
- 合并LoRA权重后推理延迟与原始模型完全相同，零额外开销
- 若显存不足可改用QLoRA（4-bit量化基座），精度损失通常可接受

```python
# prepare_data.py - 数据准备与格式化
import json
from typing import Dict, List
from datasets import Dataset, DatasetDict
from sklearn.model_selection import train_test_split


def load_medical_qa(data_path: str) -> List[Dict]:
    """加载医疗问答数据，格式为 instruction-input-output 三元组"""
    with open(data_path, 'r', encoding='utf-8') as f:
        data = json.load(f)

    # 数据格式示例:
    # [
    #   {
    #     "instruction": "你是一位经验丰富的医生，请根据患者症状给出诊断建议。",
    #     "input": "患者男性，35岁，持续咳嗽3周，伴有低热和胸闷。",
    #     "output": "根据您描述的症状，建议进行以下检查：1.胸部CT..."
    #   }
    # ]
    print(f"[INFO] 加载数据: {len(data)} 条")
    return data


def format_alpaca_prompt(sample: Dict) -> Dict:
    """将数据格式化为 Alpaca 指令格式，这是微调常用格式"""
    instruction = sample.get('instruction', '')
    input_text = sample.get('input', '')
    output_text = sample.get('output', '')

    if input_text:
        prompt = f"""Below is an instruction that describes a task, paired with an input that provides further context. Write a response that appropriately completes the request.

### Instruction:
{instruction}

### Input:
{input_text}

### Response:
{output_text}"""
    else:
        prompt = f"""Below is an instruction that describes a task. Write a response that appropriately completes the request.

### Instruction:
{instruction}

### Response:
{output_text}"""

    return {"text": prompt}


def split_dataset(data: List[Dict], train_ratio=0.8, val_ratio=0.1, seed=42):
    """8:1:1 划分训练/验证/测试集"""
    train_data, temp = train_test_split(data, train_size=train_ratio, random_state=seed)
    val_ratio_adjusted = val_ratio / (1 - train_ratio)
    val_data, test_data = train_test_split(temp, train_size=val_ratio_adjusted, random_state=seed)

    print(f"[INFO] 数据划分: 训练集={len(train_data)}, 验证集={len(val_data)}, 测试集={len(test_data)}")

    dataset = DatasetDict({
        "train": Dataset.from_list(train_data),
        "validation": Dataset.from_list(val_data),
        "test": Dataset.from_list(test_data),
    })
    return dataset


if __name__ == "__main__":
    data = load_medical_qa("./data/medical_qa.json")
    dataset = split_dataset(data)
    dataset = dataset.map(format_alpaca_prompt)
    dataset.save_to_disk("./data/medical_qa_processed")
    print("[INFO] 数据准备完成，已保存到 ./data/medical_qa_processed")
```

#### 第三步：模型加载与分词

```python
# train.py 第1部分 - 模型加载与分词
import torch
from transformers import (
    AutoTokenizer,
    AutoModelForCausalLM,
    BitsAndBytesConfig,
    TrainingArguments,
    Trainer,
    DataCollatorForSeq2Seq,
)
from peft import (
    LoraConfig,
    get_peft_model,
    TaskType,
    prepare_model_for_kbit_training,
)
from datasets import load_from_disk

# ========== 配置参数 ==========
MODEL_NAME = "meta-llama/Meta-Llama-3-8B"    # 基座模型
# 可替换为: "Qwen/Qwen2-7B" (中文场景)
DATA_PATH = "./data/medical_qa_processed"
OUTPUT_DIR = "./lora-medical-output"
MAX_SEQ_LENGTH = 2048

# LoRA 配置
LORA_R = 16              # 低秩矩阵的秩
LORA_ALPHA = 32          # 缩放因子
LORA_DROPOUT = 0.05      # Dropout 防止过拟合
TARGET_MODULES = ["q_proj", "k_proj", "v_proj", "o_proj"]  # 注意力投影层

# 训练配置
NUM_EPOCHS = 3
BATCH_SIZE = 4           # 单卡 batch size
GRAD_ACCUMULATION = 8    # 梯度累积，有效 batch = 4 * 8 = 32
LEARNING_RATE = 2e-4     # LoRA 可用更高学习率
WARMUP_RATIO = 0.03
USE_4BIT = False         # 显存不足时改为 True 启用 QLoRA


def load_model_and_tokenizer():
    """加载模型和分词器，支持 4-bit 量化"""
    # 量化配置（QLoRA）
    bnb_config = None
    if USE_4BIT:
        bnb_config = BitsAndBytesConfig(
            load_in_4bit=True,
            bnb_4bit_quant_type="nf4",
            bnb_4bit_compute_dtype=torch.bfloat16,
            bnb_4bit_use_double_quant=True,
        )
        print("[INFO] 启用 4-bit 量化 (QLoRA 模式)")

    # 加载分词器
    tokenizer = AutoTokenizer.from_pretrained(
        MODEL_NAME,
        trust_remote_code=True,
        padding_side="right",
    )
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token

    # 加载模型
    model = AutoModelForCausalLM.from_pretrained(
        MODEL_NAME,
        quantization_config=bnb_config,
        torch_dtype=torch.bfloat16,
        device_map="auto",
        trust_remote_code=True,
        use_cache=False,  # 训练时禁用 KV 缓存
    )
    model.gradient_checkpointing_enable()  # 节省显存

    if USE_4BIT:
        model = prepare_model_for_kbit_training(model)

    print(f"[INFO] 模型加载完成，参数量: {sum(p.numel() for p in model.parameters()) / 1e9:.2f}B")
    return model, tokenizer


def tokenize_function(examples, tokenizer):
    """分词函数：将文本转为模型输入张量"""
    tokenized = tokenizer(
        examples["text"],
        truncation=True,
        padding=False,
        max_length=MAX_SEQ_LENGTH,
    )
    tokenized["labels"] = tokenized["input_ids"].copy()
    return tokenized
```

#### 第四步：LoRA 配置与训练

```python
# train.py 第2部分 - LoRA 配置与训练

def setup_lora(model):
    """配置 LoRA 参数并应用到模型"""
    lora_config = LoraConfig(
        task_type=TaskType.CAUSAL_LM,
        r=LORA_R,
        lora_alpha=LORA_ALPHA,
        lora_dropout=LORA_DROPOUT,
        target_modules=TARGET_MODULES,
        bias="none",
    )

    model = get_peft_model(model, lora_config)

    trainable = sum(p.numel() for p in model.parameters() if p.requires_grad)
    total = sum(p.numel() for p in model.parameters())
    print(f"[INFO] LoRA 配置完成:")
    print(f"  - 可训练参数: {trainable / 1e6:.2f}M ({trainable / total * 100:.2f}%)")
    print(f"  - 秩 (r): {LORA_R}, Alpha: {LORA_ALPHA}")
    print(f"  - 目标模块: {TARGET_MODULES}")
    return model


def train():
    """完整训练流程"""
    # 1. 加载数据
    print("\n[步骤1] 加载数据...")
    dataset = load_from_disk(DATA_PATH)
    print(f"  训练集: {len(dataset['train'])} 条")

    # 2. 加载模型和分词器
    print("\n[步骤2] 加载模型和分词器...")
    model, tokenizer = load_model_and_tokenizer()

    # 3. 分词
    print("\n[步骤3] 分词处理...")
    tokenized_dataset = dataset.map(
        lambda x: tokenize_function(x, tokenizer),
        batched=True,
        remove_columns=["text"],
        desc="Tokenizing",
    )

    # 4. 配置 LoRA
    print("\n[步骤4] 配置 LoRA...")
    model = setup_lora(model)

    # 5. 训练参数
    training_args = TrainingArguments(
        output_dir=OUTPUT_DIR,
        num_train_epochs=NUM_EPOCHS,
        per_device_train_batch_size=BATCH_SIZE,
        per_device_eval_batch_size=BATCH_SIZE,
        gradient_accumulation_steps=GRAD_ACCUMULATION,
        learning_rate=LEARNING_RATE,
        warmup_ratio=WARMUP_RATIO,
        lr_scheduler_type="cosine",
        logging_steps=10,
        eval_strategy="steps",
        eval_steps=100,
        save_steps=200,
        save_total_limit=3,
        bf16=True,
        gradient_checkpointing=True,
        load_best_model_at_end=True,
        metric_for_best_model="eval_loss",
        greater_is_better=False,
        report_to="none",
        seed=42,
        remove_unused_columns=False,
    )

    # 6. 数据整理器
    data_collator = DataCollatorForSeq2Seq(
        tokenizer=tokenizer,
        model=model,
        padding=True,
        label_pad_token_id=-100,  # 忽略填充位置的损失计算
    )

    # 7. 创建 Trainer
    trainer = Trainer(
        model=model,
        args=training_args,
        train_dataset=tokenized_dataset["train"],
        eval_dataset=tokenized_dataset["validation"],
        data_collator=data_collator,
        tokenizer=tokenizer,
    )

    # 8. 开始训练
    print("\n" + "=" * 60)
    print(f"[步骤5] 开始训练")
    print(f"  Epochs: {NUM_EPOCHS}")
    print(f"  有效 Batch Size: {BATCH_SIZE * GRAD_ACCUMULATION}")
    print(f"  学习率: {LEARNING_RATE}")
    print(f"  训练样本数: {len(dataset['train'])}")
    print("=" * 60 + "\n")

    trainer.train()

    # 9. 保存模型
    print("\n[步骤6] 保存 LoRA 权重...")
    trainer.save_model()
    tokenizer.save_pretrained(OUTPUT_DIR)
    print(f"[SUCCESS] 模型已保存到: {OUTPUT_DIR}")


if __name__ == "__main__":
    train()
```

#### 第五步：模型合并与推理

```python
# inference.py - 推理脚本
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM
from peft import PeftModel


def merge_and_save(lora_path: str, base_model_name: str, output_path: str):
    """
    合并 LoRA 权重到基座模型并导出为标准格式
    合并后推理延迟与原始模型完全相同，零额外开销
    """
    print("[INFO] 加载基座模型...")
    base_model = AutoModelForCausalLM.from_pretrained(
        base_model_name,
        torch_dtype=torch.bfloat16,
        device_map="auto",
        trust_remote_code=True,
    )

    print("[INFO] 加载 LoRA 权重...")
    model = PeftModel.from_pretrained(base_model, lora_path)

    print("[INFO] 合并 LoRA 权重到基座模型...")
    merged_model = model.merge_and_unload()

    print(f"[INFO] 保存合并后模型到: {output_path}")
    merged_model.save_pretrained(output_path, safe_serialization=True)

    tokenizer = AutoTokenizer.from_pretrained(lora_path, trust_remote_code=True)
    tokenizer.save_pretrained(output_path)
    print("[SUCCESS] 模型合并完成!")


def generate_response(model, tokenizer, instruction: str, input_text: str = ""):
    """使用微调后的模型生成回答"""
    # 构建与训练时一致的 prompt 格式
    if input_text:
        prompt = f"""Below is an instruction that describes a task, paired with an input that provides further context. Write a response that appropriately completes the request.

### Instruction:
{instruction}

### Input:
{input_text}

### Response:
"""
    else:
        prompt = f"""Below is an instruction that describes a task. Write a response that appropriately completes the request.

### Instruction:
{instruction}

### Response:
"""

    inputs = tokenizer(prompt, return_tensors="pt").to(model.device)

    with torch.no_grad():
        outputs = model.generate(
            **inputs,
            max_new_tokens=512,
            temperature=0.7,
            top_p=0.9,
            top_k=50,
            do_sample=True,
            repetition_penalty=1.1,
            pad_token_id=tokenizer.pad_token_id,
            eos_token_id=tokenizer.eos_token_id,
        )

    response = tokenizer.decode(outputs[0], skip_special_tokens=True)
    return response.split("### Response:")[-1].strip()


if __name__ == "__main__":
    # 1. 合并 LoRA 权重
    merge_and_save(
        lora_path="./lora-medical-output",
        base_model_name="meta-llama/Meta-Llama-3-8B",
        output_path="./lora-medical-merged",
    )

    # 2. 加载合并后模型测试
    model = AutoModelForCausalLM.from_pretrained(
        "./lora-medical-merged",
        torch_dtype=torch.bfloat16,
        device_map="auto",
        trust_remote_code=True,
    )
    tokenizer = AutoTokenizer.from_pretrained(
        "./lora-medical-merged",
        trust_remote_code=True,
    )
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token

    # 3. 测试推理
    test_cases = [
        {
            "instruction": "你是一位经验丰富的医生，请根据患者症状给出诊断建议。",
            "input": "患者男性，35岁，持续咳嗽3周，伴有低热和胸闷，近期体重下降5公斤。",
        },
        {
            "instruction": "请解释高血压患者的日常饮食注意事项。",
            "input": "",
        },
    ]

    for i, case in enumerate(test_cases, 1):
        print(f"\n--- 测试 {i} ---")
        print(f"问题: {case['instruction'][:40]}...")
        response = generate_response(model, tokenizer, case["instruction"], case["input"])
        print(f"回答: {response[:300]}...")
        print("-" * 50)
```

## 场景二：RLHF对齐训练流程

### 场景描述
某AI公司需要将一款开源对话模型进行安全对齐，使其拒绝回答有害问题、减少幻觉、遵循用户指令。团队有约3万条人工标注的偏好数据，需要在8张A100 GPU上完成RLHF全流程。

### 涉及知识点
- [Transformer架构导览](./01-大模型基础与Transformer架构-导览.md)：模型架构、RLHF概念
- [微调技术导览](./02-微调技术与LoRA原理-导览.md)：SFT训练配置
- [RLHF导览](./03-强化学习与RLHF对齐技术-导览.md)：奖励模型、PPO、DPO替代方案

### 协作流程
1. 阶段一SFT：用1万条高质量指令-回答对微调基座模型，学习率5e-6，1-2个epoch，输出SFT模型。
2. 阶段二RM：用SFT模型对每个prompt生成4个回答，标注者排序后构成偏好对。基于SFT模型移除LM Head替换为标量头训练RM，损失函数为Bradley-Terry负对数似然。
3. 阶段三PPO：加载4个模型（Actor/SFT策略、Reference/SFT冻结、Reward/RM、Critic/从RM初始化），对每个prompt由Actor采样回答，RM计算奖励，PPO用clip和KL惩罚更新策略。
4. 训练监控：实时追踪KL散度（防止策略偏离）、RM奖励均值（防止reward hacking）、回答长度分布（防止模型钻空子生成冗长回答）。
5. 评估对比：用GPT-4作为裁判对比SFT模型和RLHF模型在有用性、无害性、诚实性三个维度的胜率。

### 关键要点
- RLHF三阶段流程长，每个阶段的输出质量直接影响下一阶段，需逐阶段验证
- 偏好数据标注质量是RLHF的上限，标注指南需明确定义"好"的标准
- 若资源有限可考虑DPO替代方案：跳过RM和PPO，直接从偏好数据优化策略
- 评估不能仅看自动指标，需人工评估或LLM-as-Judge做最终判断
