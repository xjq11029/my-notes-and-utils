# AI 辅助开发 - 概念对比速查

> 模块：11-ai-assisted | 共 4 组对比

## 1. Cursor vs Claude Code vs Copilot

| 对比维度 | Cursor | Claude Code | GitHub Copilot |
|---------|--------|-------------|----------------|
| 运行环境 | IDE（VS Code 内核） | 终端（CLI） | IDE 插件 |
| 交互方式 | 图形界面 + 快捷键 | 命令行 + 对话 | 幽灵文本 + 聊天面板 |
| 实时补全 | Tab 多行补全 | 无（纯对话式） | 行内幽灵文本 |
| 多文件操作 | Composer Agent | 原生强支持 | Workspace 代理 |
| 项目理解 | 通过 @file/@folder 引用 | 自动读取项目全貌 | 当前文件 + 打开标签 |
| 终端命令执行 | Agent 模式支持 | 原生支持 | 代理模式支持 |
| 代码审查 | Chat 审查 | 原生支持 | PR 审查集成 |
| 适用场景 | 日常编码、快速迭代 | 架构重构、复杂任务 | 团队协作、GitHub 生态 |
| 学习曲线 | 低 | 中 | 低 |
| 定价 | 免费额度 + Pro $20/月 | Pro $20/月 | 个人 $10/月 |

**选择建议**：日常编码选 Cursor，复杂重构选 Claude Code，团队协作选 Copilot。

## 2. AI 直接生成 vs Few-shot 引导

| 对比维度 | 直接生成 | Few-shot 引导 |
|---------|---------|--------------|
| 代码准确率 | 60-70% | 85-95% |
| 格式一致性 | 随机 | 与示例高度一致 |
| 类型安全 | 常遗漏类型定义 | 模仿示例中的类型模式 |
| 错误处理 | 常遗漏 | 模仿示例中的错误处理 |
| 适用场景 | 简单的、无格式要求的代码 | 需要特定格式和风格的代码 |
| 额外成本 | 无 | 需要准备 1-3 个高质量示例 |

**选择建议**：简单代码直接生成，需要特定格式时使用 Few-shot。

## 3. ESLint 内置规则 vs 自定义 AST 规则

| 对比维度 | 内置规则 | 自定义 AST 规则 |
|---------|---------|----------------|
| 安装成本 | 开箱即用 | 需编写和维护插件代码 |
| 覆盖范围 | 通用语法和风格问题 | 项目特定的 API 和模式 |
| 拦截 AI 幻觉 | 部分（no-eval、no-debugger） | 全面（自定义 API 白名单） |
| 误报率 | 低 | 取决于规则设计 |
| 维护成本 | 社区维护 | 需自行维护白名单 |
| 适用场景 | 通用代码质量保障 | AI 代码质量防线 |

**选择建议**：内置规则做基础防线，自定义规则做 AI 幻觉专项拦截。

## 4. AbortController vs 请求队列 vs 版本号

| 对比维度 | AbortController | 请求队列 | 版本号机制 |
|---------|----------------|---------|-----------|
| 核心思路 | 取消旧请求 | 串行执行 | 忽略过期结果 |
| 实现复杂度 | 低 | 中 | 低 |
| 适用场景 | 搜索结果、自动补全 | 需要顺序保证的操作 | 简单场景 |
| 网络资源 | 节省（取消旧请求） | 不节省（依然发出） | 不节省（依然发出） |
| 并发能力 | 无限制 | 一次一个 | 无限制 |
| 浏览器支持 | 现代浏览器 | 不受限 | 不受限 |

**选择建议**：搜索/筛选场景用 AbortController，严格要求顺序用队列，简单场景用版本号。
