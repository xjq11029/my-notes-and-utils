# 03-可观测性与故障排查

## 一、核心概念

### 1.1 可观测性三支柱

可观测性（Observability）是通过系统输出的外部数据来推断内部状态的能力。类比医院体检：日志是病历（记录发生了什么），指标是体检数据（量化健康状况），链路是诊断流程（追踪请求的完整路径）。

```
┌──────────────────────────────────────────────────────────────┐
│                     可观测性三支柱                             │
├──────────────┬──────────────────┬────────────────────────────┤
│  Logs（日志） │ Metrics（指标）   │ Traces（链路追踪）         │
├──────────────┼──────────────────┼────────────────────────────┤
│              │                  │                            │
│ 医院类比：    │ 医院类比：         │ 医院类比：                  │
│ 病历          │ 体检数据           │ 诊断流程                    │
│              │                  │                            │
│ 记录离散事件   │ 量化系统状态        │ 追踪请求路径                │
│ 时间点明确     │ 时间序列数据        │ 端到端可视化                │
│ 结构化/非结构化 │ 可聚合/可告警       │ 上下文传播                  │
│              │                  │                            │
│ 示例：        │ 示例：             │ 示例：                      │
│ - 错误日志    │ - LCP/INP/CLS     │ - traceId 贯穿全链路        │
│ - 用户操作    │ - 错误率 2.3%     │ - spanId 标识各阶段         │
│ - 接口调用    │ - P99 响应 2.1s   │ - 前端→网关→服务→数据库      │
│ - 面包屑      │ - 可用性 99.97%   │ - 火焰图分析耗时            │
└──────────────┴──────────────────┴────────────────────────────┘
```

**三支柱的协作关系**：

| 场景 | Logs 的作用 | Metrics 的作用 | Traces 的作用 |
|---|---|---|---|
| 发现故障 | 搜索错误日志，定位异常事件 | 监控指标阈值告警 | 不适用（被动发现） |
| 定位根因 | 查看错误详情和上下文 | 查看哪个服务/接口指标异常 | 追踪故障请求的完整调用链 |
| 趋势分析 | 不适用（离散事件） | 绘制趋势图，分析规律 | 不适用（单次请求粒度） |
| 容量规划 | 不适用 | 分析 QPS 和响应时间趋势 | 识别瓶颈环节 |

### 1.2 前端故障排查流程

## 二、底层原理

### 2.1 日志收集

前端日志收集通过劫持原生 console 方法并记录用户操作轨迹（Breadcrumbs）来实现。

```typescript
// ========== 完整的日志收集器 ==========

interface LogEntry {
  level: 'debug' | 'info' | 'warn' | 'error';
  message: string;
  timestamp: number;
  breadcrumbs: BreadcrumbItem[];
  context?: Record<string, unknown>;
}

interface BreadcrumbItem {
  type: 'click' | 'navigation' | 'http' | 'console' | 'input';
  category: string;
  message: string;
  timestamp: number;
  data?: Record<string, unknown>;
}

class LoggerCollector {
  private logs: LogEntry[] = [];
  private breadcrumbs: BreadcrumbItem[] = [];
  private maxLogs = 200;
  private maxBreadcrumbs = 100;

  constructor() {
    this.hijackConsole();
    this.collectBreadcrumbs();
  }

  // ------ console 劫持 ------
  private hijackConsole(): void {
    const levels = ['debug', 'info', 'warn', 'error'] as const;

    levels.forEach((level) => {
      const original = console[level];

      console[level] = (...args: unknown[]) => {
        // 1. 保留原始行为
        original.apply(console, args);

        // 2. 收集日志
        const message = args
          .map((arg) => {
            if (arg instanceof Error) {
              return `${arg.message}\n${arg.stack}`;
            }
            if (typeof arg === 'object') {
              try {
                // 脱敏处理：移除密码、token 等敏感字段
                const sanitized = this.sanitize(arg);
                return JSON.stringify(sanitized, null, 2);
              } catch {
                return String(arg);
              }
            }
            return String(arg);
          })
          .join(' ');

        this.addLog({
          level,
          message: message.slice(0, 2000), // 截断过长日志
          timestamp: Date.now(),
          breadcrumbs: [...this.breadcrumbs].slice(-20),
        });

        // 3. error 级别日志附带面包屑
        if (level === 'error') {
          this.addBreadcrumb({
            type: 'console',
            category: 'error',
            message: message.slice(0, 500),
            timestamp: Date.now(),
          });
        }
      };
    });
  }

  // ------ 用户操作轨迹（Breadcrumbs）收集 ------
  private collectBreadcrumbs(): void {
    // 1. 点击事件
    document.addEventListener('click', (e) => {
      const target = e.target as HTMLElement;
      // 过滤掉无意义的点击
      if (target === document.body || target === document.documentElement) return;

      this.addBreadcrumb({
        type: 'click',
        category: 'user-interaction',
        message: `点击 ${target.tagName.toLowerCase()}${target.id ? '#' + target.id : ''}${target.className ? '.' + target.className.split(' ').slice(0, 2).join('.') : ''}`,
        timestamp: Date.now(),
        data: {
          text: target.textContent?.slice(0, 50),
          position: { x: (e as MouseEvent).clientX, y: (e as MouseEvent).clientY },
        },
      });
    }, true);

    // 2. 输入事件（仅记录输入框类型，不记录具体内容，保护隐私）
    document.addEventListener('input', (e) => {
      const target = e.target as HTMLInputElement;
      if (!target.name && !target.id) return;

      this.addBreadcrumb({
        type: 'input',
        category: 'user-interaction',
        message: `输入 ${target.name || target.id} (${target.type})`,
        timestamp: Date.now(),
        data: {
          name: target.name,
          type: target.type,
          // 不记录 value，保护用户隐私
        },
      });
    }, true);

    // 3. 路由导航
    const originalPushState = history.pushState;
    history.pushState = (...args) => {
      this.addBreadcrumb({
        type: 'navigation',
        category: 'route',
        message: `导航到: ${args[2] || '/'}`,
        timestamp: Date.now(),
        data: { url: args[2], from: window.location.pathname },
      });
      return originalPushState.apply(history, args);
    };

    // 4. 网络请求
    this.interceptFetch();
  }

  private interceptFetch(): void {
    const originalFetch = window.fetch;
    window.fetch = (...args: Parameters<typeof fetch>) => {
      const url = typeof args[0] === 'string' ? args[0] : args[0].url;
      const method = (typeof args[0] === 'object' ? args[0].method : args[1]?.method) || 'GET';
      const start = Date.now();

      return originalFetch(...args)
        .then((response) => {
          this.addBreadcrumb({
            type: 'http',
            category: 'network',
            message: `${method} ${url} → ${response.status} (${Date.now() - start}ms)`,
            timestamp: Date.now(),
            data: { url, method, status: response.status, duration: Date.now() - start },
          });
          return response;
        })
        .catch((error) => {
          this.addBreadcrumb({
            type: 'http',
            category: 'network',
            message: `${method} ${url} → 失败 (${Date.now() - start}ms)`,
            timestamp: Date.now(),
            data: { url, method, error: error instanceof Error ? error.message : String(error) },
          });
          throw error;
        });
    };
  }

  // ------ 数据脱敏 ------
  private sanitize(obj: unknown): unknown {
    if (typeof obj !== 'object' || obj === null) return obj;

    const sensitiveKeys = ['password', 'token', 'secret', 'authorization', 'cookie', 'creditCard'];
    const sanitized: Record<string, unknown> = {};

    if (Array.isArray(obj)) {
      return obj.map(item => this.sanitize(item));
    }

    for (const [key, value] of Object.entries(obj as Record<string, unknown>)) {
      if (sensitiveKeys.some(k => key.toLowerCase().includes(k.toLowerCase()))) {
        sanitized[key] = '***[REDACTED]***';
      } else {
        sanitized[key] = this.sanitize(value);
      }
    }
    return sanitized;
  }

  private addLog(log: LogEntry): void {
    this.logs.push(log);
    if (this.logs.length > this.maxLogs) {
      this.logs.shift();
    }
  }

  private addBreadcrumb(breadcrumb: BreadcrumbItem): void {
    this.breadcrumbs.push(breadcrumb);
    if (this.breadcrumbs.length > this.maxBreadcrumbs) {
      this.breadcrumbs.shift();
    }
  }

  // 获取最近的日志（用于错误上报时附带上下文）
  getRecentLogs(count = 50): LogEntry[] {
    return this.logs.slice(-count);
  }

  // 获取最近的面包屑
  getBreadcrumbs(count = 30): BreadcrumbItem[] {
    return this.breadcrumbs.slice(-count);
  }
}
```

### 2.2 性能指标采集

```typescript
// ========== 性能指标采集（含自定义指标）==========

interface PerformanceMetrics {
  // Core Web Vitals
  lcp: number;
  inp: number;
  cls: number;
  fcp: number;
  ttfb: number;

  // 自定义指标
  customMetrics: Record<string, number>;
}

class MetricsCollector {
  private metrics: PerformanceMetrics = {
    lcp: 0, inp: 0, cls: 0, fcp: 0, ttfb: 0,
    customMetrics: {},
  };
  private observers: PerformanceObserver[] = [];

  start(): void {
    this.observeLCP();
    this.observeINP();
    this.observeCLS();
    this.observeFCP();
    this.measureTTFB();
    this.observeLongTasks();
    this.measureCustomMetrics();
  }

  private observeLCP(): void {
    // 原理详见 01-前端监控体系 2.2 节
    const observer = new PerformanceObserver((list) => {
      const entries = list.getEntries();
      const lastEntry = entries[entries.length - 1];
      this.metrics.lcp = lastEntry.startTime;
    });
    observer.observe({ type: 'largest-contentful-paint', buffered: true });
    this.observers.push(observer);
  }

  private observeINP(): void {
    let maxDelay = 0;
    const observer = new PerformanceObserver((list) => {
      for (const entry of list.getEntries()) {
        const evt = entry as PerformanceEventTiming;
        if (evt.interactionId) {
          maxDelay = Math.max(maxDelay, evt.processingStart - evt.startTime);
        }
      }
    });
    observer.observe({ type: 'event', buffered: true, durationThreshold: 16 });
    this.observers.push(observer);

    window.addEventListener('visibilitychange', () => {
      if (document.visibilityState === 'hidden') {
        this.metrics.inp = maxDelay;
      }
    });
  }

  private observeCLS(): void {
    let clsValue = 0;
    const observer = new PerformanceObserver((list) => {
      for (const entry of list.getEntries()) {
        const shift = entry as LayoutShift;
        if (!shift.hadRecentInput) {
          clsValue += shift.value;
        }
      }
    });
    observer.observe({ type: 'layout-shift', buffered: true });
    this.observers.push(observer);

    window.addEventListener('visibilitychange', () => {
      if (document.visibilityState === 'hidden') {
        this.metrics.cls = clsValue;
      }
    });
  }

  private observeFCP(): void {
    const observer = new PerformanceObserver((list) => {
      const entry = list.getEntries().find((e) => e.name === 'first-contentful-paint');
      if (entry) this.metrics.fcp = entry.startTime;
    });
    observer.observe({ type: 'paint', buffered: true });
    this.observers.push(observer);
  }

  private measureTTFB(): void {
    const nav = performance.getEntriesByType('navigation')[0] as PerformanceNavigationTiming;
    if (nav) {
      this.metrics.ttfb = nav.responseStart - nav.requestStart;
    }
  }

  private observeLongTasks(): void {
    const observer = new PerformanceObserver((list) => {
      for (const entry of list.getEntries()) {
        if (entry.duration > 50) {
          // 长任务记录
          this.metrics.customMetrics[`long_task_${entry.startTime.toFixed(0)}`] = entry.duration;
        }
      }
    });
    observer.observe({ type: 'longtask', buffered: true });
    this.observers.push(observer);
  }

  // ------ 自定义指标测量 ------
  private measureCustomMetrics(): void {
    // 监听页面完全加载（所有资源加载完成）
    window.addEventListener('load', () => {
      // 使用 PerformanceNavigationTiming（Level 2）替代已废弃的 performance.timing
      const navEntry = performance.getEntriesByType('navigation')[0] as PerformanceNavigationTiming;
      if (navEntry) {
        this.metrics.customMetrics['page_fully_loaded'] = navEntry.loadEventEnd - navEntry.startTime;
      }
    });

    // 测量首次交互时间（三种事件类型任意一个触发即记录）
    // firstInteraction 标志确保跨事件类型互斥，{ once: true } 用于自动解绑监听器
    let firstInteraction = true;
    ['click', 'keydown', 'scroll'].forEach((eventType) => {
      window.addEventListener(eventType, () => {
        if (firstInteraction) {
          this.metrics.customMetrics['first_interaction'] = performance.now();
          firstInteraction = false;
        }
      }, { once: true });
    });
  }

  // 公共方法：手动测量自定义指标
  measureTiming(name: string, fn: () => void): void {
    const start = performance.now();
    fn();
    const duration = performance.now() - start;
    this.metrics.customMetrics[name] = duration;
  }

  // 获取所有指标
  getMetrics(): PerformanceMetrics {
    return { ...this.metrics };
  }

  stop(): void {
    this.observers.forEach((o) => o.disconnect());
    this.observers = [];
  }
}
```

### 2.3 链路追踪

W3C Trace Context 标准定义了 `traceparent` 和 `tracestate` 两个 HTTP 头，用于在分布式系统中传播追踪上下文。

```typescript
// ========== 前端链路追踪实现 ==========

// W3C Trace Context 标准格式：
// traceparent: 00-{traceId}-{spanId}-{traceFlags}
//   00 = 版本号
//   traceId = 32 位十六进制（16 字节）
//   spanId = 16 位十六进制（8 字节）
//   traceFlags = 01（采样）或 00（不采样）

class TraceContext {
  traceId: string;
  spanId: string;
  parentSpanId?: string;
  sampled: boolean;

  constructor(traceId?: string, sampled = true) {
    this.traceId = traceId || TraceContext.generateId(32);
    this.spanId = TraceContext.generateId(16);
    this.sampled = sampled;
  }

  // 生成十六进制 ID
  private static generateId(length: number): string {
    const chars = '0123456789abcdef';
    let id = '';
    const array = new Uint8Array(length / 2);
    crypto.getRandomValues(array);
    for (let i = 0; i < array.length; i++) {
      id += chars[array[i] >> 4] + chars[array[i] & 15];
    }
    return id;
  }

  // 创建子 Span
  createChildSpan(): TraceContext {
    const child = new TraceContext(this.traceId, this.sampled);
    child.parentSpanId = this.spanId;
    return child;
  }

  // 生成 W3C traceparent 头
  toTraceParent(): string {
    const flags = this.sampled ? '01' : '00';
    return `00-${this.traceId}-${this.spanId}-${flags}`;
  }

  // 从 traceparent 头解析
  static fromTraceParent(header: string): TraceContext | null {
    const parts = header.split('-');
    if (parts.length !== 4 || parts[0] !== '00') return null;

    // parts[1] = traceId, parts[2] = parentSpanId（上游传递的 spanId）, parts[3] = flags
    const ctx = new TraceContext(parts[1], parts[3] === '01');
    ctx.parentSpanId = parts[2]; // 保存上游 spanId 为 parentSpanId
    // ctx.spanId 已在构造函数中通过 generateId 生成了新的 spanId
    return ctx;
  }
}

// 前端追踪器
class FrontendTracer {
  private currentTrace: TraceContext | null = null;
  private spans: Span[] = [];

  // 创建新的 Trace
  startTrace(operationName: string): TraceContext {
    this.currentTrace = new TraceContext();
    this.startSpan(operationName); // 注意：此处是 Sentry 的实现，与 OpenTelemetry 的 startSpan 有细微差异
    return this.currentTrace;
  }

  // 创建 Span
  startSpan(operationName: string, attributes?: Record<string, string>): Span {
    if (!this.currentTrace) {
      this.currentTrace = new TraceContext();
    }

    const parentContext = this.currentTrace;
    this.currentTrace = this.currentTrace.createChildSpan();

    const span: Span = {
      traceId: this.currentTrace.traceId,
      spanId: this.currentTrace.spanId,
      parentSpanId: this.currentTrace.parentSpanId || parentContext.spanId,
      operationName,
      startTime: performance.now(),
      attributes: attributes || {},
    };

    this.spans.push(span);
    return span;
  }

  // 结束 Span
  endSpan(span: Span): void {
    span.endTime = performance.now();
    span.duration = span.endTime - span.startTime;
  }

  // 在 fetch 请求中传播追踪上下文
  createTracedFetch(): typeof fetch {
    const originalFetch = window.fetch.bind(window);

    return (...args: Parameters<typeof fetch>) => {
      const span = this.startSpan('http-request', {
        url: typeof args[0] === 'string' ? args[0] : args[0].url,
      });

      // 将 traceparent 头注入到请求中
      const headers = new Headers(args[1]?.headers);
      if (this.currentTrace) {
        headers.set('traceparent', this.currentTrace.toTraceParent());
      }

      const modifiedArgs: [RequestInfo, RequestInit?] = [
        args[0],
        { ...args[1], headers },
      ];

      return originalFetch(...modifiedArgs)
        .then((response) => {
          this.endSpan(span);
          return response;
        })
        .catch((error) => {
          this.endSpan(span);
          throw error;
        });
    };
  }

  // 获取所有 Span 数据
  getSpans(): Span[] {
    return [...this.spans];
  }
}

interface Span {
  traceId: string;
  spanId: string;
  parentSpanId: string;
  operationName: string;
  startTime: number;
  endTime?: number;
  duration?: number;
  attributes: Record<string, string>;
}

// 使用示例
const tracer = new FrontendTracer();

// 开始一个追踪
tracer.startTrace('page-load');

// 创建子 Span
const loadDataSpan = tracer.startSpan('load-user-data', { userId: '123' });
// ... 加载用户数据
tracer.endSpan(loadDataSpan);

const renderSpan = tracer.startSpan('render-dashboard', { component: 'Dashboard' });
// ... 渲染仪表盘
tracer.endSpan(renderSpan);

// 使用带追踪的 fetch
const tracedFetch = tracer.createTracedFetch();
tracedFetch('/api/data');

// 上报追踪数据
console.log(tracer.getSpans());
```

### 2.4 告警策略设计

告警策略需要平衡"不漏报"和"不误报"，避免告警风暴和告警疲劳。

```typescript
// ========== 告警策略设计 ==========

interface AlertRule {
  name: string;
  type: 'threshold' | 'trend' | 'new_error' | 'anomaly';
  description: string;
  condition: (metrics: AlertMetrics) => boolean;
  cooldown: number; // 冷却时间（秒），同一规则两次告警的最小间隔
  severity: 'critical' | 'warning' | 'info';
}

interface AlertMetrics {
  // 错误相关
  errorRate: number;           // 错误率 0-1
  errorCount: number;          // 5 分钟内错误数
  affectedUsers: number;       // 受影响用户数
  newErrorTypes: string[];     // 新出现的错误类型

  // 性能相关
  p50ResponseTime: number;
  p95ResponseTime: number;
  p99ResponseTime: number;
  lcp: number;
  inp: number;
  cls: number;

  // 可用性相关
  availability: number;        // 0-1
  pvCount: number;
}

class AlertEngine {
  private rules: AlertRule[] = [];
  private lastAlertTimes: Map<string, number> = new Map();
  private alertHistory: AlertRecord[] = [];

  constructor() {
    this.registerDefaultRules();
  }

  private registerDefaultRules(): void {
    // 规则 1：错误率阈值告警
    this.rules.push({
      name: '错误率超过 1%',
      type: 'threshold',
      description: '5 分钟内错误率超过 1% 且影响用户数 > 10',
      condition: (m) => m.errorRate > 0.01 && m.affectedUsers > 10,
      cooldown: 300, // 5 分钟冷却
      severity: 'critical',
    });

    // 规则 2：P99 响应时间告警
    this.rules.push({
      name: 'P99 响应时间超过 3s',
      type: 'threshold',
      description: 'P99 响应时间超过 3 秒',
      condition: (m) => m.p99ResponseTime > 3000,
      cooldown: 600, // 10 分钟冷却
      severity: 'warning',
    });

    // 规则 3：新错误类型告警
    this.rules.push({
      name: '新错误类型出现',
      type: 'new_error',
      description: '出现之前未出现过的错误类型',
      condition: (m) => m.newErrorTypes.length > 0,
      cooldown: 0, // 新错误告警不需要冷却
      severity: 'warning',
    });

    // 规则 4：错误率趋势告警（环比增长 100%）
    this.rules.push({
      name: '错误率趋势告警',
      type: 'trend',
      description: '错误率环比增长超过 100%',
      condition: (m) => {
        const previous = this.getPreviousErrorRate();
        return previous > 0 && m.errorRate > previous * 2;
      },
      cooldown: 600,
      severity: 'warning',
    });

    // 规则 5：可用性告警
    this.rules.push({
      name: '可用性低于 99.9%',
      type: 'threshold',
      description: '页面可用性低于 99.9%',
      condition: (m) => m.availability < 0.999,
      cooldown: 300,
      severity: 'critical',
    });

    // 规则 6：LCP 超标告警
    this.rules.push({
      name: 'LCP 超过 4 秒',
      type: 'threshold',
      description: 'P75 LCP 超过 4 秒',
      condition: (m) => m.lcp > 4000,
      cooldown: 1800, // 30 分钟冷却
      severity: 'warning',
    });
  }

  evaluate(metrics: AlertMetrics): AlertRecord[] {
    const triggered: AlertRecord[] = [];
    const now = Date.now();

    for (const rule of this.rules) {
      // 检查冷却时间
      const lastTime = this.lastAlertTimes.get(rule.name) || 0;
      if (now - lastTime < rule.cooldown * 1000) {
        continue; // 在冷却期内，跳过
      }

      // 检查条件
      if (rule.condition(metrics)) {
        const record: AlertRecord = {
          ruleName: rule.name,
          severity: rule.severity,
          triggeredAt: now,
          metrics: { ...metrics },
        };

        this.lastAlertTimes.set(rule.name, now);
        this.alertHistory.push(record);
        triggered.push(record);

        this.sendAlert(record);
      }
    }

    return triggered;
  }

  private getPreviousErrorRate(): number {
    // 从历史数据中获取上一次的错误率
    const previous = this.alertHistory
      .filter((a) => a.metrics.errorRate !== undefined)
      .slice(-1)[0];
    return previous?.metrics?.errorRate || 0;
  }

  private sendAlert(record: AlertRecord): void {
    // 发送告警通知（钉钉、飞书、邮件、短信等）
    console.log(`[告警] ${record.severity.toUpperCase()}: ${record.ruleName}`, record.metrics);
  }
}

interface AlertRecord {
  ruleName: string;
  severity: 'critical' | 'warning' | 'info';
  triggeredAt: number;
  metrics: AlertMetrics;
}

// 使用示例
const alertEngine = new AlertEngine();

// 模拟告警评估
const currentMetrics: AlertMetrics = {
  errorRate: 0.025,        // 2.5% 错误率
  errorCount: 150,
  affectedUsers: 45,
  newErrorTypes: ['TypeError: undefined is not a function'],
  p50ResponseTime: 800,
  p95ResponseTime: 2400,
  p99ResponseTime: 3500,   // 超过 3s
  lcp: 3200,
  inp: 180,
  cls: 0.08,
  availability: 0.998,
  pvCount: 10000,
};

const alerts = alertEngine.evaluate(currentMetrics);
console.log('触发的告警:', alerts);
```

**告警策略设计原则**：

| 原则 | 说明 | 示例 |
|---|---|---|
| 基于影响用户数 | 不以错误次数告警，以受影响用户数为准 | 10 个用户各报错 100 次，不如 100 个用户各报错 1 次严重 |
| 冷却时间 | 同一规则两次告警之间有最小间隔 | 错误率告警 5 分钟冷却，避免告警风暴 |
| 分级告警 | critical > warning > info | 可用性 < 99.9% 是 critical，LCP > 4s 是 warning |
| 趋势告警 | 不只看绝对值，也看环比变化 | 错误率从 0.1% 飙升至 0.5%，即使未超过 1% 阈值也应告警 |
| 新错误告警 | 新出现的错误类型即时告警 | 之前从未出现过的 TypeError，即使量少也应立即关注 |

// ========== 前端上报 Prometheus 指标 ==========

class PrometheusReporter {
  private endpoint: string;
  private metrics: Map<string, number> = new Map();

  constructor(endpoint: string) {
    this.endpoint = endpoint;
  }

  // 记录 Counter 类型指标（只增不减）
  incrementCounter(name: string, labels?: Record<string, string>): void {
    const key = this.formatMetric(name, labels);
    this.metrics.set(key, (this.metrics.get(key) || 0) + 1);
  }

  // 记录 Gauge 类型指标（可增可减）
  setGauge(name: string, value: number, labels?: Record<string, string>): void {
    const key = this.formatMetric(name, labels);
    this.metrics.set(key, value);
  }

  // 记录 Histogram 类型指标（分布统计）
  recordHistogram(name: string, value: number, labels?: Record<string, string>): void {
    const key = this.formatMetric(name, labels);
    this.metrics.set(key, value);
  }

  private formatMetric(name: string, labels?: Record<string, string>): string {
    if (!labels || Object.keys(labels).length === 0) return name;
    const labelStr = Object.entries(labels)
      .map(([k, v]) => `${k}="${v}"`)
      .join(',');
    return `${name}{${labelStr}}`;
  }

  // 推送指标到 Pushgateway
  async push(): Promise<void> {
    let body = '';
    this.metrics.forEach((value, key) => {
      body += `${key} ${value}\n`;
    });

    try {
      await fetch(this.endpoint, {
        method: 'POST',
        body,
        headers: { 'Content-Type': 'text/plain' },
      });
    } catch (error) {
      console.error('[PrometheusReporter] 推送失败:', error);
    }
  }
}

// 使用示例
const promReporter = new PrometheusReporter('https://pushgateway.example.com/metrics/job/frontend');

// 页面加载时上报 PV
promReporter.incrementCounter('frontend_page_views_total', { page: '/dashboard' });
promReporter.incrementCounter('frontend_page_views_total', { page: '/dashboard', status: '200' });

// 上报性能指标
promReporter.setGauge('frontend_lcp_seconds', 2.3);
promReporter.setGauge('frontend_inp_seconds', 0.15);
promReporter.setGauge('frontend_cls_score', 0.05);

// 上报 API 耗时

// 定时推送
setInterval(() => promReporter.push(), 15000); // 每 15 秒推送一次

## 四、常见面试题

### 面试题 1：什么是可观测性三支柱？它们之间的关系是什么？

**答案要点**：

可观测性三支柱包括 Logs（日志）、Metrics（指标）、Traces（链路追踪）：
- **Logs**：记录离散事件，提供详细的上下文信息，适合问题定位
- **Metrics**：时间序列数据，可聚合和告警，适合发现问题和趋势分析
- **Traces**：追踪请求的完整调用链，适合定位分布式系统中的瓶颈

三者关系：Metrics 发现问题（"错误率上升了"），Traces 定位范围（"是哪个服务/接口慢了"），Logs 定位根因（"具体是什么错误"）。

### 面试题 2：前端故障排查的标准流程是什么？

**答案要点**：

六步法：发现（Detect）→ 定位（Locate）→ 复现（Reproduce）→ 修复（Fix）→ 验证（Verify）→ 复盘（Review）。

关键工具：发现靠监控告警和用户反馈；定位靠 Sentry 错误堆栈和 Sourcemap 还原；复现靠本地模拟条件；修复靠代码改动和测试；验证靠灰度发布和监控确认；复盘靠文档和流程改进。

### 面试题 3：什么是 W3C Trace Context？如何在前后端之间传递 traceId？

**答案要点**：

W3C Trace Context 是分布式追踪的 W3C 标准，定义了 `traceparent` HTTP 头格式：`00-{traceId}-{spanId}-{traceFlags}`。

传递方式：
1. 前端生成 traceId 和 spanId
2. 在 fetch/XHR 请求中通过 `traceparent` 头传递给后端
3. 后端接收后继续传递给下游服务
4. 所有服务使用同一个 traceId，各自生成 spanId
5. 在追踪系统（如 Jaeger、Zipkin）中通过 traceId 关联所有 Span

### 面试题 4：如何设计一个合理的告警策略？

**答案要点**：

五项原则：
1. **基于影响用户数**：不以错误次数告警，以受影响用户数为准
2. **冷却时间**：同一规则两次告警之间有最小间隔，避免告警风暴
3. **分级告警**：critical > warning > info，不同级别不同通知渠道
4. **趋势告警**：不只看绝对值，也看环比变化
5. **新错误告警**：新出现的错误类型即时告警，即使量少

### 面试题 5：Session Replay 是什么？有哪些采样策略？

**答案要点**：

Session Replay 是用户行为录制回放技术，记录 DOM 快照、用户交互、网络请求、控制台日志等。

采样策略：
- **全量采样**：录制所有会话，成本高但数据完整
- **比例采样**：录制固定比例（如 10%）的会话
- **错误优先采样**：正常会话低采样率，错误发生时 100% 录制
- **用户分群采样**：仅录制特定用户群（如付费用户、内部测试用户）

推荐策略：`replaysSessionSampleRate: 0.1` + `replaysOnErrorSampleRate: 1.0`，即正常采样 10%，错误时 100% 录制。

## 五、避坑指南

| 常见错误 | 产生原因 | 正确做法 |
|---|---|---|
| 告警太多导致"狼来了"效应，团队对告警不再敏感 | 告警阈值设置过低；告警无冷却时间；无分级告警 | 告警阈值基于统计学（如 P99 而非平均值）；每个规则设置冷却时间；分级告警（critical 即时通知，warning 仅发邮件，info 汇总日报） |
| Session Replay 录制了敏感信息（密码、身份证号、银行卡号等），导致隐私合规风险 | 未开启脱敏配置；录制范围过大 | 配置 `maskAllText: true` 脱敏所有文本；`maskAllInputs: true` 脱敏所有输入框；`blockAllMedia: true` 阻止媒体录制；排除敏感页面（如支付页、个人信息页） |
| 日志中包含了完整的用户 token 和密码，被泄露到第三方监控平台 | console 劫持时未脱敏；日志上报时未过滤敏感字段 | 实现数据脱敏函数，过滤 password、token、secret 等敏感字段；日志上报前进行脱敏检查；敏感数据使用 `***[REDACTED]***` 替换 |
