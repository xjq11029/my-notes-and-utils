# JavaScript核心 - 概念对比速查

---

### var vs let vs const

| 对比维度 | var | let | const |
|---------|-----|-----|-------|
| 作用域 | 函数作用域或全局作用域 | 块级作用域 | 块级作用域 |
| 变量提升 | 存在提升，声明前访问为undefined | 存在提升但声明前访问报错(TDZ) | 存在提升但声明前访问报错(TDZ) |
| 重复声明 | 允许重复声明同一变量 | 同一作用域不允许重复声明 | 同一作用域不允许重复声明 |
| 重新赋值 | 允许重新赋值 | 允许重新赋值 | 不允许重新赋值 |
| 绑定全局 | 顶层声明会绑定到globalThis | 顶层声明不绑定到globalThis | 顶层声明不绑定到globalThis |
| 适用场景 | 遗留代码，兼容旧浏览器 | 需要重新赋值的变量 | 不需要重新赋值的常量 |
| 选择建议 | 避免使用 | 优先使用const，需要重新赋值时使用let | 优先默认使用const |

### == vs ===

| 对比维度 | ==（抽象相等） | ===（严格相等） |
|---------|---------------|----------------|
| 类型转换 | 会进行隐式类型转换后比较 | 不进行类型转换，类型不同直接不相等 |
| null与undefined | null == undefined 结果为true | null === undefined 结果为false |
| 0与false | 0 == false 结果为true | 0 === false 结果为false |
| 空字符串与false | '' == false 结果为true | '' === false 结果为false |
| 对象与原始值 | 会尝试调用valueOf/toString转换 | 类型不同直接返回false |
| 优点 | 某些场景下更简洁（如判断null/undefined） | 更严格，避免隐式转换带来的意外错误 |
| 选择建议 | 只在判断null/undefined时使用（x == null） | 默认所有比较都使用=== |

### null vs undefined

| 对比维度 | null | undefined |
|---------|------|-----------|
| 含义 | 表示"空值"，有意赋值为空 | 表示"未定义"，变量未赋值默认值 |
| 类型 | Null（语言类型） | Undefined（语言类型） |
| typeof结果 | "object" | "undefined" |
| 转换为数字 | 0 | NaN |
| JSON序列化 | 会被序列化为null | 对象属性中：被省略；数组中：变为 null |
| 使用场景 | 对象原型链终点，清空对象引用 | 变量声明未赋值，函数参数未传，函数无返回值 |
| 判断方式 | x === null | x === undefined |
| 相等比较 | null == undefined 为true | null == undefined 为true |

### async/await vs Promise

| 对比维度 | Promise | async/await |
|---------|---------|------------|
| 语法风格 | 链式调用（.then().catch()） | 同步语法风格（try/catch） |
| 代码结构 | 横向嵌套，易造成then地狱 | 纵向扁平，更符合阅读习惯 |
| 错误处理 | .catch()捕获，每个链式可单独捕获 | try/catch统一捕获，也可以使用.catch() |
| 并发控制 | Promise.all实现并发 | 需要结合Promise.all使用await |
| 调试难度 | 断点调试困难，跨回调难以跟踪 | 调试和同步代码一样简单 |
| 错误冒泡 | 需要在链式末尾添加catch | 错误自然冒泡到上层catch |
| 适用场景 | 单个异步操作，简单链式调用 | 多个顺序依赖的异步操作 |
| 选择建议 | 简单异步操作直接使用Promise | 复杂异步流程优先使用async/await |

### map vs forEach vs for

| 对比维度 | map | forEach | for循环 |
|---------|-----|---------|---------|
| 返回值 | 返回新数组，包含转换结果 | 返回undefined | 返回undefined |
| 是否改变原数组 | 不改变原数组 | 不改变原数组 | 可以改变原数组 |
| 链式调用 | 支持，可以继续调用filter/reduce等 | 不支持，返回undefined | 不支持 |
| 中断循环 | 不能中断，会遍历所有元素 | 不能中断，会遍历所有元素 | 可以使用break/continue中断 |
| 性能 | 会创建新数组，需要额外内存 | 没有返回值，比map略高效 | 最灵活，性能最好 |
| 适用场景 | 数组转换，生成新数组 | 遍历数组执行副作用操作 | 需要提前中断，复杂遍历逻辑 |
| 选择建议 | 需要得到转换结果时使用 | 需要执行操作不需要返回值时使用 | 需要优化性能或提前退出时使用 |
