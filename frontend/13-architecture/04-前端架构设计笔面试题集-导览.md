# 04-前端架构设计笔面试题集 - 导览

---

## 选择题部分（10 题）

| 维度 | 内容 |
|---|---|
| 是什么 | 10 道选择题覆盖微前端（3 题）、设计系统（3 题）、架构管理（4 题），每题附详细解析 |
| 能做什么 | 快速检验对前端架构核心概念的掌握程度；模拟面试中的选择题环节 |
| 怎么用 | 先独立完成所有题目，再对照解析检查答案，标记错题重点复习 |
| 原理和工作流程 | 每道题考查一个核心知识点，解析中说明正确选项的原因和错误选项的误区 |
| 缺点 | 选择题只能覆盖知识点，无法考察实际编码和架构设计能力 |

---

## 简答题部分（8 题）

| 维度 | 内容 |
|---|---|
| 是什么 | 8 道简答题覆盖微前端价值、方案对比、Design Tokens 原理、Headless UI 对比、依赖倒置、技术债管理、技术选型平衡、渐进式迁移策略 |
| 能做什么 | 模拟面试中的简答环节；提供标准化的答题要点和思路 |
| 怎么用 | 先尝试口头回答，再对照答案要点补充遗漏，反复练习直到流畅表达 |
| 原理和工作流程 | 每道题从"是什么"、"为什么"、"怎么做"三个维度组织答案 |
| 缺点 | 简答题答案仅供参考，实际面试中需要结合项目经验展开 |

---

## 场景设计题部分（5 题）

| 维度 | 内容 |
|---|---|
| 是什么 | 5 道场景设计题：微前端架构设计、设计系统规划、技术选型评估、分层架构重构、技术债管理方案 |
| 能做什么 | 模拟面试中的场景设计/系统设计环节；培养架构思维和方案设计能力 |
| 怎么用 | 先独立设计方案（画出架构图、列出关键决策），再对照答案要点补充和优化 |
| 原理和工作流程 | 每道题从需求分析 → 方案选择 → 架构设计 → 关键决策 → 实施策略逐步展开 |
| 缺点 | 场景设计题的答案具有开放性，实际项目中需要结合更多约束条件 |
