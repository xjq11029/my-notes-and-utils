# Vue3 - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| ref对象解构后丢失响应式 | 解构赋值会断开与ref的引用关系 | 使用toRefs或toRef保持响应式，或直接使用.value访问 | [Vue3核心语法导览](./01-Vue3核心语法-导览.md) |
| reactive对象进行整体替换后丢失响应式 | 直接将新对象赋值给reactive变量会断开响应式引用 | 使用Object.assign更新属性，或使用ref包裹对象 | [Vue3核心语法导览](./01-Vue3核心语法-导览.md) |
| 在setup中忘记computed的依赖会触发多次计算 | 不了解computed的缓存机制 | 确保computed依赖的响应式数据正确，computed只在依赖变化时重新计算 | [Vue3核心语法导览](./01-Vue3核心语法-导览.md) |
| v-if和v-for同时使用导致性能问题 | v-for优先级高于v-if，v-if在每次循环中执行 | 使用computed过滤数据后v-for遍历，或使用template包裹v-if然后v-for | [Vue3核心语法导览](./01-Vue3核心语法-导览.md) |
| 组合式函数中直接修改props | props是单向数据流，子组件不应修改父组件传入的值 | 使用emit通知父组件修改，使用computed或者本地ref作为副本 | [Vue3核心语法导览](./01-Vue3核心语法-导览.md) |
| 使用ref获取DOM时机错误 | 在组件挂载前访问ref（如setup顶层） | 在onMounted生命周期中访问ref，或使用watchEffect监听ref值变化 | [Vue3核心语法导览](./01-Vue3核心语法-导览.md) |
| 响应式数据使用普通for...in循环导致性能问题 | 不了解Proxy的get陷阱每次读取属性都会触发依赖收集 | 使用Object.keys获取属性列表，或者使用shallowRef避免深层响应式 | [响应式与编译优化导览](./02-响应式与编译优化-导览.md) |
| 大列表未使用v-memo或虚拟列表导致卡顿 | 大量DOM节点同时渲染造成性能瓶颈 | 使用v-memo缓存不变的行，或使用虚拟列表库只渲染可视区域 | [响应式与编译优化导览](./02-响应式与编译优化-导览.md) |
| 多组件间共享状态使用不当导致数据流混乱 | 不了解provide/inject与响应式API的配合 | 使用provide传递ref对象，inject接收后读取.value，或使用Pinia管理状态 | [响应式与编译优化导览](./02-响应式与编译优化-导览.md) |
| 使用watchEffect未注意副作用导致无限循环 | watchEffect中修改了依赖的响应式数据 | 检查watchEffect内部的副作用，确保不会无限触发依赖更新 | [响应式与编译优化导览](./02-响应式与编译优化-导览.md) |
| 路由跳转后页面状态丢失 | 组件销毁时状态未保存 | 使用keep-alive包裹router-view缓存组件，使用pinia将状态提升到全局 | [路由与状态管理导览](./03-路由与状态管理-导览.md) |
| 路由守卫中访问store但store未初始化 | 路由守卫执行时机早于pinia安装 | 在路由守卫中动态导入store，或使用pinia的独立store实例 | [路由与状态管理导览](./03-路由与状态管理-导览.md) |
| Pinia store中直接修改state导致持久化未更新 | 直接修改state未通过action触发持久化钩子 | 使用action统一修改state，在action中调用持久化插件的方法 | [路由与状态管理导览](./03-路由与状态管理-导览.md) |
| 动态路由参数变化时组件未重新渲染 | 未监听路由参数变化或未使用key绑定 | 使用watch监听route.params变化，或给router-view添加key绑定 | [路由与状态管理导览](./03-路由与状态管理-导览.md) |
| 使用Vue3的Composition API但未正确导入生命周期 | 从vue包导入生命周期函数名称错误 | 使用onMounted、onUnmounted等正确名称，注意on前缀 | [路由与状态管理导览](./03-路由与状态管理-导览.md) |
| Teleport组件内容样式未正确生效 | Teleport将内容渲染到目标位置，CSS作用域可能失效 | 在目标元素上定义样式，或使用:deep()穿透作用域 | [Vue3笔面试题集导览](./04-Vue3笔面试题集-导览.md) |
| Suspense组件使用不当导致白屏 | 未正确处理异步组件的加载状态 | 使用Suspense包裹异步组件，提供fallback插槽显示加载状态 | [Vue3笔面试题集导览](./04-Vue3笔面试题集-导览.md) |
