## 核验记录（2026-11-10）

核验方式：三组并行核查，口径为 **官方模型卡 / 官方文档与源码 / 法规原文**；价格取 2026 年 11 月国内成交价量级。

### 六处硬错误

| # | 原文 | 实际 |
|---|---|---|
| 1 | Qwen3-Coder 有 14B 版本 | 官方只有 480B-A35B、30B-A3B、Coder-Next（80B-A3B）；14B 型号从未存在 |
| 2 | 4060 Ti / 5060 Ti 16G 约 3000 元 | 2026-11 国内成交约 4000 / 5000 元 |
| 3 | 671B MoE 用 8 卡 80G | FP8 权重约 671 GB，8×80 GB 装不下；需 8×H200 141G 或 16×H100 |
| 4 | vLLM 24\~32 并发 | `--max-num-seqs` 默认 128，可调数百 |
| 5 | Ollama 8\~10 并发、llama.cpp 4\~6 并发 | Ollama 默认并行 1；llama.cpp 默认 auto；且并发 ≠ 吞吐 |
| 6 | 日志留存条款为《网络安全法》第二十一条 | 2026-01-01 起移至第二十三条（内容未改） |

### 三处代际过时

| # | 原文 | 现状 |
|---|---|---|
| 7 | 主力推荐 Qwen3 / DeepSeek-R1 | Qwen 已到 3.8（2026-08）、DeepSeek 已到 V4/V4.1（2026-04 起） |
| 8 | vLLM 默认占 90% 显存 | 旧版 0.9；当前主线 0.92，extensible KV cache 时 1.0 |
| 9 | 「8192 足够」（未提默认值） | Ollama `num_ctx` 默认 4096，不显式设置会静默截断 |

### 六处需加限定

Qwen 系列许可（Max 闭源）、DeepSeek 许可（原始 V3 权重例外）、Gemma 许可（Gemma 4 已转 Apache-2.0）、`.bin` 风险（torch 2.6 起 `weights_only=True` 默认）、GGUF 安全（解析器仍有 RCE 级漏洞）、「日千万级自建划算」（同档对比平衡点在 2000 万/日 量级）。

### 仍然成立的判断

显存三段式结构、MoE 按总参数算、上下文与并发共享 KV 池、检索质量优先于模型大小、网关是总闸、检索层权限过滤、POC→试点→生产三阶段、以及「私有化买的是可控而非便宜」。
