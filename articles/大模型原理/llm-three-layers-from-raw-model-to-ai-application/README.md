### 为什么是深色底

`scripts/svg-to-png.mjs` 硬编码 `background: '#FFFFFF'`，而这 8 张图沿用同仓库另一篇发布稿（[`articles/agent-harness/`](../../agent-harness/agent-harness-from-analogy-to-12-components/README.md)）的**深色色板**（底 `#111721`，文字 `#dfe6ee` / `#93a1b1`，蓝 `#4dabf7`、青 `#2dd4a7`、橙 `#e8a34b`、红 `#f0655f`）——**文字全部是浅色**。所以每张 SVG 的第一行（`<defs>` 之前）必须是满幅底矩形，否则直接渲染会得到「浅字白底」，在掘金 / CSDN 的浅色页面上完全不可读。

选择深色底而非白底，是为了让两篇发布稿的配图**视觉上成为一个系列**。

### 图号：做进图片里，不靠 HTML

每张图底部有一行**居中的「图 N」**，直接写在 SVG 里（`y = H-11`），内容不侵入底部 34px 区域。理由见上层 [`articles/README.md`](../../README.md) 的统一约定第 3 条。

### 一处需要留意的图内几何

图 9 是**泳道时序图**，三处几何约束：① 三列只画**表头芯片**，列位置由虚线生命线延续——不要恢复成整列大框（旧版就是大框，泳道内大片空白）；② 两轮往返用背景带分组，带标题是**小药丸**，pill 必须画在生命线**之上**，否则文字会压在虚线上；③ 六步编号写在标签文字里（`① …`），**不要再做成独立圆圈**——④ 那条虚线箭头只有 52px，加圆圈必被盖住。④ 的方块刻意放在两条带**之间**、且在 AI 应用泳道之外，表示「它不属于任何一轮的网络往返」。

图 8 的中央方块**跨两排**，上排与下排的箭头都与各自那一行垂直居中对齐。早期版本把方块放在两排之间居中，导致上排箭头起点落在空气里——**改版式时保持「方块跨两排」**。
