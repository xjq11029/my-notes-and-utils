# ZooKeeper - 综合场景串联

---

## 场景一：用ZooKeeper实现分布式锁

### 场景描述

某电商系统需要在分布式环境下实现库存扣减的互斥访问。要求支持公平锁（先到先得）、锁超时自动释放、高可用（集群故障时锁不丢失）。

### 涉及知识点

- [ZooKeeper核心原理](./01-Zookeeper核心原理.md)：ZNode四种类型、Watcher机制、会话机制、临时节点生命周期
- [ZooKeeper集群与应用场景](./02-Zookeeper集群与应用场景.md)：过半机制、分布式锁实现、Leader选举、Curator框架

### 协作流程

**ZAB 协议写入流程图：**

```mermaid
%%{init: {'themeVariables': {'fontSize': '16px'}}}%%
flowchart LR
    A["Leader 接收写请求"] --> B["Leader 生成 Proposal 并广播"]
    B --> C["Follower 接收 Proposal 并写入本地日志"]
    C --> D["Follower 返回 ACK 确认"]
    D --> E["Leader 收到过半 ACK 后提交"]
    E --> F["Leader 广播 Commit 消息，事务完成"]
```

> ZAB 协议是 ZooKeeper 实现分布式一致性的核心。Leader 将写请求封装为 Proposal 广播给所有 Follower，Follower 确认后返回 ACK，Leader 收到过半 ACK 后提交事务并广播 Commit 消息，保证数据一致性。

1. **锁路径设计**：在ZooKeeper中创建锁根路径`/locks/inventory/{productId}/`，所有竞争该商品库存的客户端在此路径下操作。
2. **公平锁竞争**：每个客户端在锁路径下创建临时有序节点（EPHEMERAL_SEQUENTIAL），如`/locks/inventory/product-100/_c_0000000001`。Curator的InterProcessSemaphoreMutex自动处理。
3. **获取锁判定**：客户端获取锁路径下所有子节点并按序号排序。序号最小的节点对应的客户端获得锁，开始执行库存扣减。
4. **等待排队**：未获得锁的客户端注册Watcher监听序号比自己小一位的节点。前一个节点删除（释放锁）时，Watcher触发通知，下一个客户端自动获取锁。此机制保证先到先得，无惊群效应。
5. **锁释放**：正常释放时客户端主动删除自己的临时节点。异常释放时（客户端宕机或网络中断），会话超时后临时节点自动删除，锁自动释放，避免死锁。
6. **高可用保障**：ZooKeeper集群5节点部署，基于过半机制容忍2个节点故障。临时节点与会话绑定，即使Leader切换也不影响已有锁。连接字符串配置所有节点地址。

### 关键要点

- 使用临时节点实现锁，确保会话超时自动释放
- 使用临时有序节点实现公平锁，避免惊群效应
- 连接字符串包含所有集群节点，利用高可用特性
- 使用Curator框架的InterProcessSemaphoreMutex（公平锁）或InterProcessMutex（排他锁）
- 合理设置sessionTimeout（10-30秒），平衡故障检测速度和网络抖动容错
- 使用ConnectionStateListener监听连接状态，LOST/SUSPENDED时暂停协调操作

## 场景二：ZooKeeper作为配置中心

### 场景描述

某微服务系统有20+个服务实例，需要实现配置集中管理。要求配置变更实时推送、支持配置回滚、配置变更审计、对业务代码侵入小。

### 涉及知识点

- [ZooKeeper核心原理](./01-Zookeeper核心原理.md)：Watcher机制、Curator框架、NodeCache/TreeCache
- [ZooKeeper集群与应用场景](./02-Zookeeper集群与应用场景.md)：配置中心架构、过半机制、集群部署

### 协作流程

1. **配置存储结构设计**：在ZooKeeper中建立层级配置路径——`/config/common/`存放公共配置（所有服务共享），`/config/{serviceName}/`存放服务专属配置（覆盖公共配置），`/config/history/`存放历史版本（持久有序节点），`/config/audit/`存放审计日志（带时间戳节点）。
2. **配置集中管理**：配置管理后台将配置写入ZooKeeper对应节点。每个配置项作为一个ZNode，数据为配置值。公共配置与服务专属配置冲突时，服务专属配置优先。
3. **实时推送**：各服务实例通过Curator的TreeCache监听整个`/config`子树。任何配置节点数据变更时，TreeCache自动触发回调通知所有监听实例。实例更新本地ConcurrentHashMap缓存，并触发对应刷新逻辑（如DataSource重建、Redis连接重建）。
4. **配置回滚**：每次配置变更时在`/config/history/{path}/`下创建持久有序节点保存历史版本。需要回滚时读取指定版本数据，重新发布到配置节点，TreeCache自动通知所有实例刷新。
5. **审计日志**：每次配置变更在`/config/audit/`下创建带时间戳的节点，记录操作路径、操作人和时间，便于审计追溯。
6. **低侵入设计**：业务代码只需注入ConfigCenter并通过getConfig()读取配置，或通过addListener()注册变更回调，不需要修改业务逻辑。

### 关键要点

- 使用TreeCache替代多个独立Watcher，减少Watcher数量和通知风暴风险
- 配置数据存储在ZNode中，单个配置不超过1MB，ZNode只存配置元数据而非大数据
- 合理设置sessionTimeout（10-30秒），避免网络抖动导致频繁重连重建缓存
- 配置回滚依赖持久有序节点的历史版本存储，确保回滚路径可追溯
- 与Nacos/Apollo相比，ZooKeeper无内置管理界面，适合已有ZK集群的轻量场景
- 生产环境开启autopurge自动清理，防止审计日志和历史版本耗尽磁盘

### 步骤二：Curator 框架客户端初始化

```java
// src/main/java/com/example/zk/config/ZkClientConfig.java
package com.example.zk.config;

import lombok.extern.slf4j.Slf4j;
import org.apache.curator.framework.CuratorFramework;
import org.apache.curator.framework.CuratorFrameworkFactory;
import org.apache.curator.framework.state.ConnectionState;
import org.apache.curator.retry.ExponentialBackoffRetry;

/**
 * ZooKeeper 客户端配置（基于 Curator 框架）
 */
@Slf4j
public class ZkClientConfig {

    /**
     * ZooKeeper 集群连接地址（多个节点用逗号分隔）
     */
    private static final String ZK_CONNECT_STRING =
            "192.168.1.10:2181,192.168.1.11:2181,192.168.1.12:2181,"
          + "192.168.1.13:2181,192.168.1.14:2181";

    /**
     * 会话超时时间（毫秒）
     * 建议 10-30 秒，平衡故障检测速度和网络抖动容错
     */
    private static final int SESSION_TIMEOUT_MS = 30000;

    /**
     * 连接超时时间（毫秒）
     */
    private static final int CONNECTION_TIMEOUT_MS = 15000;

    /**
     * 命名空间：所有操作路径的前缀，隔离不同应用
     */
    private static final String NAMESPACE = "ecommerce";

    private static volatile CuratorFramework client;

    /**
     * 获取 CuratorFramework 客户端（单例，双重检查锁定）
     */
    public static CuratorFramework getClient() {
        if (client == null) {
            synchronized (ZkClientConfig.class) {
                if (client == null) {
                    client = buildClient();
                }
            }
        }
        return client;
    }

    private static CuratorFramework buildClient() {
        // 重试策略：指数退避，初始间隔 1000ms，最多重试 3 次
        ExponentialBackoffRetry retryPolicy =
                new ExponentialBackoffRetry(1000, 3);

        CuratorFramework curatorClient = CuratorFrameworkFactory.builder()
                .connectString(ZK_CONNECT_STRING)
                .sessionTimeoutMs(SESSION_TIMEOUT_MS)
                .connectionTimeoutMs(CONNECTION_TIMEOUT_MS)
                .retryPolicy(retryPolicy)
                .namespace(NAMESPACE)          // 命名空间隔离
                .build();

        // 注册连接状态监听器
        curatorClient.getConnectionStateListenable().addListener(
                (curatorFramework, newState) -> {
                    switch (newState) {
                        case CONNECTED:
                            log.info("ZooKeeper 连接成功，会话已建立");
                            break;
                        case RECONNECTED:
                            log.info("ZooKeeper 重新连接成功");
                            // 重新注册临时节点和 Watcher
                            break;
                        case SUSPENDED:
                            log.warn("ZooKeeper 连接挂起（网络抖动或 GC 暂停）");
                            // 暂停所有依赖 ZK 的操作，等待恢复
                            break;
                        case LOST:
                            log.error("ZooKeeper 会话丢失，需要重新创建会话");
                            // 会话丢失时临时节点会被删除，锁会自动释放
                            break;
                        case READ_ONLY:
                            log.warn("ZooKeeper 只读模式（集群过半节点不可用）");
                            break;
                    }
                });

        // 启动客户端
        curatorClient.start();
        log.info("Curator 客户端启动完成，连接地址: {}", ZK_CONNECT_STRING);
        return curatorClient;
    }
}
```

### 步骤三：分布式锁 - 库存扣减服务

```java
// src/main/java/com/example/zk/lock/InventoryService.java
package com.example.zk.lock;

import com.example.zk.config.ZkClientConfig;
import lombok.extern.slf4j.Slf4j;
import org.apache.curator.framework.CuratorFramework;
import org.apache.curator.framework.recipes.locks.InterProcessMutex;

import java.util.concurrent.TimeUnit;

/**
 * 库存扣减服务 - 使用 Curator 分布式锁保证互斥访问
 */
@Slf4j
public class InventoryService {

    private final CuratorFramework client;

    /**
     * 锁根路径：所有库存锁的父节点
     */
    private static final String LOCK_ROOT_PATH = "/locks/inventory";

    public InventoryService() {
        this.client = ZkClientConfig.getClient();
    }

    /**
     * 扣减商品库存（带分布式锁保护）
     *
     * @param productId 商品 ID
     * @param quantity  扣减数量
     * @return true 扣减成功，false 扣减失败
     */
    public boolean reduceStock(String productId, int quantity) {
        // 构造锁路径：/locks/inventory/{productId}
        String lockPath = LOCK_ROOT_PATH + "/" + productId;
        // 创建可重入排他锁（InterProcessMutex 基于临时节点 + Watcher 实现）
        InterProcessMutex lock = new InterProcessMutex(client, lockPath);

        try {
            // 尝试获取锁，最多等待 5 秒
            boolean acquired = lock.acquire(5, TimeUnit.SECONDS);
            if (!acquired) {
                log.warn("获取分布式锁超时，商品ID: {}, 锁路径: {}", productId, lockPath);
                return false;
            }

            log.info("成功获取分布式锁，商品ID: {}, 锁路径: {}", productId, lockPath);

            // ===== 临界区：执行库存扣减 =====
            try {
                // 1. 查询当前库存
                int currentStock = queryStockFromDB(productId);
                log.info("当前库存: {}, 商品ID: {}", currentStock, productId);

                // 2. 校验库存是否充足
                if (currentStock < quantity) {
                    log.warn("库存不足，商品ID: {}, 当前库存: {}, 需要: {}",
                            productId, currentStock, quantity);
                    return false;
                }

                // 3. 扣减库存
                int newStock = currentStock - quantity;
                updateStockToDB(productId, newStock);
                log.info("库存扣减成功，商品ID: {}, 扣减: {}, 剩余: {}",
                        productId, quantity, newStock);
                return true;

            } finally {
                // 4. 无论成功与否，释放锁
                lock.release();
                log.info("分布式锁已释放，商品ID: {}", productId);
            }

        } catch (Exception e) {
            log.error("库存扣减异常，商品ID: {}", productId, e);
            // 锁会在 finally 中释放（如果已获取）
            return false;
        }
    }

    // ===== 模拟数据库操作 =====
    private int queryStockFromDB(String productId) {
        // 实际应从数据库查询
        return 100;
    }

    private void updateStockToDB(String productId, int newStock) {
        // 实际应更新数据库
        log.debug("更新数据库库存: productId={}, newStock={}", productId, newStock);
    }
}
```

```java
// src/main/java/com/example/zk/lock/InventoryConcurrencyTest.java
package com.example.zk.lock;

import com.example.zk.config.ZkClientConfig;
import lombok.extern.slf4j.Slf4j;

import java.util.concurrent.CountDownLatch;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * 分布式锁并发测试：模拟 100 个线程同时扣减同一商品库存
 */
@Slf4j
public class InventoryConcurrencyTest {

    private static final int THREAD_COUNT = 100;
    private static final String PRODUCT_ID = "product-100";

    public static void main(String[] args) throws Exception {
        // 确保 ZK 客户端已启动
        ZkClientConfig.getClient();

        InventoryService inventoryService = new InventoryService();
        ExecutorService executor = Executors.newFixedThreadPool(20);
        CountDownLatch latch = new CountDownLatch(THREAD_COUNT);
        AtomicInteger successCount = new AtomicInteger(0);
        AtomicInteger failCount = new AtomicInteger(0);

        log.info("===== 开始分布式锁并发测试，线程数: {} =====", THREAD_COUNT);

        long startTime = System.currentTimeMillis();

        for (int i = 0; i < THREAD_COUNT; i++) {
            final int threadIndex = i;
            executor.submit(() -> {
                try {
                    boolean result = inventoryService.reduceStock(PRODUCT_ID, 1);
                    if (result) {
                        successCount.incrementAndGet();
                        log.info("线程-{} 扣减成功", threadIndex);
                    } else {
                        failCount.incrementAndGet();
                        log.info("线程-{} 扣减失败（库存不足或超时）", threadIndex);
                    }
                } finally {
                    latch.countDown();
                }
            });
        }

        latch.await();
        executor.shutdown();
        long elapsed = System.currentTimeMillis() - startTime;

        log.info("===== 测试完成 =====");
        log.info("总耗时: {}ms", elapsed);
        log.info("成功次数: {}", successCount.get());
        log.info("失败次数: {}", failCount.get());
        log.info("平均每次耗时: {}ms", elapsed / (double) THREAD_COUNT);
    }
}
```

### 步骤五：配置中心 - 核心实现

```java
// src/main/java/com/example/zk/config/ConfigCenter.java
package com.example.zk.config;

import lombok.extern.slf4j.Slf4j;
import org.apache.curator.framework.CuratorFramework;
import org.apache.curator.framework.recipes.cache.ChildData;
import org.apache.curator.framework.recipes.cache.TreeCache;
import org.apache.curator.framework.recipes.cache.TreeCacheListener;
import org.apache.zookeeper.CreateMode;

import java.nio.charset.StandardCharsets;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.function.Consumer;

/**
 * 基于 ZooKeeper 的配置中心实现
 * 使用 TreeCache 监听整个配置子树，实现配置实时推送
 */
@Slf4j
public class ConfigCenter {

    private final CuratorFramework client;

    /**
     * 配置根路径
     */
    private static final String CONFIG_ROOT = "/config";

    /**
     * 本地配置缓存（ConcurrentHashMap 保证线程安全）
     */
    private final Map<String, String> configCache = new ConcurrentHashMap<>();

    /**
     * 配置变更回调注册表
     */
    private final Map<String, Consumer<String>> listeners = new ConcurrentHashMap<>();

    /**
     * TreeCache 实例，监听整个配置子树
     */
    private TreeCache treeCache;

    public ConfigCenter() {
        this.client = ZkClientConfig.getClient();
    }

    /**
     * 初始化配置中心，启动 TreeCache 监听
     */
    public void init() throws Exception {
        // 确保配置根节点存在
        if (client.checkExists().forPath(CONFIG_ROOT) == null) {
            client.create()
                    .creatingParentsIfNeeded()
                    .withMode(CreateMode.PERSISTENT)
                    .forPath(CONFIG_ROOT);
            log.info("配置根节点已创建: {}", CONFIG_ROOT);
        }

        // 启动 TreeCache 监听整个配置子树
        treeCache = new TreeCache(client, CONFIG_ROOT);
        treeCache.getListenable().addListener(createTreeCacheListener());
        treeCache.start();
        log.info("TreeCache 启动完成，监听路径: {}", CONFIG_ROOT);
    }

    /**
     * 创建 TreeCache 监听器
     */
    private TreeCacheListener createTreeCacheListener() {
        return (curatorClient, event) -> {
            ChildData data = event.getData();
            if (data == null) {
                return;
            }

            String path = data.getPath();
            String value = new String(data.getData(), StandardCharsets.UTF_8);

            switch (event.getType()) {
                case NODE_ADDED:
                    log.info("配置新增: {} = {}", path, value);
                    configCache.put(path, value);
                    notifyListeners(path, value);
                    break;

                case NODE_UPDATED:
                    log.info("配置更新: {} = {}", path, value);
                    configCache.put(path, value);
                    notifyListeners(path, value);
                    break;

                case NODE_REMOVED:
                    log.info("配置删除: {}", path);
                    configCache.remove(path);
                    notifyListeners(path, null);
                    break;

                case INITIALIZED:
                    log.info("TreeCache 初始化完成，当前配置数量: {}",
                            configCache.size());
                    break;

                default:
                    break;
            }
        };
    }

    /**
     * 获取配置值
     *
     * @param key          配置键（相对于配置根路径的路径）
     * @param defaultValue 默认值
     * @return 配置值
     */
    public String getConfig(String key, String defaultValue) {
        String path = CONFIG_ROOT + "/" + key;
        String value = configCache.get(path);
        return value != null ? value : defaultValue;
    }

    /**
     * 获取配置值（整数类型）
     */
    public int getIntConfig(String key, int defaultValue) {
        String value = getConfig(key, String.valueOf(defaultValue));
        try {
            return Integer.parseInt(value);
        } catch (NumberFormatException e) {
            log.warn("配置值不是整数，key: {}, value: {}", key, value);
            return defaultValue;
        }
    }

    /**
     * 获取配置值（布尔类型）
     */
    public boolean getBooleanConfig(String key, boolean defaultValue) {
        String value = getConfig(key, String.valueOf(defaultValue));
        return Boolean.parseBoolean(value);
    }

    /**
     * 更新配置（写入 ZooKeeper）
     */
    public void setConfig(String key, String value) throws Exception {
        String path = CONFIG_ROOT + "/" + key;

        // 确保父节点存在
        if (client.checkExists().forPath(path) == null) {
            client.create()
                    .creatingParentsIfNeeded()
                    .withMode(CreateMode.PERSISTENT)
                    .forPath(path, value.getBytes(StandardCharsets.UTF_8));
        } else {
            client.setData().forPath(path, value.getBytes(StandardCharsets.UTF_8));
        }

        log.info("配置已更新: {} = {}", path, value);
    }

    /**
     * 注册配置变更回调
     *
     * @param key     配置键
     * @param listener 回调函数
     */
    public void addListener(String key, Consumer<String> listener) {
        String path = CONFIG_ROOT + "/" + key;
        listeners.put(path, listener);
        log.info("配置变更监听已注册: {}", path);
    }

    /**
     * 通知所有匹配的监听器
     */
    private void notifyListeners(String path, String newValue) {
        Consumer<String> listener = listeners.get(path);
        if (listener != null) {
            try {
                listener.accept(newValue);
            } catch (Exception e) {
                log.error("配置变更通知异常，path: {}", path, e);
            }
        }
    }

    /**
     * 获取所有配置（调试用）
     */
    public Map<String, String> getAllConfigs() {
        return new ConcurrentHashMap<>(configCache);
    }

    /**
     * 关闭配置中心
     */
    public void close() {
        if (treeCache != null) {
            treeCache.close();
            log.info("TreeCache 已关闭");
        }
    }
}
```

### 步骤六：配置中心 - 使用示例

```java
// src/main/java/com/example/zk/config/ConfigCenterDemo.java
package com.example.zk.config;

import lombok.extern.slf4j.Slf4j;

/**
 * 配置中心使用示例
 */
@Slf4j
public class ConfigCenterDemo {

    private static ConfigCenter configCenter;

    public static void main(String[] args) throws Exception {
        // 1. 确保 ZK 客户端已启动
        ZkClientConfig.getClient();

        // 2. 初始化配置中心
        configCenter = new ConfigCenter();
        configCenter.init();

        // 3. 写入初始配置
        initConfigs();

        // 4. 注册配置变更回调
        registerListeners();

        // 5. 读取配置
        readConfigs();

        // 6. 模拟配置动态变更
        simulateConfigChange();

        // 保持运行，观察配置变更
        Thread.sleep(60000);
        configCenter.close();
    }

    private static void initConfigs() throws Exception {
        // 公共配置
        configCenter.setConfig("common/db.url", "jdbc:mysql://127.0.0.1:3306/ecommerce");
        configCenter.setConfig("common/db.maxPoolSize", "20");
        configCenter.setConfig("common/redis.host", "127.0.0.1");
        configCenter.setConfig("common/redis.port", "6379");

        // 订单服务专属配置
        configCenter.setConfig("order-service/timeout-minutes", "30");
        configCenter.setConfig("order-service/max-unpaid-orders", "5");
        configCenter.setConfig("order-service/pre-stock-deduction", "true");

        // 用户服务专属配置
        configCenter.setConfig("user-service/session-timeout", "3600");
        configCenter.setConfig("user-service/max-login-attempts", "5");

        log.info("初始配置写入完成");
    }

    private static void registerListeners() {
        // 监听数据库连接池配置变更，实时重建连接池
        configCenter.addListener("common/db.maxPoolSize", newValue -> {
            log.info("数据库连接池大小变更: {} -> 正在重建连接池...", newValue);
            // 实际业务逻辑：重建 HikariCP / Druid 连接池
        });

        // 监听 Redis 配置变更
        configCenter.addListener("common/redis.host", newValue -> {
            log.info("Redis 主机地址变更: {} -> 正在重建 Redis 连接...", newValue);
            // 实际业务逻辑：重建 Jedis / Lettuce 连接
        });

        // 监听订单超时配置变更
        configCenter.addListener("order-service/timeout-minutes", newValue -> {
            log.info("订单超时时间变更: {} 分钟 -> 已生效", newValue);
            // 实际业务逻辑：更新定时任务调度时间
        });
    }

    private static void readConfigs() {
        // 读取配置，带默认值
        String dbUrl = configCenter.getConfig("common/db.url", "jdbc:mysql://localhost:3306/default");
        int poolSize = configCenter.getIntConfig("common/db.maxPoolSize", 10);
        boolean preStock = configCenter.getBooleanConfig("order-service/pre-stock-deduction", false);
        int timeout = configCenter.getIntConfig("order-service/timeout-minutes", 30);

        log.info("===== 当前配置 =====");
        log.info("数据库 URL: {}", dbUrl);
        log.info("连接池大小: {}", poolSize);
        log.info("库存预扣: {}", preStock);
        log.info("订单超时: {} 分钟", timeout);
    }

    private static void simulateConfigChange() throws Exception {
        // 模拟在另一个线程中修改配置（模拟配置管理后台操作）
        new Thread(() -> {
            try {
                Thread.sleep(10000);
                log.info("===== 模拟配置变更 =====");
                configCenter.setConfig("order-service/timeout-minutes", "60");
                configCenter.setConfig("common/db.maxPoolSize", "50");
            } catch (Exception e) {
                log.error("配置变更失败", e);
            }
        }).start();
    }
}
```
