## 场景一：实现商品搜索服务

### 场景描述
构建一个电商平台的商品搜索服务，支持关键词全文检索、分类筛选、价格区间过滤、品牌聚合、销量排序、关键词高亮和分页功能。

### 涉及知识点
- [ES核心原理](01-ES核心原理.md)：倒排索引、分词器、分片机制、索引设计
- [ES查询与聚合分析](02-ES查询与聚合分析.md)：bool 组合查询、聚合分析、排序分页、高亮显示

```mermaid
%%{init: {'themeVariables': {'fontSize': '16px'}}}%%
flowchart LR
    A["文档写入请求"] --> B["内存索引缓冲区（Buffer）"]
    B --> C["Refresh（默认 1s）生成 Segment"]
    C --> D["Segment 可搜索（文件系统缓存）"]
    D --> E["Flush（默认 30min）持久化到磁盘"]
    E --> F["清空 Translog，数据安全落盘"]
```

> ES 文档写入首先进入内存索引缓冲区，通过 Refresh 操作生成 Segment 变为可搜索状态，再通过 Flush 操作将 Segment 持久化到磁盘。Refresh 保证近实时搜索（NRT），Flush 保证数据持久化不丢失。

### 协作流程
1. 设计索引结构：创建 products 索引，配置 5 个主分片和 1 个副本
2. 配置字段映射：name 使用 ik_max_word 索引分词器和 ik_smart 搜索分词器，category/brand 使用 keyword，price 使用 double
3. 通过 Canal 或 Logstash 将 MySQL 商品数据同步到 ES
4. 构建搜索 DSL：multi_match 在 name 和 description 字段中搜索关键词
5. 使用 bool 组合查询：filter 子句筛选 category、brand、price 区间
6. 添加聚合分析：terms 聚合统计品牌分布，range 聚合统计价格区间
7. 配置排序：按销量降序和相关性评分排序
8. 添加高亮：highlight 对 name 字段进行高亮显示
9. 使用 search_after 实现深度分页，避免 from/size 性能问题
10. 通过索引别名实现零停机索引重建

### 关键要点
- 全文搜索用 must，精确筛选用 filter（不计算评分且自动缓存）
- 聚合字段必须使用 keyword 类型，不能使用 text 类型
- 先 filter 缩小范围再聚合，减少计算量
- 搜索时设置 size:0 只返回聚合结果不返回文档
- 深度分页使用 search_after 替代 from/size

## 场景二：分布式日志分析系统架构

### 场景描述
构建日均 100GB 日志的实时收集、存储、分析系统，支持按时间范围检索、按服务级别聚合统计、错误率监控和告警。

### 涉及知识点
- [ES核心原理](01-ES核心原理.md)：索引模板、ILM 生命周期管理、Refresh 机制
- [ES查询与聚合分析](02-ES查询与聚合分析.md)：date_histogram 聚合、filter 聚合、索引别名

### 协作流程
1. 采集层：Filebeat 部署在各服务器上，采集日志并发送到 Kafka
2. 缓冲层：Kafka 按日志类型创建 Topic，分区 30-50，LZ4 压缩
3. 消费层：Logstash 或 Flink 消费 Kafka 消息，解析清洗后写入 ES
4. 存储层：ES 按天滚动创建索引（logs-YYYY-MM-DD），使用索引模板统一配置
5. 索引模板配置：3 个主分片 1 个副本，refresh_interval 设为 30s（批量写入场景）
6. ILM 生命周期管理：Hot 阶段（0-2 天）高写入；Warm 阶段（2-7 天）只读合并；Cold 阶段（7-30 天）副本数 0；Delete 阶段（30 天后）自动删除
7. 查询方案：按时间范围指定索引或通配符，date_histogram 按小时聚合日志量，filter 聚合统计错误率
8. 可视化：Grafana 大盘展示日志趋势，Kibana 检索详细日志
9. 告警：ElastAlert 或 Grafana 告警规则，错误率超过阈值时钉钉/短信通知

### 关键要点
- 按天滚动索引避免单索引过大，便于按时间范围管理和删除
- 批量写入时增大 refresh_interval 减少 Segment 数量，提升写入性能
- 日志查询始终指定时间范围，利用索引名裁剪减少扫描
- date_histogram 聚合时显式设置时区 time_zone: "+08:00"
- 冷数据降低副本数节省存储成本

## 完整可运行示例代码

以下是一个基于 Elasticsearch 的完整商品搜索系统示例，涵盖索引创建、数据导入、搜索查询和聚合分析。

### 步骤一：环境准备 - Docker Compose

```yaml
# docker-compose.yml
version: '3.8'
services:
  elasticsearch:
    image: docker.elastic.co/elasticsearch/elasticsearch:8.17.0
    container_name: es-node
    environment:
      - discovery.type=single-node
      - "ES_JAVA_OPTS=-Xms1g -Xmx1g"
      - xpack.security.enabled=false
      - xpack.monitoring.enabled=true
    ports:
      - "9200:9200"
      - "9300:9300"
    volumes:
      - es-data:/usr/share/elasticsearch/data
      - ./plugins/ik:/usr/share/elasticsearch/plugins/ik
    networks:
      - es-network

  kibana:
    image: docker.elastic.co/kibana/kibana:8.17.0
    container_name: kibana
    ports:
      - "5601:5601"
    environment:
      - ELASTICSEARCH_HOSTS=http://elasticsearch:9200
    depends_on:
      - elasticsearch
    networks:
      - es-network

volumes:
  es-data:

networks:
  es-network:
    driver: bridge
```

### 步骤四：关键词搜索 - 多字段匹配

```bash
# ===== 场景 1: 基础关键词搜索 =====
# 搜索"手机"，在 name 和 description 字段中匹配
POST /products/_search
{
  "query": {
    "multi_match": {
      "query": "手机",
      "fields": ["name^3", "description^1"],
      "type": "best_fields",
      "operator": "or"
    }
  },
  "highlight": {
    "pre_tags": ["<em>"],
    "post_tags": ["</em>"],
    "fields": {
      "name": {
        "fragment_size": 100,
        "number_of_fragments": 1
      },
      "description": {
        "fragment_size": 100,
        "number_of_fragments": 1
      }
    }
  },
  "_source": ["id", "name", "price", "brand", "sales", "rating"],
  "size": 10
}

# ===== 场景 2: 复杂组合搜索 =====
# 搜索条件：关键词"小米" + 分类"手机" + 价格区间 3000-6000 + 品牌"小米"
POST /products/_search
{
  "query": {
    "bool": {
      "must": [
        {
          "multi_match": {
            "query": "小米",
            "fields": ["name^3", "brand", "description"]
          }
        }
      ],
      "filter": [
        { "term": { "category_name": "手机" } },
        { "range": { "price": { "gte": 3000, "lte": 6000 } } },
        { "term": { "brand": "小米" } },
        { "term": { "is_on_sale": true } }
      ]
    }
  },
  "sort": [
    { "sales": { "order": "desc" } },
    { "_score": { "order": "desc" } }
  ],
  "highlight": {
    "pre_tags": ["<em>"],
    "post_tags": ["</em>"],
    "fields": {
      "name": {},
      "description": {}
    }
  },
  "_source": ["id", "name", "price", "original_price", "brand", "sales", "rating"],
  "from": 0,
  "size": 20
}

# ===== 场景 3: 拼音搜索（搜索 "xiaomi" 也能匹配小米） =====
POST /products/_search
{

      "query": "xiaomi",
      "fields": ["name.pinyin", "brand"]
    }
  },
  "_source": ["id", "name", "price", "brand"],
  "size": 10
}
```

```bash

    "match_all": {}
```

### 步骤六：深度分页 - search_after 实现

```bash
# search_after 替代 from/size 实现深度分页
# 第一步：获取首页数据 + 排序字段值
POST /products/_search
{
  "query": {
    "match_all": {}
  },
  "sort": [
    { "sales": "desc" },
    { "id": "asc" }
  ],
  "_source": ["id", "name", "price", "sales"],
  "size": 5
}

# 第二步：使用第一步最后一个结果的 sort 值作为 search_after 参数
# 假设第一步最后一个结果的 sort 值为 [12000, 7]
POST /products/_search
{
  "query": {
    "match_all": {}
  },
  "sort": [
    { "sales": "desc" },
    { "id": "asc" }
  ],
  "_source": ["id", "name", "price", "sales"],
  "size": 5,
  "search_after": [12000, 7]
}
```

```java
// ProductSearchService.java - 搜索服务
package com.example.es.service;

import com.example.es.entity.ProductDocument;
import lombok.RequiredArgsConstructor;
import org.elasticsearch.index.query.BoolQueryBuilder;
import org.elasticsearch.index.query.MultiMatchQueryBuilder;
import org.elasticsearch.index.query.QueryBuilders;
import org.elasticsearch.search.aggregations.AggregationBuilders;
import org.elasticsearch.search.aggregations.bucket.terms.TermsAggregationBuilder;
import org.elasticsearch.search.fetch.subphase.highlight.HighlightBuilder;
import org.springframework.data.domain.PageRequest;
import org.springframework.data.elasticsearch.core.*;
import org.springframework.data.elasticsearch.core.query.NativeSearchQuery;
import org.springframework.data.elasticsearch.core.query.NativeSearchQueryBuilder;
import org.springframework.stereotype.Service;

import java.util.List;
import java.util.stream.Collectors;

@Service
@RequiredArgsConstructor
public class ProductSearchService {

    private final ElasticsearchRestTemplate elasticsearchRestTemplate;

    /**
     * 综合搜索：关键词 + 分类筛选 + 价格区间 + 品牌 + 排序
     */
    public SearchHits<ProductDocument> search(String keyword, String category,
                                               Double minPrice, Double maxPrice,
                                               String brand, int page, int size) {
        NativeSearchQueryBuilder queryBuilder = new NativeSearchQueryBuilder();

        // 构建 Bool 查询
        BoolQueryBuilder boolQuery = QueryBuilders.boolQuery();

        // 关键词搜索（must：参与评分）
        if (keyword != null && !keyword.isEmpty()) {
            MultiMatchQueryBuilder multiMatch = QueryBuilders.multiMatchQuery(keyword)
                    .field("name", 3.0f)
                    .field("description", 1.0f)
                    .type(MultiMatchQueryBuilder.Type.BEST_FIELDS);
            boolQuery.must(multiMatch);
        }

        // 精确筛选（filter：不参与评分，自动缓存）
        if (category != null && !category.isEmpty()) {
            boolQuery.filter(QueryBuilders.termQuery("category_name", category));
        }
        if (brand != null && !brand.isEmpty()) {
            boolQuery.filter(QueryBuilders.termQuery("brand", brand));
        }
        if (minPrice != null || maxPrice != null) {
            boolQuery.filter(QueryBuilders.rangeQuery("price")
                    .gte(minPrice != null ? minPrice : 0)
                    .lte(maxPrice != null ? maxPrice : Double.MAX_VALUE));
        }

        queryBuilder.withQuery(boolQuery);

        // 高亮
        HighlightBuilder highlightBuilder = new HighlightBuilder();
        highlightBuilder.field("name", 100, 1)
                .field("description", 100, 1)
                .preTags("<em>")
                .postTags("</em>");
        queryBuilder.withHighlightBuilder(highlightBuilder);

        // 分页
        queryBuilder.withPageable(PageRequest.of(page, size));

        // 聚合：品牌分布
        TermsAggregationBuilder brandAgg = AggregationBuilders
                .terms("brand_distribution").field("brand").size(20);
        queryBuilder.withAggregations(brandAgg);

        NativeSearchQuery searchQuery = queryBuilder.build();
        return elasticsearchRestTemplate.search(searchQuery, ProductDocument.class);
    }
}
```
