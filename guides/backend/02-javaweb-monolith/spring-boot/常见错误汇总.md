# Spring Boot - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南章节提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| AOP 同类方法调用 @Transactional 等注解不生效 | this.method() 直接调用不走代理对象，AOP 拦截不到 | 拆分为两个 Service；通过 AopContext.currentProxy() 获取代理；自己注入自己（@Autowired + @Lazy） | [Spring IoC 与 AOP 深度](./01-Spring-IoC与AOP深度.md) |
| @Transactional 事务不回滚 | 方法非 public（AOP 只代理 public 方法）；同类方法调用；异常被 catch 未抛出；数据库引擎不支持事务；注解在接口上（CGLIB 代理）；多线程不共享事务 | 确保方法为 public；异常必须抛出到代理层；使用支持事务的引擎；注解放在实现类上 | [Spring IoC 与 AOP 深度](./01-Spring-IoC与AOP深度.md) |
| Prototype Bean 注入到 Singleton Bean 始终是同一个实例 | Singleton Bean 只创建一次，注入的 Prototype Bean 也只会创建一次 | 使用 ObjectFactory 延迟获取；使用 @Lookup 注解方法注入 | [Spring IoC 与 AOP 深度](./01-Spring-IoC与AOP深度.md) |
| 自定义自动配置不生效 | Spring Boot 只扫描主启动类所在包及其子包 | 使用 @Import 手动导入；在 META-INF/spring/*.imports 中注册；将主启动类放在根包下 | [Spring Boot 自动配置原理](./02-Spring-Boot自动配置原理.md) |
| @ConditionalOnBean 导致目标 Bean 不被创建 | 依赖的 Bean 可能还未创建，未控制配置类的加载顺序 | 使用 @AutoConfigureAfter 注解指定配置类加载顺序 | [Spring Boot 自动配置原理](./02-Spring-Boot自动配置原理.md) |
| 多环境配置切换混乱 | 未正确使用 spring.profiles.active 或配置优先级不清晰 | 使用 application-{profile}.yml 分离环境配置，通过 spring.profiles.active 激活 | [Spring Boot 自动配置原理](./02-Spring-Boot自动配置原理.md) |
| @PathVariable 与 URL 占位符不匹配导致接口报错 | @PathVariable 在 URL 中缺少对应 {xxx} 占位符 | 检查 URL 映射是否包含对应占位符，如 @GetMapping("/users/{id}") | [Spring MVC 与 RESTful 设计](./03-SpringMVC与RESTful设计.md) |
| GET 请求使用 @RequestBody 无法获取参数 | GET 请求没有请求体，大多数 HTTP 客户端不支持 GET 请求体 | GET 请求使用 @RequestParam 或 @ModelAttribute 接收参数 | [Spring MVC 与 RESTful 设计](./03-SpringMVC与RESTful设计.md) |
| 统一响应被拦截器重复包装成 Result<Result<T>> | @RestControllerAdvice 的 ResponseBodyAdvice 对所有返回值重复包装 | 在 supports() 方法中判断返回类型是否已经是 Result，避免重复包装 | [Spring MVC 与 RESTful 设计](./03-SpringMVC与RESTful设计.md) |
| JWT 中存储敏感信息导致泄露 | Payload 仅 Base64 编码，非加密 | JWT 只存用户 ID，敏感信息从数据库查 | [登录认证与安全](./04-登录认证与安全.md) |
| Session 默认内存存储导致重启后所有用户需重新登录 | 未配置分布式 Session | 使用 Spring Session + Redis | [登录认证与安全](./04-登录认证与安全.md) |
| CSRF 防护误用于前后端分离场景 | Token 在 Header 中，非 Cookie，前后端分离天然防 CSRF | 前后端分离禁用 CSRF 保护 | [登录认证与安全](./04-登录认证与安全.md) |
| 密码用 MD5 存储被彩虹表破解 | MD5 计算快，无盐值 | 使用 BCrypt 或 Argon2 | [登录认证与安全](./04-登录认证与安全.md) |
| Refresh Token 泄露导致长期被冒用 | 未做服务端失效机制 | Refresh Token 与设备绑定，支持服务端撤销 | [登录认证与安全](./04-登录认证与安全.md) |
| 日志字符串拼接造成性能下降 | 级别不匹配时仍执行字符串拼接 | 使用参数化日志 `log.info("msg {}", arg)` | [日志整合与监控](./07-日志整合与监控.md) |
| 桥接器与适配器共存导致应用启动死循环 | log4j-over-slf4j 和 slf4j-log4j 同时存在 | 只保留桥接器，排除适配器 | [日志整合与监控](./07-日志整合与监控.md) |
| 异步日志队列满导致日志丢失 | AsyncAppender 默认队列满后丢弃 | 调大 queueSize；设 neverBlock=true 明确丢弃策略 | [日志整合与监控](./07-日志整合与监控.md) |
| 日志文件无限增长导致磁盘写满 | 未配置滚动策略 | 使用 RollingFileAppender，设 maxHistory 和 totalSizeCap | [日志整合与监控](./07-日志整合与监控.md) |
| 敏感信息泄露（密码/Token 出现在日志） | 直接打印完整请求/响应 | 日志脱敏处理；使用 @ToString(exclude=...) 排除敏感字段 | [日志整合与监控](./07-日志整合与监控.md) |
| Actuator 端点暴露过多造成安全风险 | include=* 暴露所有端点 | 生产环境只暴露 health,info,prometheus；配合 Spring Security 鉴权 | [日志整合与监控](./07-日志整合与监控.md) |
| 外部配置不生效 | 配置文件位置不对 | 放到 jar 同级 config/ 目录（优先级最高）；或用 --spring.config.location 指定 | [Spring Boot 部署与运维](./08-SpringBoot部署与运维.md) |
| 环境变量不生效 | 环境变量命名格式不对 | 将属性名转为大写下划线：server.port -> SERVER_PORT | [Spring Boot 部署与运维](./08-SpringBoot部署与运维.md) |
| Docker 镜像过大（超过 1GB） | 使用 JDK 而非 JRE 基础镜像 | 使用多阶段构建 + JRE 基础镜像；或使用 jib 插件 | [Spring Boot 部署与运维](./08-SpringBoot部署与运维.md) |
| 优雅停机被强杀导致请求处理中断 | K8s terminationGracePeriodSeconds 小于应用等待时间 | 调大 K8s 宽限期（需大于 timeout-per-shutdown-phase） | [Spring Boot 部署与运维](./08-SpringBoot部署与运维.md) |
| devtools 生产环境生效导致应用频繁重启 | 未排除 devtools 依赖 | 设 optional=true；或 Maven 中设 excludeDevtools | [Spring Boot 部署与运维](./08-SpringBoot部署与运维.md) |
| 日志时间与实际差 8 小时 | JVM 默认时区非东八区 | 启动参数加 -Duser.timezone=Asia/Shanghai；Docker 中设 TZ=Asia/Shanghai | [Spring Boot 部署与运维](./08-SpringBoot部署与运维.md) |
