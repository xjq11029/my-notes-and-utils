# SSM - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南章节提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| AOP 同类方法调用失效，@Transactional 注解不生效 | this.method() 直接调用不走代理对象，切面逻辑被跳过 | 拆分为两个 Service 类；使用 AopContext.currentProxy() 获取代理；自身注入自身（@Autowired + @Lazy） | [Spring核心与IoC原理](./01-Spring核心与IoC原理-导览.md) |
| @Transactional 不回滚，抛异常后数据未回滚 | Spring 默认只回滚 RuntimeException 和 Error，checked 异常不回滚 | 添加 rollbackFor = Exception.class 显式指定回滚异常类型 | [Spring核心与IoC原理](./01-Spring核心与IoC原理-导览.md) |
| 字段注入循环依赖不报错，运行时 NPE | 字段注入（@Autowired 在字段上）允许循环依赖，问题延后到运行时才暴露 | 改用构造器注入，提前发现循环依赖并通过重构解决 | [Spring核心与IoC原理](./01-Spring核心与IoC原理-导览.md) |
| CGLIB 无法代理 final 类，创建 Bean 时报错 | CGLIB 通过生成子类实现代理，final 类不能被继承 | 去掉 final 修饰；改用 JDK 动态代理（让类实现接口） | [Spring核心与IoC原理](./01-Spring核心与IoC原理-导览.md) |
| 多线程事务不共享，子线程中操作不回滚 | 事务绑定 ThreadLocal，线程间不共享事务上下文 | 使用编程式事务传递 TransactionInfo；避免跨线程事务操作 | [Spring核心与IoC原理](./01-Spring核心与IoC原理-导览.md) |
| @RequestBody 读取后请求体为空 | Content-Type 不是 application/json | 前端设置正确的 Content-Type: application/json 请求头 | [SpringMVC执行流程](./02-SpringMVC执行流程-导览.md) |
| 拦截器配置了但不生效 | 拦截器未注册到 WebMvcConfigurer | 实现 WebMvcConfigurer 的 addInterceptors 方法注册拦截器 | [SpringMVC执行流程](./02-SpringMVC执行流程-导览.md) |
| @ExceptionHandler 不生效，异常未被全局异常处理器捕获 | 异常处理器不在 Spring 扫描范围内；Controller 内部 catch 了异常 | 确保异常处理器在扫描路径下；Controller 层不要吞异常，让异常向上抛出 | [SpringMVC执行流程](./02-SpringMVC执行流程-导览.md) |
| 请求 404 但 Controller 有注解 | 包扫描路径不包含 Controller 类 | 检查 @ComponentScan 配置是否包含 Controller 所在包 | [SpringMVC执行流程](./02-SpringMVC执行流程-导览.md) |
| 静态资源被 DispatcherServlet 拦截返回 404 | DispatcherServlet 映射 "/" 拦截了静态资源请求 | 配置 mvc:default-servlet-handler 或 WebMvcConfigurer.configureDefaultServletHandling | [SpringMVC执行流程](./02-SpringMVC执行流程-导览.md) |
| 事务不生效，数据库操作未回滚 | 包扫描未隔离，Controller 被父容器扫描导致事务代理失效 | 父容器排除 Controller 扫描，配置 excludeFilters | [MyBatis整合与配置](./03-MyBatis整合与配置-导览.md) |
| Mapper 注入失败，报 NoSuchBeanDefinitionException | @MapperScan 未配置或 basePackage 路径错误 | 检查 @MapperScan 包路径，确保 Mapper 接口在指定包下 | [MyBatis整合与配置](./03-MyBatis整合与配置-导览.md) |
| Bean 重复创建，启动时有重复 Bean 警告 | 父容器和子容器都扫描了同一个包 | 隔离包扫描：父容器扫 com.example 排除 Controller，子容器只扫 com.example.controller | [MyBatis整合与配置](./03-MyBatis整合与配置-导览.md) |
| DataSource 配置错误导致启动失败 | 数据库 URL、用户名、密码配置错误 | 检查配置文件，确认数据库连接参数正确 | [MyBatis整合与配置](./03-MyBatis整合与配置-导览.md) |
| Mapper XML 找不到，报 Invalid bound statement | mapperLocations 路径配置错误 | 检查 classpath:mapper/*.xml 路径，确保 XML 在 resources/mapper 目录下 | [MyBatis整合与配置](./03-MyBatis整合与配置-导览.md) |
| @Transactional 放在 Controller 层事务失效 | Controller 被父容器扫描时事务代理丢失 | @Transactional 必须放在 Service 层，且 Controller 不被父容器扫描 | [MyBatis整合与配置](./03-MyBatis整合与配置-导览.md) |
