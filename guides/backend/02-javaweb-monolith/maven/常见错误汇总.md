# Maven - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南章节提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 传递依赖版本冲突导致 NoSuchMethodError / NoClassDefFoundError | 多路径引入同一库不同版本，最短路径裁决规则生效的版本不是预期版本 | `mvn dependency:tree -Dverbose` 查看被丢弃版本，用 exclusions 排除或在 dependencyManagement 锁定版本 | [Maven核心原理与依赖管理](./01-Maven核心原理与依赖管理-导览.md) |
| scope 配错导致 jar 打包体积异常大 | 把 test/provided 依赖写成 compile，测试库被打进产物 | JUnit、Mockito 用 test；Servlet API 用 provided | [Maven核心原理与依赖管理](./01-Maven核心原理与依赖管理-导览.md) |
| SNAPSHOT 进入生产环境导致线上行为不确定 | SNAPSHOT 会被私服更新为最新构建，版本不固定 | 发布版本用 RELEASE，禁止生产依赖 SNAPSHOT | [Maven核心原理与依赖管理](./01-Maven核心原理与依赖管理-导览.md) |
| 子模块版本各自写死导致多模块版本不一致 | 未用 dependencyManagement 统一管理 | 在父 POM 集中声明版本，子模块省略 version | [Maven核心原理与依赖管理](./01-Maven核心原理与依赖管理-导览.md) |
| 中文注释编译报错或编码乱码 | maven-compiler-plugin 未指定 UTF-8 | properties 中设 project.build.sourceEncoding=UTF-8，插件配 encoding | [Maven核心原理与依赖管理](./01-Maven核心原理与依赖管理-导览.md) |
| 忘记 parent 的 relativePath 导致找不到父 POM | 子模块 parent 的 relativePath 默认为 ../pom.xml，目录结构不符 | 显式写 relativePath 或设空，配合 -N 在父目录安装 | [Maven核心原理与依赖管理](./01-Maven核心原理与依赖管理-导览.md) |
| mirrorOf 配成 * 导致私服内部构件拉取失败 | 镜像拦截了所有仓库请求，私服被重定向 | mirrorOf 限定为 central，或用 `*,!nexus-public` 排除私服 | [Maven私服与实战配置](./02-Maven私服与实战配置-导览.md) |
| servers 的 id 不匹配导致 deploy 报 401 Unauthorized | distributionManagement 的 repository id 与 settings 的 server id 不一致 | 两处 id 保持完全一致，并确认账号有写入权限 | [Maven私服与实战配置](./02-Maven私服与实战配置-导览.md) |
| releases 仓库重复上传报 400 Repository does not allow updating assets | releases 仓库禁止覆盖同版本 | 重新发布前升级版本号，或改用 SNAPSHOT；需要覆盖时在 Nexus 开启该仓库的 Allow Redeploy | [Maven私服与实战配置](./02-Maven私服与实战配置-导览.md) |
| SNAPSHOT 不更新，拉取到旧快照 | 本地缓存了旧 SNAPSHOT，updatePolicy 默认 daily | 设 updatePolicy=always，或加 `-U` 强制更新（`mvn clean package -U`） | [Maven私服与实战配置](./02-Maven私服与实战配置-导览.md) |
| 离线构建失败，报 Cannot access 仓库 | 本地仓库缺构件且 offline=true | settings.xml 设 offline=false，或预先在联网环境 install 好构件 | [Maven私服与实战配置](./02-Maven私服与实战配置-导览.md) |
| 密码明文泄露，settings.xml 中明文存储私服密码 | 直接写 password | 用 `${env.NEXUS_PWD}` 从环境变量读取，或用 mvn 的 settings security 加密 | [Maven私服与实战配置](./02-Maven私服与实战配置-导览.md) |
