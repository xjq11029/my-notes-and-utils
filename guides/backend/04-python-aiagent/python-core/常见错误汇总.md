# Python核心 - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南章节与题集易错点提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 对可变对象使用默认参数导致共享状态 | Python函数默认参数在定义时求值一次，列表/字典等可变对象被多次调用共享 | 默认参数使用None，函数体内判断并初始化 | [导览](./01-Python核心语法速通-导览.md) |
| 列表推导式中变量泄露到外层作用域 | Python 2中列表推导式不创建独立作用域；Python 3已修复但嵌套推导式仍可能混淆 | 在Python 3中使用列表推导式；注意生成器表达式的作用域 | [导览](./01-Python核心语法速通-导览.md) |
| GIL导致多线程CPU密集型任务性能不升反降 | CPython的GIL同一时刻只允许一个线程执行Python字节码，多线程实际是并发不是并行 | CPU密集型用multiprocessing；I/O密集型用threading或asyncio | [导览](./01-Python核心语法速通-导览.md) |
| `is` 与 `==` 混淆 | `is`比较对象身份（内存地址），`==`比较值相等；小整数和小字符串驻留（interning）导致误判 | 与None比较用`is`；值比较用`==` | [导览](./01-Python核心语法速通-导览.md) |
| 浅拷贝导致嵌套对象修改相互影响 | `copy.copy()`只复制外层对象，内层嵌套对象仍共享引用 | 嵌套结构需修改内部对象时用`copy.deepcopy()` | [导览](./01-Python核心语法速通-导览.md) |
| 闭包中变量绑定延迟导致循环变量值错误 | 闭包捕获的是变量名而非值，循环结束后变量指向最终值 | 使用默认参数冻结当前值：`lambda x=i: x` 或 `functools.partial` | [导览](./01-Python核心语法速通-导览.md) |
| 装饰器丢失被装饰函数元信息 | 装饰器返回的wrapper函数替换了原函数，`__name__`和`__doc__`丢失 | 使用`@functools.wraps(func)`装饰wrapper函数 | [导览](./01-Python核心语法速通-导览.md) |
| 动态类型导致运行时属性错误难以排查 | Python无编译期类型检查，拼写错误的属性名或方法名在运行时才暴露 | 使用类型注解配合mypy/pyright做静态检查；编写单元测试 | [导览](./01-Python核心语法速通-导览.md) |
| 生成器只能迭代一次 | 生成器是惰性求值的迭代器，遍历完后耗尽，再次遍历无输出 | 需要多次遍历时转为list或使用`itertools.tee` | [导览](./01-Python核心语法速通-导览.md) |
| 类变量与实例变量混淆 | 类变量在类定义体中赋值，被所有实例共享；实例变量在`__init__`中用`self.xxx`赋值 | 可变类变量作为共享状态时需谨慎；实例级属性在`__init__`中初始化 | [导览](./01-Python核心语法速通-导览.md) |
| 异常被静默吞没，故障无声扩散 | `except: pass` 或只打日志不重抛，异常信息丢失且上层无法感知 | 只捕获预期异常；记录日志后用 `raise` 重抛或 `raise NewError(...) from e` 包装 | [导览](./02-Python笔面试题集-导览.md) |
| 循环引用导致内存泄漏 | 两个对象互相持有强引用，引用计数永不归零，仅靠引用计数无法回收 | 用`weakref.ref`打破环；必要时`gc.collect()`；用`objgraph`/`tracemalloc`排查 | [导览](./02-Python笔面试题集-导览.md) |
| 使用`__slots__`后子类内存优化失效或赋值报错 | 子类未声明自己的`__slots__`会重新获得`__dict__`；多继承多个非空`__slots__`会冲突 | 子类同样声明`__slots__`；需要弱引用时加入`"__weakref__"` | [导览](./02-Python笔面试题集-导览.md) |
| 函数内修改外层变量报`UnboundLocalError` | 函数内赋值即视为局部变量，未声明`global`/`nonlocal`时解释器认为该名字是新的局部名 | 模块级用`global`，闭包外层用`nonlocal`；或改用可变容器/类属性承载状态 | [导览](./02-Python笔面试题集-导览.md) |
| 边遍历列表边删除元素导致漏删或错乱 | 删除元素后列表索引前移，迭代器仍按原索引推进 | 用列表推导式重建：`[x for x in lst if 条件]`；或倒序遍历删除 | [导览](./01-Python核心语法速通-导览.md) |
| `TypeError: unhashable type: 'list'` | 字典键与集合元素必须可哈希，list/dict/set 不可哈希 | 改用tuple作为键；自定义类实现`__hash__`与`__eq__` | [导览](./01-Python核心语法速通-导览.md) |
| `@classmethod`与装饰器叠加顺序错误导致`cls`错位 | 装饰器从下往上应用，`@classmethod`若不在最外层，收到的是函数而非绑定方法 | 把`@classmethod`写在最外层，其余装饰器写在它下面 | [导览](./02-Python笔面试题集-导览.md) |
| 装饰异步函数时wrapper未用`async def` | 同步wrapper返回的是协程对象而非执行结果，`await`后才报错或拿到coroutine | 装饰协程函数时`wrapper`必须为`async def`并`await func(...)` | [导览](./02-Python笔面试题集-导览.md) |
| `finally`中的`return`覆盖返回值并吞掉异常 | `finally`必定执行，其中的`return`/`break`会中断异常传播并覆盖`try`的返回值 | 不在`finally`中写`return`/`break`；清理逻辑只做资源释放 | [导览](./02-Python笔面试题集-导览.md) |
| 多继承下基类被重复初始化 | 子类直接调用具体父类方法而非`super()`，菱形继承中共享基类被多次执行 | 统一用`super().__init__(...)`按MRO链式调用，保证每个类只初始化一次 | [导览](./01-Python核心语法速通-导览.md) |
| `@property`只定义getter导致赋值报`AttributeError` | 只写了`@property`未定义对应的`@x.setter`，属性成为只读 | 需要可写时补充`@x.setter`，且函数名必须与被装饰的property同名 | [导览](./01-Python核心语法速通-导览.md) |
| `contextlib.contextmanager`中`yield`未包`try/finally`导致清理被跳过 | 块内抛异常时异常在`yield`处抛入生成器，后续清理代码不再执行 | 用`try: yield ... finally: 清理`包住`yield` | [导览](./02-Python笔面试题集-导览.md) |
| 读写文件未指定`encoding`导致乱码或`UnicodeDecodeError` | 使用平台默认编码（Windows 常为 GBK），与文件实际编码不一致 | 显式传入`encoding="utf-8"`；容错场景加`errors="replace"` | [导览](./01-Python核心语法速通-导览.md) |
| 遍历字典时增删key触发`RuntimeError: dictionary changed size` | 字典视图是动态的，遍历期间改变长度会使迭代器失效 | 先`list(d.keys())`再遍历修改；或改为构建新字典 | [导览](./01-Python核心语法速通-导览.md) |
| 元类中忘记跳过基类自身，注册表出现空基类 | 元类`__new__`会对所有使用它的类生效，包括抽象基类 | 用`if name != "Model"`等条件跳过基类；或改用`__init_subclass__` | [导览](./02-Python笔面试题集-导览.md) |
