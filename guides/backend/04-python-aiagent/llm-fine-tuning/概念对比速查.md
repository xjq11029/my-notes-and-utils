# 大模型微调 - 概念对比速查

---

### 全量微调 vs LoRA vs QLoRA

| 对比维度 | 全量微调（Full Fine-tuning） | LoRA（Low-Rank Adaptation） | QLoRA（Quantized LoRA） |
|---------|---------------------------|---------------------------|------------------------|
| 核心定位 | 更新模型所有参数进行任务适配 | 冻结原始权重，通过低秩矩阵分解近似权重更新 | 在LoRA基础上将基座模型量化到4-bit，进一步降低显存 |
| 适用场景 | 数据充足、算力充裕、需要最大化性能 | 多任务微调、小数据集、资源受限 | 消费级GPU微调大模型（如单卡24GB微调65B） |
| 可训练参数 | 100%参数 | 0.1%-1%参数 | 0.1%-1%参数（与LoRA相同） |
| 显存需求 | 极高（需存储全部梯度、优化器状态） | 低（仅训练低秩矩阵） | 极低（基座4-bit量化加LoRA） |
| 性能表现 | 理论上限最高 | 多数任务接近全量微调，rank合理时差距很小 | 与LoRA接近，4-bit量化引入的精度损失很小 |
| 推理开销 | 无额外开销 | 合并后无额外开销 | 合并后无额外开销（需反量化） |
| 选择建议 | 算力充足且追求极致性能 | 资源受限、多任务场景、快速迭代 | 消费级GPU、需要微调超大规模模型 |

### RLHF vs DPO

| 对比维度 | RLHF（PPO） | DPO（Direct Preference Optimization） |
|---------|-----------|--------------------------------------|
| 核心定位 | 三阶段对齐：SFT+RM+PPO，用强化学习优化策略 | 两阶段对齐：SFT+DPO，将偏好学习转化为分类问题 |
| 训练阶段 | 三阶段（SFT、RM训练、PPO策略优化） | 两阶段（SFT、DPO直接优化） |
| 模型数量 | 4个模型（Actor、Reference、Reward、Critic） | 2个模型（策略、参考） |
| 数据需求 | 偏好对数据 + PPO阶段的prompt采样数据 | 仅需偏好对数据（离线） |
| 训练稳定性 | 差（RL训练不稳定，超参数敏感） | 好（标准监督学习范式） |
| 计算成本 | 高（多模型加载、多步采样） | 低（单次前向传播） |
| 在线探索 | 支持（PPO可在线采样新回答） | 不支持（完全离线） |
| 选择建议 | 追求极致性能、有在线数据、算力充足 | 快速迭代、资源有限、偏好数据质量高 |

### BERT vs GPT vs Transformer

| 对比维度 | Transformer（原始） | BERT | GPT |
|---------|-------------------|------|-----|
| 核心定位 | 通用序列到序列架构，Encoder-Decoder结构 | 双向Encoder-only，专注语言理解 | 自回归Decoder-only，专注语言生成 |
| 注意力机制 | Encoder用双向自注意力，Decoder用因果掩码+Cross-Attention | 双向自注意力，可同时看到左右上下文 | 因果掩码自注意力，只能看到左侧上文 |
| 预训练目标 | -（原始论文用于机器翻译） | MLM（掩码语言模型）+ NSP（下一句预测） | 自回归语言模型（Next Token Prediction） |
| 适用场景 | 机器翻译、文本摘要等seq2seq任务 | 文本分类、命名实体识别、问答、情感分析 | 文本生成、对话、代码生成、开放式创作 |
| 输入处理 | Encoder和Decoder分别输入源和目标序列 | 单序列输入，加[CLS]和[SEP]特殊标记 | 单序列输入，所有token统一处理 |
| 选择建议 | 需要深度理解输入再生成输出的任务 | 理解/分类/抽取类NLP任务 | 生成类任务、对话系统、通用大模型预训练 |
