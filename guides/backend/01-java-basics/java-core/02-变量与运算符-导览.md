## 一、关键字与标识符

### 1.1 关键字

| 维度 | 内容 |
|------|------|
| 是什么 | Java 语言预定义的保留字，全部小写，具有特殊语法含义 |
| 能做什么 | 标识访问控制、类方法修饰、程序控制、包、基本类型、变量引用等语法范畴 |
| 怎么用 | 不能用作变量名、类名、方法名 |
| 原理和工作流程 | 编译器在词法分析阶段将源码切分为 token，命中关键字表即归为关键字 token 并赋予固定语法语义，约 50 个。true、false、null 虽为字面量保留字但严格意义属保留字而非关键字。关键字参与语法树构造，决定后续语法分析路径 |
| 缺点 | 数量多需记忆；保留字占位导致无法用作标识符；strictfp、native 等冷门关键字易被忽略 |

### 1.2 标识符命名规则

| 维度 | 内容 |
|------|------|
| 是什么 | 给变量、类、方法、包命名的字符序列，须遵守语法规则与命名规范 |
| 能做什么 | 区分类名大驼峰、变量方法小驼峰、常量全大写、包名全小写 |
| 怎么用 | 类名 `UserService`、变量 `userName`、常量 `MAX_VALUE` |
| 原理和工作流程 | 语法层只允许字母、数字、下划线、美元符号组成且不能数字开头，不能与关键字重名，区分大小写。规范层约定驼峰命名法提升可读性，编译器不强制规范但团队 lint 工具会检查 |
| 缺点 | 规范靠自觉与工具约束；美元符号合法但易与编译器生成名冲突；中文标识符合法但不推荐 |

## 二、变量的基本概念

### 2.1 变量是什么

| 维度 | 内容 |
|------|------|
| 是什么 | 程序中存储数据的基本单元，在内存中开辟空间存放特定类型数据 |
| 能做什么 | 声明并保存数据；参与运算与传递；通过类型约束取值范围 |
| 怎么用 | `int age = 18;` |
| 原理和工作流程 | 声明时编译器根据类型在栈或堆分配对应大小内存，变量名映射到该内存地址。基本类型变量直接在栈存值，引用类型变量在栈存堆对象地址。赋值即将数据写入对应内存 |
| 缺点 | 局部变量无默认值必须手动初始化；命名不当降低可读性；类型一旦声明不可变 |

### 2.2 变量分类

| 维度 | 内容 |
|------|------|
| 是什么 | 按声明位置划分的成员变量、静态变量、局部变量三类 |
| 能做什么 | 区分生命周期与默认值；控制作用域；决定内存归属 |
| 怎么用 | 成员变量在类内方法外，静态变量加 static，局部变量在方法内 |
| 原理和工作流程 | 成员变量随对象存于堆，对象回收即销毁有默认值；静态变量随类存于方法区，类加载即存在类卸载才销毁有默认值；局部变量存于栈帧，方法执行完即销毁无默认值必须初始化 |
| 缺点 | 局部变量无默认值易引发未初始化错误；静态变量生命周期长易造成内存常驻；作用域误用导致变量泄露 |

## 三、8种基本数据类型

### 3.1 基本类型对照表

| 维度 | 内容 |
|------|------|
| 是什么 | Java 内置的八种值类型，分整数型、浮点型、字符型、布尔型四类 |
| 能做什么 | 固定字节存储数值；提供默认值；支撑运算与比较 |
| 怎么用 | `byte b=10; short s=200; int i=1; long l=1L;` |
| 原理和工作流程 | 八种为 byte(1)、short(2)、int(4)、long(8)、float(4)、double(8)、char(2)、boolean(1)。整数用补码存储，int 为默认整数类型，long 需加 L 后缀，float 需加 f 后缀，double 为默认浮点类型。char 存 Unicode 编码，boolean 仅 true/false |
| 缺点 | 取值范围固定易溢出；浮点无法精确表示十进制小数；short 与 float 实际很少使用 |

### 3.2 各类型说明

| 维度 | 内容 |
|------|------|
| 是什么 | 八种基本类型在字面量写法与使用细节上的具体规则 |
| 能做什么 | 指明 long 加 L、float 加 f；说明浮点精度误差；说明 boolean 不可与 0/1 互转 |
| 怎么用 | `long l=123L; float f=3.14f; char c='A';` |
| 原理和工作流程 | 整数字面量默认 int，long 需 L 后缀让编译器识别为 long。浮点字面量默认 double，float 需 f 后缀。浮点采用 IEEE754 存储导致 0.1+0.2 不等于 0.3，精确计算须用 BigDecimal。boolean 在 JVM 中以 1 字节存储，不能与整型互转，区别于 C 语言 |
| 缺点 | 后缀遗漏导致编译错误或隐式截断；浮点精度问题引发金额计算 bug；boolean 与整型不互通增加迁移成本 |

### 3.3 基本类型 vs 引用类型

| 维度 | 内容 |
|------|------|
| 是什么 | 按存储方式划分的两类数据类型，前者直接存值后者存对象地址 |
| 能做什么 | 对比存储位置、默认值、占用空间；解释 == 比较差异 |
| 怎么用 | 基本类型 `int a=1`，引用类型 `String s="x"` |
| 原理和工作流程 | 基本类型变量在栈直接存值，有默认值，占用固定 1 到 8 字节，比较的是值。引用类型变量在栈存堆对象地址，默认 null，大小不固定，== 比较地址而 equals 比较内容。基本类型无方法无属性，引用类型有方法 |
| 缺点 | 基本类型不能为 null 不利于 ORM 映射；引用类型需装箱有性能开销；两者混用触发自动装箱易引发缓存陷阱 |

## 四、类型转换

### 4.1 自动类型提升（隐式转换）

| 维度 | 内容 |
|------|------|
| 是什么 | 小范围类型赋值给大范围类型时由编译器自动完成的转换 |
| 能做什么 | 实现安全扩容；混合运算统一类型；避免数据丢失 |
| 怎么用 | `double b = 10;` int 自动提升为 double |
| 原理和工作流程 | 转换方向 byte→short→int→long→float→double，char→int。容量指表示范围而非字节数，故 float(4字节) 范围大于 long(8字节)。byte、short、char 混合运算时自动提升为 int，结果为 int，因此 byte+byte 须用 int 接收 |
| 缺点 | byte/short/char 运算结果为 int 易致编译错误；float 范围大于 long 易混淆；隐式提升掩盖精度损失 |

### 4.2 强制类型转换（显式转换）

| 维度 | 内容 |
|------|------|
| 是什么 | 大范围类型赋值给小范围类型时需显式声明的转换，可能丢失精度 |
| 能做什么 | 截断小数；处理溢出；满足窄类型赋值 |
| 怎么用 | `int i = (int) 3.14;` |
| 原理和工作流程 | 语法为 `(目标类型) 变量`。浮点转整数直接砍掉小数部分；大整数转小整数按二进制位截断，超出范围则溢出回绕，如 128 强转 byte 得 -128。编译器不做范围检查，由开发者承担风险 |
| 缺点 | 精度丢失无警告；溢出回绕产生负值难以排查；滥用破坏类型安全 |

## 五、String 基础使用

### 5.1 基本语法

| 维度 | 内容 |
|------|------|
| 是什么 | 表示字符串的引用类型，虽非基本类型但支持 + 拼接运算 |
| 能做什么 | 声明字符串；用 + 拼接；与基本类型混合自动转字符串 |
| 怎么用 | `String name = "张" + "三";` |
| 原理和工作流程 | String 是 java.lang 包下的不可变类，字面量存于字符串常量池。+ 运算符被重载为字符串拼接，当一侧为 String 时另一侧自动调用 toString 转为字符串。编译期常量拼接会被优化合并 |
| 缺点 | 不可变导致循环拼接产生大量临时对象；+ 在循环中性能差应改用 StringBuilder；null 拼接得到字符串 "null" |

### 5.2 代码示例

| 维度 | 内容 |
|------|------|
| 是什么 | 演示 String 拼接运算优先级与从左到右结合特性的示例 |
| 能做什么 | 说明 1+2+"3" 得 "33"；说明 "1"+2+3 得 "123" |
| 怎么用 | `System.out.println(1+2+"3");` 输出 33 |
| 原理和工作流程 | + 运算从左到右结合。1+2 先按整数加法得 3，再与 "3" 拼接得 "33"。"1"+2 先拼接得 "12"，再 +3 拼接得 "123"。一旦遇到 String 操作数，后续运算均按字符串拼接处理 |
| 缺点 | 优先级规则易误判；混用算术与拼接降低可读性；建议显式加括号或用 StringBuilder |

## 六、进制转换

### 6.1 常见进制

| 维度 | 内容 |
|------|------|
| 是什么 | Java 字面量支持的二进制、八进制、十进制、十六进制四种表示 |
| 能做什么 | 用前缀区分进制；跨进制赋值；底层位运算配合 |
| 怎么用 | `0b10`=2、`010`=8、`0x10`=16 |
| 原理和工作流程 | 二进制前缀 0b，八进制前缀 0，十六进制前缀 0x，十进制无前缀。编译器将不同进制字面量统一解析为 int 补码存储，输出时默认十进制。一个十六进制位对应 4 个二进制位，一个八进制位对应 3 个二进制位 |
| 缺点 | 八进制前缀 0 易与十进制混淆；前缀拼写错误静默改变值；可读性差需注释说明 |

### 6.2 进制快速换算

| 维度 | 内容 |
|------|------|
| 是什么 | 二进制与十进制互转的快速计算方法 |
| 能做什么 | 二进制转十进制按权展开；十进制转二进制除 2 取余逆序 |
| 怎么用 | 二进制 1010 = 8+2 = 10 |
| 原理和工作流程 | 二进制转十进制：每一位乘以 2 的 n 次方累加，n 为该位从右起序号。十进制转二进制：不断除以 2 取余数，将余数逆序排列。借助 1 字节等于 8 位、十六进制位对应 4 位等换算关系加速手工计算 |
| 缺点 | 大数手工换算易错；负数需结合补码理解；实际开发多用 Integer.toBinaryString 等工具方法 |

### 6.3 原码、反码、补码

| 维度 | 内容 |
|------|------|
| 是什么 | 计算机存储整数的三种二进制编码方式，Java 整数用补码存储 |
| 能做什么 | 表示正负数；统一加减法电路；解释溢出回绕 |
| 怎么用 | 正数三码相同，负数补码 = 反码 + 1 |
| 原理和工作流程 | 符号位最高位 0 正 1 负。正数原码反码补码相同。负数反码为原码符号位不变其余取反，补码为反码加 1。采用补码可使减法转为加法简化 CPU 运算，并让 0 的表示唯一。溢出时按位截断产生回绕 |
| 缺点 | 负数补码人脑直读困难；溢出无异常易出错；移位运算需理解补码位模式 |

## 七、各种运算符

### 7.1 运算符分类

| 维度 | 内容 |
|------|------|
| 是什么 | Java 按功能划分的算术、赋值、比较、逻辑、位、条件六大类运算符 |
| 能做什么 | 执行数学运算；赋值；比较；逻辑判断；位操作；三目选择 |
| 怎么用 | 算术 `+ - * / %`，逻辑 `&& || !` |
| 原理和工作流程 | 编译器根据运算符 token 生成对应字节码指令，算术生成 iadd、imul 等，比较生成 if_icmp，逻辑依赖短路跳转，位运算生成 iand、ishl 等。不同运算符有固定优先级与结合性决定表达式求值顺序 |
| 缺点 | 优先级复杂难记；同一符号多义（如 & 既逻辑又位运算）；建议加括号避免歧义 |

### 7.2 算术运算符重点

| 维度 | 内容 |
|------|------|
| 是什么 | 执行加减乘除取模与自增自减的运算符 |
| 能做什么 | 整数除法截断；取模求余；自增自减改变值 |
| 怎么用 | `5/2`=2、`5%2`=1、`++a` 与 `a++` |
| 原理和工作流程 | 整数除法直接截断小数部分，有浮点参与则结果为浮点。取模结果符号与被除数一致。自增自减分前置后置：前置先运算后使用，后置先使用后运算。`i = i++` 因底层栈操作结果仍为原值，源于操作数栈与局部变量表的赋值顺序 |
| 缺点 | 整数除法截断易误判；自增自减在复杂表达式中难预测；`i=i++` 陷阱违反直觉 |

### 7.3 赋值运算符

| 维度 | 内容 |
|------|------|
| 是什么 | 将右侧值赋给左侧变量的运算符，含 = 与 += 等复合形式 |
| 能做什么 | 基本赋值；复合算术赋值；隐式强制转换 |
| 怎么用 | `a += 5;` 等价 `a = a + 5` |
| 原理和工作流程 | 复合赋值运算符 `+=`、`-=`、`*=` 等在执行运算后会自动将结果强制转换为左侧变量类型，因此 `b += 20` 对 byte 合法，而 `b = b + 20` 因结果是 int 无法赋给 byte 需显式强转。赋值运算返回赋值后的值可链式使用 |
| 缺点 | 复合赋值的隐式强转掩盖溢出风险；链式赋值降低可读性；与 == 易混淆引发 bug |

### 7.4 比较运算符

| 维度 | 内容 |
|------|------|
| 是什么 | 比较两个值大小或相等性的运算符，返回 boolean |
| 能做什么 | 判断大小关系；判断相等不等；区分值比较与地址比较 |
| 怎么用 | `a == b`、`a != b`、`a > b` |
| 原理和工作流程 | 比较运算生成 boolean 结果。基本类型比较的是值，引用类型 == 比较的是堆地址，因此两个 new String("abc") 用 == 为 false。字符串内容比较须用 equals。编译期常量折叠的字符串可能指向常量池同一对象 |
| 缺点 | == 误用于引用类型内容比较是高频 bug；字符串比较应用 equals；包装类缓存导致 == 时而成立时而不成立 |

### 7.5 逻辑运算符

| 维度 | 内容 |
|------|------|
| 是什么 | 对 boolean 表达式执行与或非异或运算的运算符 |
| 能做什么 | 短路与或；非短路与或；取反；异或 |
| 怎么用 | `a > 20 && a++ < 20` |
| 原理和工作流程 | && 与 || 具短路特性：&& 左侧为 false 则右侧不执行，|| 左侧为 true 则右侧不执行。& 与 | 不短路两侧都执行。! 取反，^ 相异为真。短路特性可避免 NPE 与减少无效计算，开发中基本只用 &&、||、! |
| 缺点 | 短路特性使副作用表达式不被执行易误判；& 与 | 易与位运算混淆；异或使用场景少 |

### 7.6 位运算符

| 维度 | 内容 |
|------|------|
| 是什么 | 直接操作整数二进制位的运算符，含与或异或取反移位 |
| 能做什么 | 按位与或异或；取反；左移右移无符号右移 |
| 怎么用 | `2 << 1`=4、`8 >> 2`=2 |
| 原理和工作流程 | & 按位与，| 按位或，^ 按位异或，~ 按位取反。<< 左移 n 位等价乘 2 的 n 次方，>> 右移等价除以 2 的 n 次方且符号位填充，>>> 无符号右移高位补 0。对 2 的幂运算位运算快于乘除。移位实际移动位数为 n 对 32 取模（long 对 64 取模） |
| 缺点 | 可读性差需注释；负数右移行为依赖符号位填充；移位超范围自动取模易出 bug |

### 7.7 条件运算符（三目）

| 维度 | 内容 |
|------|------|
| 是什么 | Java 唯一的三目运算符，根据条件选择两个表达式之一 |
| 能做什么 | 简化 if-else；内联返回值；嵌套求多值 |
| 怎么用 | `int max = a > b ? a : b;` |
| 原理和工作流程 | 语法 `条件 ? 表达式1 : 表达式2`，条件为 true 返回表达式1，false 返回表达式2。两个分支类型不一致时编译器按自动类型提升统一结果类型。可嵌套实现多分支选择，从右到左结合 |
| 缺点 | 嵌套可读性差；副作用分支不被执行易误判；结果类型自动提升可能引发拆箱 NPE |

## 八、运算符优先级

| 维度 | 内容 |
|------|------|
| 是什么 | 决定表达式中多个运算符求值先后顺序的规则 |
| 能做什么 | 控制求值顺序；避免歧义；配合结合性 |
| 怎么用 | 括号最高，赋值最低，不确定就加括号 |
| 原理和工作流程 | 优先级从高到低大致为括号、单目、算术、位移、比较、位运算、逻辑、三目、赋值。结合性多数从左到右，单目、三目、赋值从右到左。编译器按优先级与结合性构建抽象语法树决定字节码生成顺序 |
| 缺点 | 优先级表难记；位运算与比较优先级反直觉；过度依赖优先级降低可读性应加括号 |
