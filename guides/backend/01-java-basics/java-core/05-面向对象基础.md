## 一、类与对象基础

### 1.1 类与对象

#### 面向对象 vs 面向过程

| 维度 | 面向过程（POP） | 面向对象（OOP） |
|------|---------------|---------------|
| **核心思想** | 功能分解，强调"怎么做" | 数据抽象，强调"谁来做" |
| **基本单位** | 函数 | 类/对象 |
| **数据与行为** | 分离 | 封装在一起 |
| **复用方式** | 函数调用 | 继承、组合、多态 |
| **典型语言** | C | Java、C++、Python |

**面向对象的三大特征：**
1. **封装**（Encapsulation）：隐藏内部实现，对外暴露接口
2. **继承**（Inheritance）：子类复用父类的属性和方法
3. **多态**（Polymorphism）：同一行为在不同对象上表现不同

#### 类的定义与对象的创建

```java
/**
 * 类的定义：成员变量 + 成员方法 + 构造器 + 代码块 + 内部类
 */
public class Person {
    // ========== 成员变量（属性/字段） ==========
    private String name;    // 私有属性，外部不可直接访问
    private int age;
    public String gender;   // 公有属性，外部可直接访问

    // ========== 构造器（Constructor） ==========
    // 无参构造器：若未定义任何构造器，编译器自动生成默认无参构造器
    public Person() {
        System.out.println("Person 无参构造器被调用");
    }

    // 有参构造器：一旦定义了有参构造器，默认无参构造器自动消失
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // ========== 成员方法 ==========
    public void setName(String name) {
        this.name = name;   // this 指代当前对象
    }

    public String getName() {
        return name;
    }

    public void setAge(int age) {
        if (age >= 0 && age <= 150) {
            this.age = age;
        } else {
            System.out.println("年龄不合法！");
        }
    }

    public int getAge() {
        return age;
    }

    public void speak() {
        System.out.println("我叫" + name + "，今年" + age + "岁");
    }
}

// ========== 对象的创建与使用 ==========
public class PersonTest {
    public static void main(String[] args) {
        // 创建对象：类名 变量名 = new 构造器();
        Person p1 = new Person();               // 调用无参构造器
        p1.setName("张三");
        p1.setAge(25);
        p1.speak();                             // 输出：我叫张三，今年25岁

        Person p2 = new Person("李四", 30);      // 调用有参构造器
        p2.speak();                             // 输出：我叫李四，今年30岁

        // 匿名对象：不赋给变量，直接使用
        new Person("王五", 22).speak();          // 只能使用一次
    }
}
```

#### 对象的内存模型

```
栈（Stack）                          堆（Heap）
┌─────────────────────────┐         ┌──────────────────────────────┐
│  p1 = 0x1000            │────────>│  Person 对象实例              │
│  (局部变量，引用类型)      │         │  name = "张三" (String引用)    │
│                         │         │  age = 25                    │
│  p2 = 0x2000            │──┐      │  gender = null               │
└─────────────────────────┘  │      └──────────────────────────────┘
                             │      ┌──────────────────────────────┐
                             └─────>│  Person 对象实例              │
                                    │  name = "李四" (String引用)    │
                                    │  age = 30                    │
                                    │  gender = null               │
                                    └──────────────────────────────┘
```

**关键理解：**
- `new` 关键字在**堆**中分配内存，创建对象实例
- 对象变量（如 `p1`）存储在**栈**中，存储的是对象在堆中的**引用地址**
- 成员变量有默认值（`int` 为 0，引用类型为 `null`），局部变量没有默认值
- 多个对象变量可以指向同一个对象（`p1 = p2` 后两者指向同一实例）

### 1.2 成员变量 vs 局部变量

| 对比维度 | 成员变量（实例变量） | 局部变量 |
|---------|-------------------|---------|
| **声明位置** | 类中、方法外 | 方法内、代码块内、构造器内、形参 |
| **修饰符** | 可用 `public/private/protected/static/final` 等 | 只能用 `final` |
| **默认值** | 有默认值（`int`=0, 引用=null 等） | **无默认值**，必须先赋值后使用 |
| **内存位置** | 堆（随对象） | 栈 |
| **生命周期** | 随对象创建而创建，随 GC 回收而消亡 | 随方法调用而创建，随方法结束而消亡 |
| **作用域** | 整个类 | 声明所在的 `{}` 内 |

```java
public class VariableDemo {
    // 成员变量（有默认值）
    int memberVar;         // 默认值 0
    String memberStr;      // 默认值 null

    public void method(int param) {  // param 是局部变量（形参）
        // 局部变量（无默认值，必须初始化）
        int localVar = 10;
        // int x;  // 编译错误：未初始化不能使用

        System.out.println(memberVar);   // 0
        System.out.println(memberStr);   // null
        System.out.println(localVar);    // 10
        System.out.println(param);       // 传入的值

        // 成员变量与局部变量同名时，局部变量优先（就近原则）
        int memberVar = 100;
        System.out.println(memberVar);   // 100（局部变量）
        System.out.println(this.memberVar); // 0（成员变量，通过 this 区分）
    }
}
```

### 1.3 方法声明与重载

#### 方法声明格式

```java

    // 方法体
    [return 返回值;]
}
```

```java
public class MethodDemo {

    // 无参无返回值
    public void sayHello() {
        System.out.println("Hello!");
    }

    // 有参有返回值
    public int add(int a, int b) {
        return a + b;
    }

    // 有参无返回值
    public void printInfo(String name, int age) {
        System.out.println("姓名：" + name + "，年龄：" + age);
        // return;  // 可省略（void 方法默认在末尾 return）
    }

    // 无参有返回值

        return "无名氏";
    }

```

#### 方法重载（Overload）

**重载条件：** 同一类中，方法名相同，参数列表不同（参数个数、类型或顺序不同）。**与返回值类型、修饰符、形参名无关。**

```java
public class OverloadDemo {

    // 参数个数不同
    public int max(int a, int b) {
        return a > b ? a : b;
    }

    public int max(int a, int b, int c) {
        int temp = max(a, b);
        return temp > c ? temp : c;
    }

    // 参数类型不同
    public double max(double a, double b) {
        return a > b ? a : b;
    }

    // 参数顺序不同
    public void show(String name, int age) {
        System.out.println("姓名：" + name + "，年龄：" + age);
    }

    public void show(int age, String name) {
        System.out.println("年龄：" + age + "，姓名：" + name);
    }

    // ========== 以下不是重载，编译错误 ==========
    // public int max(int x, int y) { ... }     // 仅形参名不同，不算重载
    // public String max(int a, int b) { ... }  // 仅返回值类型不同，不算重载
}
```

**重载方法匹配规则（编译期确定）：**
1. 精确匹配：参数类型完全一致
2. 自动类型提升：如 `byte` -> `short` -> `int` -> `long` -> `float` -> `double`
3. 自动装箱/拆箱：基本类型与包装类之间
4. 可变参数：优先级最低

```java
public class OverloadMatch {
    public void test(int a)        { System.out.println("int"); }
    public void test(double a)     { System.out.println("double"); }
    public void test(Integer a)    { System.out.println("Integer"); }
    public void test(int... a)     { System.out.println("int..."); }

    public static void main(String[] args) {
        OverloadMatch om = new OverloadMatch();
        om.test(10);       // int（精确匹配优先）
        om.test(10.0);     // double（精确匹配）
        om.test('A');      // int（char 自动提升为 int）
        // 若没有 test(int)，则 'A' 会匹配到 test(double)
    }
}
```

### 1.4 可变参数（Varargs）

JDK 5 引入，用于简化需要传递多个同类型参数的方法。

```java
public class VarargsDemo {

    // 传统写法：需要先创建数组
    public static int sumOld(int[] arr) {
        int sum = 0;
        for (int num : arr) {
            sum += num;
        }
        return sum;
    }

    // 可变参数写法：int... nums 等价于 int[] nums
    public static int sum(int... nums) {
        int sum = 0;
        for (int num : nums) {
            sum += num;
        }
        return sum;
    }

    public static void main(String[] args) {
        // 传统写法：必须传数组
        System.out.println(sumOld(new int[]{1, 2, 3}));  // 6

        // 可变参数：可以传任意个参数，也可以传数组
        System.out.println(sum(1, 2, 3));      // 6
        System.out.println(sum(1, 2, 3, 4, 5)); // 15
        System.out.println(sum());              // 0（不传参也行）
        System.out.println(sum(new int[]{1, 2})); // 3（也能传数组）
    }
}
```

**可变参数规则：**

```java
// 规则1：一个方法最多只能有一个可变参数
// public void m1(int... a, String... b) { } // 编译错误

// 规则2：可变参数必须放在参数列表的最后
public void m2(String name, int... scores) { }  // 正确
// public void m3(int... scores, String name) { } // 编译错误

// 规则3：可变参数与方法重载的优先级
public void m4(int a)          { System.out.println("固定参数"); }
public void m4(int... a)       { System.out.println("可变参数"); }

public static void main(String[] args) {
    VarargsDemo vd = new VarargsDemo();
    vd.m4(10);     // 输出：固定参数（固定参数优先于可变参数）
    vd.m4(10, 20); // 输出：可变参数（没有匹配的固定参数，使用可变参数）
}
```

### 1.5 值传递机制

**Java 中只有值传递，没有引用传递。**

```java
public class ValueTransferDemo {

    // ========== 基本数据类型：传递的是数据值的副本 ==========
    public static void changeInt(int x) {
        System.out.println("changeInt 方法内，修改前 x = " + x); // 10
        x = 20;
        System.out.println("changeInt 方法内，修改后 x = " + x); // 20
    }

    // ========== 引用数据类型：传递的是引用地址值的副本 ==========
    public static void changeArray(int[] arr) {
        System.out.println("changeArray 方法内，修改前 arr[0] = " + arr[0]); // 1
        arr[0] = 100;
        System.out.println("changeArray 方法内，修改后 arr[0] = " + arr[0]); // 100
    }

    // 尝试在方法内改变引用指向（不会影响外部）
    public static void changeRef(int[] arr) {
        arr = new int[]{999, 888, 777};  // 让形参指向新对象
        System.out.println("changeRef 方法内 arr[0] = " + arr[0]); // 999
    }

    // 字符串的特殊性（String 不可变）
    public static void changeString(String s) {
        s = "新字符串";  // 让形参指向新对象，不影响外部
        System.out.println("changeString 方法内 s = " + s); // 新字符串
    }

    public static void main(String[] args) {
        // --- 基本类型 ---
        int a = 10;
        changeInt(a);
        System.out.println("main 中 a = " + a); // 10（未改变！）

        // --- 引用类型 ---
        int[] nums = {1, 2, 3};
        changeArray(nums);
        System.out.println("main 中 nums[0] = " + nums[0]); // 100（被改变了！）

        // --- 尝试改变引用 ---
        int[] nums2 = {1, 2, 3};
        changeRef(nums2);
        System.out.println("main 中 nums2[0] = " + nums2[0]); // 1（未改变！）

        // --- String ---
        String str = "原始字符串";
        changeString(str);
        System.out.println("main 中 str = " + str); // 原始字符串（未改变！）
    }
}
```

**值传递内存解析：**

```
基本类型传递：
main: a=10  ──复制值──>  changeInt: x=10  ──修改──>  x=20
                                   ↑ 只影响形参，不影响实参 a

引用类型传递：
main: nums=0x3000  ──复制引用地址──>  changeArray: arr=0x3000
     │                                    │
     └──────────────┬─────────────────────┘
                    ▼
              堆: [1, 2, 3]  ──arr[0]=100──>  [100, 2, 3]
                    ↑ nums 和 arr 指向同一对象，修改通过 arr 可见

改变引用：
main: nums2=0x4000  ──复制引用──>  changeRef: arr=0x4000
      │                                    │  arr = new int[]{...}
      │                                    │  arr=0x5000 (重新指向)
      ▼                                    ▼
堆: [1, 2, 3]                         [999, 888, 777]
      ↑ nums2 仍指向原对象，不受影响
```

### 1.6 递归（Recursion）

递归：方法自己调用自己。适用于问题可以分解为相同子问题且子问题规模缩小的场景。

```java
public class RecursionDemo {

    // ========== 示例1：计算 n 的阶乘 ==========
    // 递推公式：f(n) = n * f(n-1)，终止条件：f(1) = 1
    public static long factorial(int n) {
        if (n < 0) {
            throw new IllegalArgumentException("n 不能为负数");
        }
        if (n == 0 || n == 1) {  // 递归终止条件（递归头）
            return 1;
        }
        return n * factorial(n - 1);  // 递归体
    }

    // ========== 示例2：斐波那契数列 ==========
    // 递推公式：f(n) = f(n-1) + f(n-2)，f(0)=0, f(1)=1
    public static long fibonacci(int n) {
        if (n < 0) {
            throw new IllegalArgumentException("n 不能为负数");
        }
        if (n == 0) return 0;
        if (n == 1) return 1;
        return fibonacci(n - 1) + fibonacci(n - 2);
    }

    // ========== 示例3：汉诺塔问题 ==========
    public static void hanoi(int n, char from, char aux, char to) {
        if (n == 1) {
            System.out.println("将第 1 个盘子从 " + from + " 移到 " + to);
            return;
        }
        hanoi(n - 1, from, to, aux);   // 将 n-1 个盘子从 from 移到 aux
        System.out.println("将第 " + n + " 个盘子从 " + from + " 移到 " + to);
        hanoi(n - 1, aux, from, to);   // 将 n-1 个盘子从 aux 移到 to
    }

    // ========== 示例4：递归遍历目录（实际应用） ==========
    public static void listFiles(File dir, int level) {
        if (dir == null || !dir.exists()) return;
        for (File file : dir.listFiles()) {
            for (int i = 0; i < level; i++) System.out.print("  ");
            System.out.println(file.getName());
            if (file.isDirectory()) {
                listFiles(file, level + 1);  // 递归进入子目录
            }
        }
    }

    public static void main(String[] args) {
        System.out.println("5! = " + factorial(5));      // 120
        System.out.println("fib(10) = " + fibonacci(10)); // 55
        System.out.println("汉诺塔（3个盘子）：");
        hanoi(3, 'A', 'B', 'C');
    }
}
```

**递归调用栈解析（以 factorial(3) 为例）：**

```
调用过程（入栈）                              返回过程（出栈）
factorial(3)                                 factorial(3) = 6
  └─ 3 * factorial(2)                          └─ 3 * 2 = 6
       └─ 2 * factorial(1)                          └─ 2 * 1 = 2
            └─ 1（终止条件）                              └─ 1
```

**递归的陷阱与优化：**

```java
// 陷阱1：缺少终止条件或终止条件永远达不到 → StackOverflowError
public static void badRecursion(int n) {
    System.out.println(n);
    badRecursion(n + 1);  // 永远不会停止！
}

// 陷阱2：重复计算导致性能灾难（斐波那契的朴素递归）
// fibonacci(50) 可能需要几分钟甚至更久！

// 优化1：记忆化搜索（Memoization）
public static long fibonacciMemo(int n) {
    long[] memo = new long[n + 1];
    return fibMemo(n, memo);
}

private static long fibMemo(int n, long[] memo) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    if (memo[n] != 0) return memo[n];  // 已计算过，直接返回
    memo[n] = fibMemo(n - 1, memo) + fibMemo(n - 2, memo);
    return memo[n];
}

// 优化2：迭代替代递归（斐波那契）
public static long fibonacciIterative(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    long a = 0, b = 1, sum = 0;
    for (int i = 2; i <= n; i++) {
        sum = a + b;
        a = b;
        b = sum;
    }
    return sum;
}

// 优化3：尾递归（Java 编译器目前不支持尾递归优化，但了解概念）
// 尾递归：递归调用是方法的最后一步操作
public static long factorialTail(int n, long accumulator) {
    if (n == 0) return accumulator;
    return factorialTail(n - 1, n * accumulator);
}
// 调用：factorialTail(5, 1) → 返回 120
```

**递归 vs 迭代：**

| 维度 | 递归 | 迭代 |
|------|------|------|
| 代码简洁性 | 简洁，接近数学定义 | 可能较冗长 |
| 内存开销 | 每次调用创建栈帧，可能 StackOverflow | 仅需少量变量，内存恒定 |
| 性能 | 有函数调用开销 | 通常更快 |
| 适用场景 | 问题具有天然递归结构（树、图、分治） | 线性计算、简单循环 |

### 2.1 封装（Encapsulation）

**封装的核心思想：** 将数据（属性）和操作数据的方法绑定在一起，隐藏内部实现细节，只暴露必要的接口。

> **生活化类比：银行卡** —— 你不能直接修改银行卡里的余额（私有属性），只能通过 ATM 的存款/取款/查询接口（公开方法）来操作。ATM 内部会验证密码、检查余额是否足够、记录日志（隐藏实现），但你只需要知道插卡输入密码就够了。封装的核心是：**数据私有 + 公开方法控制访问**，而非简单的"隐藏细节"。

```java
public class BankAccount {
    // ========== 私有属性：外部不可直接访问 ==========
    private String accountNo;      // 账号
    private String accountHolder;  // 户名
    private double balance;        // 余额（敏感数据，必须保护）

    // ========== 构造器 ==========
    public BankAccount(String accountNo, String accountHolder, double initialBalance) {
        this.accountNo = accountNo;
        this.accountHolder = accountHolder;
        if (initialBalance >= 0) {
            this.balance = initialBalance;
        } else {
            throw new IllegalArgumentException("初始余额不能为负数");
        }
    }

    // ========== getter / setter：受控访问 ==========
    public String getAccountNo() {
        return accountNo;
    }
    // 账号通常不允许修改，不提供 setter

    public String getAccountHolder() {
        return accountHolder;
    }

    public void setAccountHolder(String accountHolder) {
        if (accountHolder != null && !accountHolder.trim().isEmpty()) {
            this.accountHolder = accountHolder;
        }
    }

    public double getBalance() {
        return balance;
    }
    // 余额不能直接修改，不提供 setter

    // ========== 业务方法：封装了余额修改逻辑 ==========
    public void deposit(double amount) {
        if (amount <= 0) {
            System.out.println("存款金额必须大于 0");
            return;
        }
        balance += amount;
        System.out.println("存入 " + amount + " 元，当前余额：" + balance);
    }

    public boolean withdraw(double amount) {
        if (amount <= 0) {
            System.out.println("取款金额必须大于 0");
            return false;
        }
        if (amount > balance) {
            System.out.println("余额不足！当前余额：" + balance);
            return false;
        }
        balance -= amount;
        System.out.println("取出 " + amount + " 元，当前余额：" + balance);
        return true;
    }
}
```

**四种访问权限修饰符：**

| 修饰符 | 本类 | 同包子类 | 同包非子类 | 不同包子类 | 不同包非子类 |
|--------|------|---------|-----------|-----------|-------------|
| `private` | 可访问 | 不可 | 不可 | 不可 | 不可 |
| 默认（无修饰符） | 可访问 | 可访问 | 可访问 | 不可 | 不可 |
| `protected` | 可访问 | 可访问 | 可访问 | 可访问 | 不可 |
| `public` | 可访问 | 可访问 | 可访问 | 可访问 | 可访问 |

**封装的最佳实践：**
- 属性一律 `private`，通过 `getter/setter` 访问
- 内部状态变化逻辑封装在方法内，对外隐藏复杂度
- 只暴露必要的 `public` 方法作为 API
- 使用 JavaBean 规范：`getXxx()` / `setXxx()`（`boolean` 类型用 `isXxx()`）

### 2.2 继承（Inheritance）

**Java 只支持单继承**（一个类只能有一个直接父类），但支持多层继承（A extends B extends C）。

> **生活化类比：动物分类学** —— 哺乳动物（父类）具有胎生、哺乳、恒温等特征。猫（子类）是哺乳动物的一种（is-a 关系），继承了哺乳动物的所有特征，同时有自己独特的特征（喵喵叫、捕鼠）。Java 继承的核心是 **is-a** 关系，而不是简单的"版本升级"——子类"是一种"父类，而非"新版本"。

```java
// ========== 父类（超类/基类） ==========
public class Animal {
    private String name;
    private int age;

    public Animal() {
        System.out.println("Animal 无参构造器");
    }

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
        System.out.println("Animal 有参构造器");
    }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }

    public void eat() {
        System.out.println(name + " 在吃东西");
    }

    public void sleep() {
        System.out.println(name + " 在睡觉");
    }
}

// ========== 子类（派生类） ==========
public class Dog extends Animal {
    private String breed;  // 子类特有的属性

    public Dog() {
        // super() 默认调用父类无参构造器，写不写都一样
        super();  // 必须在第一行
        System.out.println("Dog 无参构造器");
    }

    public Dog(String name, int age, String breed) {
        super(name, age);  // 显式调用父类有参构造器，必须在第一行
        this.breed = breed;
        System.out.println("Dog 有参构造器");
    }

    public String getBreed() { return breed; }
    public void setBreed(String breed) { this.breed = breed; }

    // 子类特有的方法
    public void bark() {
        System.out.println(getName() + " 汪汪叫！");
    }
}

// ========== 使用示例 ==========
public class InheritanceTest {
    public static void main(String[] args) {
        Dog dog = new Dog("旺财", 3, "金毛");
        // 输出：
        // Animal 有参构造器
        // Dog 有参构造器

        dog.eat();    // 继承自 Animal：旺财 在吃东西
        dog.sleep();  // 继承自 Animal：旺财 在睡觉
        dog.bark();   // Dog 自有方法：旺财 汪汪叫！
    }
}
```

**继承的规则与限制：**

```java
public class Parent {
    private String secret = "父类私有";     // 子类不可直接访问
    String defaultField = "默认访问";       // 同包子类可访问
    protected String protectedField = "受保护"; // 子类可访问
    public String publicField = "公开";     // 所有类可访问

    private void privateMethod() { }        // 子类不可继承
    // final 方法不能被重写
    public final void finalMethod() { }
}
```

**子类能继承什么？**
- 继承父类的 `public` 和 `protected` 成员（属性和方法）
- 继承父类默认访问权限的成员（仅限同包子类）
- **不能**继承父类的 `private` 成员（但可通过父类的 `public/protected` 方法间接访问）
- **不能**继承父类的构造器（需通过 `super()` 调用）

### 2.3 super 关键字

`super` 代表父类的引用，用于在子类中访问父类的成员。

```java
public class SuperDemo {
    public static void main(String[] args) {
        Student stu = new Student("小明", 18, "S001");
        stu.showInfo();
    }
}

class Person {
    protected String name;
    protected int age;
    int id = 1001;  // 与子类同名的属性

    public Person() { }

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void display() {
        System.out.println("Person: " + name + ", " + age);
    }
}

class Student extends Person {
    private String studentId;
    int id = 2001;  // 与父类同名的属性

    public Student(String name, int age, String studentId) {
        super(name, age);  // 调用父类构造器，必须在第一行
        this.studentId = studentId;
    }

    public void showInfo() {
        // super 调用父类被重写的方法
        super.display();

        System.out.println("Student: " + name + ", " + age + ", " + studentId);
        System.out.println("本类 id = " + this.id);    // 2001
        System.out.println("父类 id = " + super.id);   // 1001
    }

    @Override
    public void display() {
        super.display();  // 在重写方法中调用父类版本
        System.out.println("Student ID: " + studentId);
    }
}
```

**super 使用规则总结：**

| 用法 | 语法 | 说明 |
|------|------|------|
| 调用父类构造器 | `super(参数)` | 必须在子类构造器第一行，且 `this()` 和 `super()` 只能二选一 |
| 调用父类方法 | `super.方法名()` | 常用于在重写方法中调用父类的原始实现 |
| 访问父类属性 | `super.属性名` | 当父类和子类有同名属性时用于区分 |

### 2.4 方法重写（Override）

**重写规则：** 子类对父类方法的重新实现，方法签名（方法名 + 参数列表）完全相同。

```java
class Animal {
    public void makeSound() {
        System.out.println("动物发出声音");
    }

    public Animal getAnimal() {
        return new Animal();
    }

    // 静态方法不能被重写
    public static void staticMethod() {
        System.out.println("Animal 静态方法");
    }
}

class Cat extends Animal {
    // ========== 正确重写 ==========
    @Override  // 注解：编译器帮你检查是否真的重写了
    public void makeSound() {
        System.out.println("喵喵喵~");
    }

    // 返回值类型可以是父类方法返回值的子类型（协变返回类型）
    @Override
    public Cat getAnimal() {  // Cat 是 Animal 的子类
        return new Cat();
    }

    // 子类重写方法的访问权限不能比父类更严格
    // 父类 public → 子类必须 public
    // 父类 protected → 子类可以是 protected 或 public

    // 抛出的异常不能比父类方法的异常范围更大

    // ========== 这不是重写（静态方法） ==========
    // @Override  // 加 @Override 会编译报错！
    public static void staticMethod() {
        System.out.println("Cat 静态方法");  // 这是隐藏（hide），不是重写
    }
}
```

**重写 vs 重载对比：**

| 维度 | 重写（Override） | 重载（Overload） |
|------|-----------------|-----------------|
| **发生位置** | 子类与父类之间 | 同一个类中 |
| **方法名** | 相同 | 相同 |
| **参数列表** | 必须相同 | 必须不同（个数/类型/顺序） |
| **返回值类型** | 相同或其子类型 | 无要求 |
| **访问修饰符** | 不能比父类更严格 | 无要求 |
| **异常** | 不能抛出更宽泛的异常 | 无要求 |
| **多态表现** | 运行时多态 | 编译时多态 |

### 2.5 多态（Polymorphism）

**多态的核心：** 父类引用指向子类对象，调用的是子类重写的方法。

> **生活化类比：遥控器** —— 按遥控器上的"播放"键（同一操作），在电视上播放节目（不同行为），在 DVD 上播放光盘（不同行为），在音响上播放音乐（不同行为）。编译器只知道这是个"可播放设备"（父类引用），运行时每个设备自动执行自己的播放逻辑（动态绑定）。你不需要关心具体是什么设备，按播放键就行。

```java
public class PolymorphismDemo {
    public static void main(String[] args) {
        // ========== 多态的核心形式 ==========
        Animal a1 = new Dog();   // 父类引用指向子类对象
        Animal a2 = new Cat();   // 父类引用指向子类对象

        a1.makeSound();  // 汪汪汪！（调用 Dog 重写的方法，运行时绑定）
        a2.makeSound();  // 喵喵喵！（调用 Cat 重写的方法，运行时绑定）

        // ========== 多态应用场景1：方法参数 ==========
        feedAnimal(new Dog());
        feedAnimal(new Cat());

        // ========== 多态应用场景2：方法返回值 ==========
        Animal pet = buyPet("dog");  // 返回 Dog 对象
        pet.makeSound();

        // ========== 多态应用场景3：数组/集合 ==========
        Animal[] zoo = {new Dog(), new Cat(), new Bird()};
        for (Animal animal : zoo) {
            animal.makeSound();  // 各自发出不同的声音
        }

        // ========== 多态的局限 ==========
        // a1.bark();  // 编译错误！父类引用不能调用子类特有方法
        // 需要向下转型
        if (a1 instanceof Dog) {
            Dog dog = (Dog) a1;  // 向下转型（强制类型转换）
            dog.bark();          // 汪汪叫！
        }
    }

    public static void feedAnimal(Animal animal) {
        animal.eat();  // 无论传入什么动物，都调用其重写的 eat 方法
    }

    public static Animal buyPet(String type) {
        if ("dog".equals(type)) {
            return new Dog();
        } else if ("cat".equals(type)) {
            return new Cat();
        }
        return null;
    }
}

// ========== 完整示例类 ==========
class Animal {
    public void makeSound() { System.out.println("动物发出声音"); }
    public void eat() { System.out.println("动物在吃东西"); }
}

class Dog extends Animal {
    @Override
    public void makeSound() { System.out.println("汪汪汪！"); }
    public void bark() { System.out.println("狗在汪汪叫！"); }
}

class Cat extends Animal {
    @Override
    public void makeSound() { System.out.println("喵喵喵！"); }
    public void scratch() { System.out.println("猫在抓东西！"); }
}

class Bird extends Animal {
    @Override
    public void makeSound() { System.out.println("叽叽喳喳！"); }
}
```

**多态的前提条件：**
1. 有继承关系（或实现接口）
2. 子类重写父类方法
3. 父类引用指向子类对象

**向上转型与向下转型：**

```java
// 向上转型（Upcasting）：自动，安全
Animal animal = new Dog();  // 子类 → 父类，自动完成

// 向下转型（Downcasting）：强制，有风险
Dog dog = (Dog) animal;     // 父类 → 子类，需要强制转换
dog.bark();                 // 可以调用子类特有方法

// 危险的向下转型：ClassCastException
Animal a = new Cat();
// Dog d = (Dog) a;  // 运行时抛出 ClassCastException！

// 使用 instanceof 确保安全
if (a instanceof Dog) {
    Dog d = (Dog) a;
    d.bark();
} else {
    System.out.println("不是 Dog 类型，无法转换");
}
```

**多态的底层原理 -- 虚方法表（Virtual Method Table）：**

```
当 JVM 执行 animal.makeSound() 时：
1. 查找 animal 实际指向的对象类型（Dog）
2. 在 Dog 的虚方法表中查找 makeSound() 方法
3. 如果 Dog 重写了，调用 Dog 版本；否则向上查找父类版本

Animal 虚方法表：          Dog 虚方法表：
makeSound() → Animal版    makeSound() → Dog版（重写）
eat()       → Animal版    eat()       → Animal版（继承）
                          bark()      → Dog版（新增）
```

### 2.6 Object 类

`java.lang.Object` 是所有类的根父类，每个类都直接或间接继承自 Object。

```java
public class ObjectDemo {
    public static void main(String[] args) throws CloneNotSupportedException {
        Person p1 = new Person("张三", 25);
        Person p2 = new Person("张三", 25);
        Person p3 = p1;

        // ========== 1. toString() ==========
        // 默认返回：类名@哈希码的十六进制
        System.out.println(p1.toString());
        // 重写后返回自定义格式
        // 直接打印对象时默认调用 toString()
        System.out.println(p1);  // 等价于 p1.toString()

        // ========== 2. equals() ==========
        // 默认比较地址（==）
        System.out.println(p1.equals(p2));  // 重写后比较内容：true
        System.out.println(p1 == p2);       // 比较地址：false
        System.out.println(p1 == p3);       // 比较地址：true

        // ========== 3. hashCode() ==========
        System.out.println(p1.hashCode());
        // 重写 equals 必须重写 hashCode！
        // 相等对象必须有相同的 hashCode

        // ========== 4. getClass() ==========
        Class<?> clazz = p1.getClass();
        System.out.println(clazz.getName());  // 类的全限定名

        // ========== 5. clone() ==========
        // 需要实现 Cloneable 接口并重写 clone()
        Person p4 = (Person) p1.clone();
        System.out.println(p1 == p4);       // false（不同对象）
        System.out.println(p1.equals(p4));  // true（内容相同）
    }
}

class Person implements Cloneable {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // ========== 重写 toString() ==========
    @Override
    public String toString() {
        return "Person{name='" + name + "', age=" + age + "}";
    }

    // ========== 重写 equals() ==========
    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;           // 地址相同
        if (obj == null) return false;          // null 检查
        if (getClass() != obj.getClass()) return false; // 类型相同
        Person other = (Person) obj;
        return this.age == other.age
            && Objects.equals(this.name, other.name); // 内容比较
    }

    // ========== 重写 hashCode() ==========
    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }

    // ========== 重写 clone() ==========
    @Override
    protected Object clone() throws CloneNotSupportedException {
        return super.clone();  // 浅拷贝
    }
}
```

**equals() 与 == 的区别：**

| 比较方式 | 基本类型 | 引用类型 |
|---------|---------|---------|
| `==` | 比较值是否相等 | 比较内存地址是否相同 |
| `equals()` | 不可用 | 默认比较地址（同 `==`），重写后比较内容 |

**重写 equals() 的规范：**
1. 自反性：`x.equals(x)` 为 `true`
2. 对称性：`x.equals(y)` 为 `true` 则 `y.equals(x)` 为 `true`
3. 传递性：`x.equals(y)` 且 `y.equals(z)` 则 `x.equals(z)`
4. 一致性：多次调用结果不变
5. 非空性：`x.equals(null)` 为 `false`

### 3.1 static 关键字

`static` 修饰的成员属于**类级别**，而非对象级别。所有对象共享同一份静态成员。

```java
public class StaticDemo {
    public static void main(String[] args) {
        // 静态成员通过类名访问（无需创建对象）
        System.out.println(Counter.getCount());  // 0

        Counter c1 = new Counter();
        Counter c2 = new Counter();
        Counter c3 = new Counter();

        System.out.println(Counter.getCount());  // 3（所有对象共享）
        System.out.println(c1.getCount());       // 3（也通过对象访问，但不推荐）
    }
}

class Counter {
    // 静态变量：属于类，所有对象共享
    private static int count = 0;

    // 实例变量：每个对象独立
    private int id;

    public Counter() {
        this.id = ++count;
    }

    // 静态方法：只能访问静态成员，不能使用 this/super
    public static int getCount() {
        return count;
        // System.out.println(id);  // 编译错误！静态方法不能访问实例变量
        // System.out.println(this); // 编译错误！静态方法没有 this
    }

    // 实例方法：可以访问静态成员和实例成员
    public int getId() {
        return id;
    }
}
```

**static 的完整用法：**

```java
public class StaticFullDemo {
    // 1. 静态变量（类变量）
    public static String company = "ABC 公司";
    private static int instanceCount = 0;

    // 2. 静态常量（通常用 public static final）
    public static final double PI = 3.141592653589793;
    public static final int MAX_RETRY = 3;

    // 3. 静态方法
    public static int getInstanceCount() {
        return instanceCount;
    }

    // 4. 静态内部类（后面详述）
    static class StaticInner {
        public void print() {
            System.out.println("静态内部类");
        }
    }

    // 5. 静态代码块（类加载时执行一次，用于初始化静态变量）
    static {
        System.out.println("静态代码块：类加载时执行");
        // 可以初始化复杂的静态变量
        company = "初始化后的公司名";
    }

    // 6. 静态导入（JDK 5，在调用方使用）
    // import static java.lang.Math.*;
    // 之后可以直接使用 sqrt(4) 而不是 Math.sqrt(4)
}
```

### 3.2 final 关键字

`final` 表示"最终的、不可改变的"，可以修饰类、方法、变量。

```java
// ========== 1. final 修饰类：类不能被继承 ==========
final class FinalClass {
    // 类体
}
// class Sub extends FinalClass { }  // 编译错误！

// 典型 final 类：String、Integer、Math 等

// ========== 2. final 修饰方法：方法不能被重写 ==========
class Parent {
    public final void finalMethod() {
        System.out.println("此方法不能被重写");
    }
}

class Child extends Parent {
    // @Override public void finalMethod() { }  // 编译错误！
}

// ========== 3. final 修饰变量：变量值不可改变 ==========
public class FinalDemo {
    // 静态常量：必须显式初始化或在静态代码块中初始化
    public static final double PI = 3.14159;

    // 实例常量：必须在构造器结束前初始化（声明时 / 构造器 / 代码块）
    private final int id;
    private final String name;

    public FinalDemo(int id, String name) {
        this.id = id;
        this.name = name;
    }

    public void method() {
        // 局部常量
        final int localConst = 100;
        // localConst = 200;  // 编译错误！

        // final 修饰引用类型：引用不可变，但对象内容可变
        final StringBuilder sb = new StringBuilder("Hello");
        // sb = new StringBuilder("World");  // 编译错误！引用不可变
        sb.append(" World");  // 可以！对象内容可变
        System.out.println(sb);  // Hello World
    }
}
```

**final 与 static final 的区别：**

| 维度 | `final` | `static final` |
|------|---------|---------------|
| 属于 | 对象级别 | 类级别 |
| 初始化时机 | 构造器结束前 | 类加载时 |
| 内存位置 | 随对象在堆中 | 方法区（元空间） |
| 每对象独立 | 是（每个对象有自己的值，但不可变） | 否（全局唯一） |
| 典型用途 | 不可变对象属性 | 全局常量 |

### 3.3 代码块

代码块是用 `{}` 包围的一段代码，根据位置和修饰符分为四种。

```java
public class BlockDemo {
    // ========== 静态代码块 ==========
    static {
        System.out.println("1. 静态代码块：类加载时执行，仅一次");
    }

    // ========== 非静态代码块（实例代码块） ==========
    {
        System.out.println("3. 实例代码块：每次创建对象时执行，在构造器之前");
    }

    // ========== 构造器 ==========
    public BlockDemo() {
        System.out.println("4. 构造器：每次创建对象时执行，在实例代码块之后");
    }

    public BlockDemo(String name) {
        System.out.println("4. 有参构造器：" + name);
    }

    static {
        System.out.println("2. 第二个静态代码块：按定义顺序执行");
    }

    public static void main(String[] args) {
        System.out.println("=== main 开始 ===");
        new BlockDemo();
        System.out.println("---");
        new BlockDemo("测试");
        // 输出顺序：
        // 1. 静态代码块：类加载时执行，仅一次
        // 2. 第二个静态代码块：按定义顺序执行
        // === main 开始 ===
        // 3. 实例代码块：每次创建对象时执行，在构造器之前
        // 4. 构造器：每次创建对象时执行，在实例代码块之后
        // ---
        // 3. 实例代码块：每次创建对象时执行，在构造器之前
        // 4. 有参构造器：测试
    }
}
```

**四种代码块总结：**

| 类型 | 位置 | 执行时机 | 执行次数 |
|------|------|---------|---------|
| 静态代码块 | 类中 `static { }` | 类加载时 | 仅一次 |
| 实例代码块 | 类中 `{ }` | 每次 `new` 对象时，构造器之前 | 每次创建对象 |
| 构造器 | 类中 `类名(){ }` | 每次 `new` 对象时，实例代码块之后 | 每次创建对象 |
| 局部代码块 | 方法内 `{ }` | 方法执行到该代码块时 | 视调用情况 |

**父子类执行顺序（经典面试题）：**

```java
class Parent {
    static { System.out.println("1. Parent 静态代码块"); }
    { System.out.println("3. Parent 实例代码块"); }
    public Parent() { System.out.println("4. Parent 构造器"); }
}

class Child extends Parent {
    static { System.out.println("2. Child 静态代码块"); }
    { System.out.println("5. Child 实例代码块"); }
    public Child() { System.out.println("6. Child 构造器"); }
}

// 执行 new Child() 输出：
// 1. Parent 静态代码块
// 2. Child 静态代码块
// 3. Parent 实例代码块
// 4. Parent 构造器
// 5. Child 实例代码块
// 6. Child 构造器
```

**执行顺序口诀：** 静态先行（父 -> 子），实例跟随（父实例 -> 父构造 -> 子实例 -> 子构造）。

### 3.4 抽象类（Abstract Class）

抽象类是不能实例化的类，用于定义子类的通用模板。

```java
// ========== 抽象类定义 ==========
public abstract class Shape {
    // 可以有普通属性
    protected String color;
    protected String name;

    // 可以有构造器（供子类调用）
    public Shape(String color, String name) {
        this.color = color;
        this.name = name;
    }

    // 抽象方法：没有方法体，子类必须实现
    public abstract double getArea();
    public abstract double getPerimeter();

    // 可以有普通方法
    public void display() {
        System.out.println(name + "（颜色：" + color + "）");
        System.out.println("面积：" + getArea());
        System.out.println("周长：" + getPerimeter());
    }

    // 可以有静态方法
    public static void printInfo() {
        System.out.println("这是一个形状类的静态方法");
    }
}

// ========== 具体子类 ==========
class Circle extends Shape {
    private double radius;

    public Circle(String color, double radius) {
        super(color, "圆形");
        this.radius = radius;
    }

    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }

    @Override
    public double getPerimeter() {
        return 2 * Math.PI * radius;
    }
}

class Rectangle extends Shape {
    private double width;
    private double height;

    public Rectangle(String color, double width, double height) {
        super(color, "矩形");
        this.width = width;
        this.height = height;
    }

    @Override
    public double getArea() {
        return width * height;
    }

    @Override
    public double getPerimeter() {
        return 2 * (width + height);
    }
}

// ========== 使用 ==========
public class AbstractTest {
    public static void main(String[] args) {
        // Shape s = new Shape("红", "形状");  // 编译错误！抽象类不能实例化

        Shape circle = new Circle("红", 5.0);
        Shape rectangle = new Rectangle("蓝", 4.0, 6.0);

        circle.display();
        rectangle.display();
    }
}
```

**抽象类 vs 具体类：**

| 维度 | 抽象类 | 具体类 |
|------|--------|--------|
| 实例化 | 不能 `new` | 可以 `new` |
| 抽象方法 | 可以有（也可以没有） | 不能有 |
| 构造器 | 可以有（供子类调用） | 有 |
| 作用 | 定义模板，提供公共实现 | 完成具体功能 |

**抽象类与接口的选择（关键判断）：**

| 场景 | 选择 |
|------|------|
| 需要在多个类之间共享代码（属性和方法实现） | 抽象类 |
| 需要定义"能做什么"而不关心"怎么做" | 接口 |
| 需要多继承行为 | 接口（Java 单继承，多接口） |
| 需要定义通用属性（非 `static final`） | 抽象类 |
| 需要严格控制类的层次结构 | 抽象类 |
| 需要不同层次类有相同行为 | 接口 |

## 四、接口与内部类

### 4.1 接口（Interface）

接口是抽象方法的集合，定义了一种规范/契约。

```java
// ========== 接口定义 ==========
public interface Flyable {
    // 常量（默认 public static final）
    int MAX_SPEED = 1000;
    String TYPE = "飞行器";

    // 抽象方法（默认 public abstract）
    void fly();
    void land();

    // JDK 8：默认方法（default method）
    default void takeOff() {
        System.out.println("起飞前检查...");
        System.out.println("准备起飞！");
    }

    // JDK 8：静态方法（static method）
    static String getType() {
        return "这是一个飞行器接口";
    }
}

// ========== 接口实现 ==========
class Bird implements Flyable {
    @Override
    public void fly() {
        System.out.println("鸟儿扇动翅膀飞行");
    }

    @Override
    public void land() {
        System.out.println("鸟儿停在树枝上");
    }

    // 可以选择重写默认方法
    @Override
    public void takeOff() {
        System.out.println("鸟儿从树枝上跳起");
        // 如果想调用接口的默认实现
        // Flyable.super.takeOff();
    }
}

class Airplane implements Flyable {
    @Override
    public void fly() {
        System.out.println("飞机通过引擎推力飞行");
    }

    @Override
    public void land() {
        System.out.println("飞机在跑道上降落");
    }
    // 使用接口默认的 takeOff() 实现
}
```

**接口的多实现与多继承：**

```java
// 一个类可以实现多个接口（解决单继承的限制）
interface Swimmable {
    void swim();
}

interface Runnable {
    void run();
}

// 一个类同时实现多个接口
class Duck implements Flyable, Swimmable, Runnable {
    @Override public void fly() { System.out.println("鸭子飞"); }
    @Override public void land() { System.out.println("鸭子降落"); }
    @Override public void swim() { System.out.println("鸭子游泳"); }
    @Override public void run() { System.out.println("鸭子跑"); }
}

// 接口可以继承多个接口
interface Amphibious extends Swimmable, Runnable {
    void crawl();  // 新增方法
    // 继承了 swim() 和 run() 两个抽象方法
}
```

### 4.2 JDK 8/9 接口新特性

#### JDK 8：默认方法（Default Method）

```java
interface Vehicle {
    // 抽象方法
    void start();

    // 默认方法：提供默认实现，实现类可以重写也可以不重写
    default void honk() {
        System.out.println("滴滴！");
    }

    default void stop() {
        System.out.println("车辆停止");
    }
}

interface Electric {
    default void charge() {
        System.out.println("充电中...");
    }

    // 两个接口有同名默认方法时的冲突解决
    default void honk() {
        System.out.println("电动车的喇叭声");
    }
}

// 实现多个接口，有同名默认方法冲突
class Tesla implements Vehicle, Electric {
    @Override
    public void start() {
        System.out.println("特斯拉启动");
    }

    // 必须重写冲突的默认方法，否则编译错误
    @Override
    public void honk() {
        // 可以选择调用某个接口的默认实现
        Vehicle.super.honk();  // 调用 Vehicle 的 honk
        Electric.super.honk(); // 调用 Electric 的 honk
        System.out.println("特斯拉自定义喇叭声");
    }
}

// 类优先原则：类的方法优先级高于接口的默认方法
class BaseCar {
    public void honk() {
        System.out.println("基础汽车喇叭");
    }
}

class MyCar extends BaseCar implements Vehicle {
    // 不需要重写 honk()，BaseCar 的 honk 优先于 Vehicle 的默认方法
}
```

**默认方法冲突解决规则（类优先原则）：**
1. 类中的方法优先于接口中的默认方法
2. 子接口中的方法优先于父接口中的方法
3. 如果两个不相关的接口有同名默认方法，实现类必须重写

#### JDK 8：静态方法

```java
interface MathUtils {
    // 接口静态方法：属于接口，通过接口名调用
    static int add(int a, int b) {
        return a + b;
    }

    static int max(int a, int b) {
        return a > b ? a : b;
    }
}

// 调用接口静态方法
int result = MathUtils.add(5, 3);  // 通过接口名调用
// 实现类不能继承接口的静态方法
```

#### JDK 9：私有方法

```java
interface Logger {
    // 公共默认方法
    default void logInfo(String message) {
        log("INFO", message);
    }

    default void logError(String message) {
        log("ERROR", message);
    }

    default void logDebug(String message) {
        log("DEBUG", message);
    }

    // JDK 9：私有方法，抽取公共代码
    private void log(String level, String message) {
        System.out.println("[" + level + "] " + getTimestamp() + " - " + message);
    }

    // JDK 9：私有静态方法
    private static String getTimestamp() {
        return java.time.LocalDateTime.now().toString();
    }
}
```

| JDK 版本 | 接口成员 | 说明 |

| JDK 7 及之前 | 常量 + 抽象方法 | 接口只能定义规范 |
| JDK 8 | + 默认方法 + 静态方法 | 接口可以有方法实现 |
| JDK 9 | + 私有方法 + 私有静态方法 | 接口内部可以复用代码 |

### 4.3 内部类（Inner Class）

内部类是定义在另一个类内部的类，分为四种类型。

#### 4.3.1 成员内部类

```java
public class Outer {
    private String name = "外部类";
    private static int staticVar = 100;

    // 成员内部类：作为外部类的成员
    public class Inner {
        private String name = "内部类";

        public void display() {
            // 访问外部类成员（包括 private）
            System.out.println("外部类 name：" + Outer.this.name);
            System.out.println("内部类 name：" + this.name);
            System.out.println("外部类静态变量：" + staticVar);
        }
    }

    public void createInner() {
        Inner inner = new Inner();
        inner.display();
    }
}

// 外部创建成员内部类对象
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();  // 必须先有外部类对象
inner.display();
```

#### 4.3.2 静态内部类

```java
public class Outer2 {
    private String name = "外部类";
    private static String staticName = "静态外部类";

    // 静态内部类：用 static 修饰
    public static class StaticInner {
        public void display() {
            // System.out.println(name);  // 编译错误！不能访问非静态成员
            System.out.println("静态外部类名：" + staticName);
            System.out.println("这是一个静态内部类");
        }

        public static void staticMethod() {
            System.out.println("静态内部类的静态方法");
        }
    }
}

// 创建静态内部类对象（不需要外部类对象）
Outer2.StaticInner inner = new Outer2.StaticInner();
inner.display();
Outer2.StaticInner.staticMethod();  // 可以直接调用静态方法
```

#### 4.3.3 局部内部类

```java
public class Outer3 {
    public void method() {
        final int localVar = 10;  // JDK 8+ 可省略 final（effectively final）

        // 局部内部类：定义在方法内部
        class LocalInner {
            public void display() {
                // 只能访问 final 或 effectively final 的局部变量
                System.out.println("局部变量：" + localVar);
                System.out.println("这是局部内部类");
            }
        }

        // 在方法内创建和使用
        LocalInner inner = new LocalInner();
        inner.display();
    }

    // 返回实现了特定接口的局部内部类对象
    public Runnable getRunnable() {
        class MyRunnable implements Runnable {
            @Override
            public void run() {
                System.out.println("局部内部类实现的 Runnable");
            }
        }
        return new MyRunnable();
    }
}
```

#### 4.3.4 匿名内部类

```java
public class AnonymousInnerDemo {
    public static void main(String[] args) {
        // ========== 基于接口的匿名内部类 ==========
        Runnable runnable = new Runnable() {
            @Override
            public void run() {
                System.out.println("匿名内部类实现的 Runnable");
            }
        };
        new Thread(runnable).start();

        // ========== 基于抽象类的匿名内部类 ==========
        Shape shape = new Shape("红", "匿名形状") {
            @Override
            public double getArea() {
                return 100.0;
            }

            @Override
            public double getPerimeter() {
                return 40.0;
            }
        };
        shape.display();

        // ========== 基于具体类的匿名内部类 ==========
        Dog dog = new Dog() {
            @Override
            public void makeSound() {
                System.out.println("匿名狗的叫声~");
            }
        };
        dog.makeSound();

        // ========== 匿名内部类作为方法参数 ==========
        execute(new Flyable() {
            @Override
            public void fly() {
                System.out.println("匿名飞行");
            }

            @Override
            public void land() {
                System.out.println("匿名降落");
            }
        });
    }

    public static void execute(Flyable flyable) {
        flyable.fly();
        flyable.land();
    }
}

// JDK 8+ 可以用 Lambda 表达式简化匿名内部类
Runnable r = () -> System.out.println("Lambda 表达式");
```

**四种内部类对比：**

| 类型 | 位置 | 修饰符 | 访问外部类 | 访问局部变量 | 典型用途 |
|------|------|--------|-----------|-------------|---------|
| 成员内部类 | 类中方法外 | `public/private/protected/static` | 所有成员 | 不适用 | 与外部类紧密关联的辅助类 |
| 静态内部类 | 类中方法外 | `static` | 仅静态成员 | 不适用 | 与外部类关联但不需要实例的辅助类 |
| 局部内部类 | 方法/代码块内 | 不能有访问修饰符 | 所有成员 | `final` 变量 | 临时使用的类 |
| 匿名内部类 | 表达式/参数中 | 无 | 所有成员 | `final` 变量 | 事件监听、回调、一次性使用 |

## 五、枚举、注解与包装类

### 5.1 枚举（Enum）

枚举是 JDK 5 引入的限定取值的特殊类，每个枚举常量都是 `public static final` 的实例。

```java
// ========== 基本枚举定义 ==========
public enum Season {
    SPRING, SUMMER, AUTUMN, WINTER  // 每个都是 Season 类型的实例
}

// ========== 枚举的常用方法 ==========
public class EnumBaseDemo {
    public static void main(String[] args) {
        Season spring = Season.SPRING;

        // 1. name()：返回枚举常量名
        System.out.println(spring.name());  // SPRING

        // 2. ordinal()：返回枚举常量的序号（从 0 开始）
        System.out.println(spring.ordinal());  // 0

        // 3. toString()：默认返回 name()，可重写
        System.out.println(spring.toString());  // SPRING

        // 4. values()：返回所有枚举常量
        for (Season s : Season.values()) {
            System.out.println(s);
        }

        // 5. valueOf(String)：通过名称获取枚举常量
        Season summer = Season.valueOf("SUMMER");
        System.out.println(summer);  // SUMMER

        // 6. switch 中使用枚举
        switch (spring) {
            case SPRING: System.out.println("春天"); break;
            case SUMMER: System.out.println("夏天"); break;
            case AUTUMN: System.out.println("秋天"); break;
            case WINTER: System.out.println("冬天"); break;
        }
    }
}
```

**复杂枚举（带属性和方法）：**

```java
public enum Weekday {
    // 枚举常量列表（必须在第一行）
    MONDAY("星期一", 1),
    TUESDAY("星期二", 2),
    WEDNESDAY("星期三", 3),
    THURSDAY("星期四", 4),
    FRIDAY("星期五", 5),
    SATURDAY("星期六", 6),
    SUNDAY("星期日", 7);

    // 私有属性
    private final String chineseName;
    private final int dayNumber;

    // 构造器必须是 private 的（默认也是 private，可省略）
    Weekday(String chineseName, int dayNumber) {
        this.chineseName = chineseName;
        this.dayNumber = dayNumber;
    }

    // getter 方法
    public String getChineseName() {
        return chineseName;
    }

    public int getDayNumber() {
        return dayNumber;
    }

    // 自定义方法
    public boolean isWeekend() {
        return this == SATURDAY || this == SUNDAY;
    }

    // 重写 toString()
    @Override
    public String toString() {
        return chineseName + "（第" + dayNumber + "天）";
    }
}

// 使用复杂枚举
public class EnumAdvancedDemo {
    public static void main(String[] args) {
        for (Weekday day : Weekday.values()) {
            System.out.println(day + " - " + (day.isWeekend() ? "周末" : "工作日"));
        }
        // 输出：
        // 星期一（第1天） - 工作日
        // ...
        // 星期六（第6天） - 周末
        // 星期日（第7天） - 周末
    }
}
```

**枚举实现接口：**

```java
interface Operator {
    double apply(double x, double y);
}

// 枚举实现接口：每个常量可以实现不同的行为
public enum Operation implements Operator {
    PLUS {
        @Override
        public double apply(double x, double y) {
            return x + y;
        }
    },
    MINUS {
        @Override
        public double apply(double x, double y) {
            return x - y;
        }
    },
    TIMES {
        @Override
        public double apply(double x, double y) {
            return x * y;
        }
    },
    DIVIDE {
        @Override
        public double apply(double x, double y) {
            if (y == 0) throw new IllegalArgumentException("除数不能为 0");
            return x / y;
        }
    };
}

// 使用
double result = Operation.PLUS.apply(10, 5);  // 15.0
```

**枚举 vs 常量类：**

| 维度 | 枚举 | 常量类（`static final`） |
|------|------|------------------------|
| 类型安全 | 编译期类型检查 | 只是 int/String，可能传错值 |
| 可读性 | 自带 name() 和自定义方法 | 需要额外实现 |
| switch 支持 | 原生支持 | 仅支持 int/String |
| 单例模式 | 天然支持 | 需手动实现 |
| 反编译 | 防止反编译创建新实例 | 无法防止 |

### 5.2 注解（Annotation）

注解是 JDK 5 引入的元数据机制，用于为代码添加标记信息。

#### 内置注解

```java
// ========== JDK 内置注解 ==========
public class BuiltInAnnotations {

    // 1. @Override：标识方法重写
    @Override
    public String toString() {
        return "BuiltInAnnotations";
    }

    // 2. @Deprecated：标识已过时（不推荐使用，但仍可用）
    @Deprecated
    public void oldMethod() {
        System.out.println("这个方法已过时");
    }

    // 3. @SuppressWarnings：抑制编译器警告
    @SuppressWarnings({"unchecked", "rawtypes"})
    public void suppressedMethod() {
        List list = new ArrayList();  // 不会提示 raw type 警告
        list.add("test");
    }

    // 4. @FunctionalInterface：标识函数式接口（只有一个抽象方法的接口）
    @FunctionalInterface
    interface MyFunction {
        void execute();
        // void execute2();  // 编译错误！函数式接口只能有一个抽象方法
    }

    // 5. @SafeVarargs（JDK 7）：抑制可变参数泛型警告
    @SafeVarargs
    public static <T> List<T> asList(T... elements) {
        return Arrays.asList(elements);
    }
}
```

#### 元注解（注解的注解）

```java
import java.lang.annotation.*;

// 1. 定义注解
@Target({ElementType.TYPE, ElementType.METHOD, ElementType.FIELD})  // 适用范围
@Retention(RetentionPolicy.RUNTIME)  // 保留策略（运行时可通过反射获取）
@Documented   // 包含在 javadoc 中
@Inherited    // 子类自动继承
public @interface MyAnnotation {
    // 注解的属性（类似方法声明）
    String value() default "";        // 默认值
    String name() default "default";
    int age() default 0;
    String[] tags() default {};       // 数组类型属性
}

// 2. 使用注解
@MyAnnotation(value = "类级别", name = "Demo", age = 1, tags = {"java", "annotation"})
public class AnnotationDemo {

    @MyAnnotation("方法级别")  // 当只有 value 属性时，可以省略 "value ="
    @Deprecated
    public void test() {
        System.out.println("test 方法");
    }

    @MyAnnotation(value = "字段级别", name = "field")
    private String data;
}
```

**元注解说明：**

| 元注解 | 说明 | 取值 |
|--------|------|------|
| `@Target` | 注解的作用范围 | `TYPE`（类）、`METHOD`（方法）、`FIELD`（字段）、`PARAMETER`（参数）等 |
| `@Retention` | 注解的保留策略 | `SOURCE`（源码）、`CLASS`（字节码，默认）、`RUNTIME`（运行时） |
| `@Documented` | 是否包含在 javadoc 中 | 标记注解 |
| `@Inherited` | 子类是否自动继承 | 标记注解 |
| `@Repeatable` | 是否可重复使用（JDK 8） | 指定容器注解 |

#### 通过反射读取注解

```java
public class AnnotationProcessor {
    public static void main(String[] args) throws Exception {
        Class<?> clazz = AnnotationDemo.class;

        // 获取类上的注解
        if (clazz.isAnnotationPresent(MyAnnotation.class)) {
            MyAnnotation ann = clazz.getAnnotation(MyAnnotation.class);
            System.out.println("类注解 value: " + ann.value());
            System.out.println("类注解 name: " + ann.name());
            System.out.println("类注解 tags: " + Arrays.toString(ann.tags()));
        }

        // 获取方法上的注解
        Method method = clazz.getMethod("test");
        if (method.isAnnotationPresent(MyAnnotation.class)) {
            MyAnnotation ann = method.getAnnotation(MyAnnotation.class);
            System.out.println("方法注解 value: " + ann.value());
        }
    }
}
```

### 5.3 包装类（Wrapper Class）

Java 为每种基本类型提供了对应的包装类，实现基本类型与对象的互转。

```java
// ========== 8 种基本类型与包装类对应关系 ==========
// byte    → Byte
// short   → Short
// int     → Integer
// long    → Long
// float   → Float
// double  → Double
// char    → Character
// boolean → Boolean
```

#### 装箱与拆箱

```java
public class WrapperDemo {
    public static void main(String[] args) {
        // ========== 1. 手动装箱（基本类型 → 包装类） ==========
        int num1 = 100;
        Integer obj1 = Integer.valueOf(num1);  // 显式装箱
        Integer obj2 = new Integer(num1);      // 构造器方式（JDK 9 已过时）

        // ========== 2. 手动拆箱（包装类 → 基本类型） ==========
        Integer obj3 = Integer.valueOf(200);
        int num2 = obj3.intValue();            // 显式拆箱

        // ========== 3. 自动装箱（JDK 5） ==========
        Integer obj4 = 100;  // 编译器自动转换为 Integer.valueOf(100)

        // ========== 4. 自动拆箱（JDK 5） ==========
        int num3 = obj4;     // 编译器自动转换为 obj4.intValue()

        // ========== 5. 自动装箱/拆箱在运算中 ==========
        Integer a = 10;
        Integer b = 20;
        Integer c = a + b;   // 自动拆箱 → 加法 → 自动装箱
        System.out.println(c);  // 30
    }
}
```

#### Integer 缓存机制（重要面试题）

```java
public class IntegerCacheDemo {
    public static void main(String[] args) {
        // Integer 默认缓存 -128 ~ 127
        Integer a = 100;  // 自动装箱，从缓存中获取
        Integer b = 100;  // 自动装箱，从缓存中获取
        System.out.println(a == b);  // true（同一个对象！）

        Integer c = 200;  // 超出缓存范围，new Integer(200)
        Integer d = 200;  // 超出缓存范围，new Integer(200)
        System.out.println(c == d);  // false（不同对象！）

        // 使用 equals 比较值（推荐）
        System.out.println(c.equals(d));  // true

        // 缓存范围可通过 JVM 参数调整
        // -Djava.lang.Integer.IntegerCache.high=500
    }
}
```

**包装类缓存范围：**

| 包装类 | 缓存范围 |
|--------|---------|
| `Boolean` | `true` 和 `false` |
| `Byte` | -128 ~ 127（全部） |
| `Short` | -128 ~ 127 |
| `Integer` | -128 ~ 127（可通过 `-XX:AutoBoxCacheMax` 调整上限） |
| `Long` | -128 ~ 127 |
| `Character` | 0 ~ 127（ASCII 范围） |
| `Float` | 无缓存 |
| `Double` | 无缓存 |

#### 包装类常用方法

```java
public class WrapperMethods {
    public static void main(String[] args) {
        // ========== 1. 字符串 ↔ 基本类型 ==========
        // 字符串 → 基本类型
        int i1 = Integer.parseInt("123");
        double d1 = Double.parseDouble("3.14");
        boolean b1 = Boolean.parseBoolean("true");

        // 基本类型 → 字符串

        String s2 = String.valueOf(123);
        String s3 = 123 + "";  // 简单但不推荐

        System.out.println(Integer.toBinaryString(10));   // 1010
        System.out.println(Integer.toOctalString(10));    // 12
        System.out.println(Integer.toHexString(255));     // ff

        // ========== 3. 数值比较 ==========
        int result = Integer.compare(5, 3);  // 1（5 > 3）

        int min = Integer.min(10, 20);       // 10

        System.out.println(Integer.MAX_VALUE);  // 2147483647

    }
}
```

**基本类型与包装类的选择：**

| 场景 | 使用基本类型 | 使用包装类 |
|------|------------|-----------|
| 性能敏感 | 优先（无装箱开销） | - |
| 集合元素 | 不可用 | 必须（泛型不支持基本类型） |
| 允许 null | 不可用 | 使用（表示"无值"） |
| 频繁运算 | 优先 | 避免（自动装箱/拆箱开销） |
| 方法参数 | 推荐 | 仅在需要 null 时使用 |
| POJO 属性 | 不推荐 | 推荐（数据库字段可能为 null） |

## 常见面试题精选

### 1. 重载和重写的区别？

| 维度 | 重载（Overload） | 重写（Override） |
|------|-----------------|-----------------|
| 发生位置 | 同一个类中 | 子类与父类之间 |
| 方法名 | 相同 | 相同 |
| 参数列表 | 必须不同 | 必须相同 |
| 返回值类型 | 无要求 | 相同或其子类型 |
| 访问修饰符 | 无要求 | 不能比父类更严格 |
| 异常 | 无要求 | 不能抛出更宽泛的异常 |
| 多态类型 | 编译时多态 | 运行时多态 |

### 2. 抽象类和接口的区别？

| 维度 | 抽象类 | 接口 |
|------|--------|------|
| 关键字 | `abstract class` | `interface` |
| 继承 | 单继承 | 多实现（多继承） |
| 构造器 | 有 | 无 |
| 变量 | 普通变量 + 常量 | 仅常量（`public static final`） |
| 方法 | 抽象方法 + 具体方法 | JDK 7：仅抽象方法；JDK 8+：抽象 + 默认 + 静态；JDK 9+：+ 私有方法 |
| 访问修饰符 | 任意 | 方法默认 `public`，JDK 9 私有方法为 `private` |
| 设计理念 | "是什么"（is-a） | "能做什么"（can-do） |

### 3. == 和 equals() 的区别？

- `==`：基本类型比较值，引用类型比较内存地址
- `equals()`：Object 类中的方法，默认实现是用 `==` 比较地址。子类（如 String、Integer）重写后比较内容
- 重写 `equals()` 必须重写 `hashCode()`，否则 HashMap/HashSet 等容器会出问题

### 4. 静态代码块、构造代码块、构造方法的执行顺序？

执行顺序：**静态代码块（父类 → 子类）→ 实例代码块（父类）→ 构造器（父类）→ 实例代码块（子类）→ 构造器（子类）**

静态代码块在类加载时执行一次，实例代码块和构造器在每次 `new` 对象时执行。

### 5. Integer 的缓存机制是怎样的？

Integer 默认缓存 -128 到 127 之间的所有 Integer 对象。自动装箱时，如果值在缓存范围内，直接从缓存数组中获取已有对象，不会新建。因此 `Integer a = 100; Integer b = 100;` 中 `a == b` 为 `true`。超出缓存范围则会新建对象，`==` 比较为 `false`。比较两个 Integer 的值应使用 `equals()` 而非 `==`。

## 避坑指南

| 常见错误 | 现象 | 原因 | 解决方案 |
|---------|------|------|---------|
| 构造器中写 `return` 返回值 | 编译错误 | 构造器没有返回值类型，也不能 `return` 值 | 构造器只能 `return;`（无值） |
| 子类构造器未调用 `super()` | 编译错误（父类无默认构造器时） | 子类构造器默认调用父类无参构造器，若父类没有则报错 | 显式调用 `super(参数)` |
| 方法重写时访问权限更严格 | 编译错误 | 子类重写方法不能缩小父类方法的访问权限 | 保持或扩大访问权限 |
| 多态下调用子类特有方法 | 编译错误 | 父类引用看不到子类特有的方法 | 向下转型（先 `instanceof` 判断） |
| `Integer` 用 `==` 比较 | 时而 true 时而 false | 缓存范围内 `==` 为 true，超出为 false | 统一使用 `equals()` |
| 匿名内部类引用局部变量 | 编译错误 | 局部变量必须是 `final` 或 effectively final | 将变量声明为 `final` 或不在内部类中修改 |
| 接口中定义非 `static final` 变量 | 编译错误 | 接口中的变量默认是 `public static final` | 使用抽象类或在实现类中定义 |
| 忘记 `break` 导致枚举 switch 穿透 | 逻辑错误 | 枚举 switch 同样有穿透特性 | 每个 case 末尾加 `break` |
| 递归没有终止条件 | `StackOverflowError` | 方法无限递归调用 | 确保递归有明确的终止条件 |
| 可变参数放在非最后位置 | 编译错误 | 可变参数必须是参数列表的最后一个 | 将可变参数移到最后 |
