# Vue3 - 概念对比速查

---

### Vue2 vs Vue3

| 对比维度 | Vue2 | Vue3 |
|---------|------|------|
| 核心定位 | 基于Options API的渐进式框架 | 基于Composition API的渐进式框架 |
| 响应式原理 | Object.defineProperty（无法检测新增属性） | Proxy（可以检测所有属性变化） |
| API风格 | 选项式API（data、methods、computed） | 组合式API（setup、ref、reactive），同时兼容选项式 |
| 组件复用 | Mixins（命名冲突、来源不清晰） | 组合式函数（显式引入、逻辑清晰） |
| 生命周期 | beforeCreate、created、beforeMount等 | onBeforeMount、onMounted、onBeforeUnmount等 |
| 模板根节点 | 必须有一个根节点包裹 | 支持多个根节点（Fragment） |
| 性能 | 虚拟DOM，组件级更新 | 静态提升、PatchFlag、靶向更新，性能更好 |
| TypeScript | 支持有限，类型推导弱 | 完全用TS重写，类型推导强 |
| 选择建议 | 维护旧项目 | 新项目默认使用Vue3 |

### v-if vs v-show

| 对比维度 | v-if | v-show |
|---------|------|--------|
| 核心定位 | 条件渲染，真正创建/销毁DOM | 条件显示，通过CSS display切换 |
| 渲染机制 | 条件为false时不渲染DOM，切换时销毁和重建 | 始终渲染DOM，通过display:none隐藏 |
| 切换成本 | 高（涉及DOM创建销毁和组件生命周期） | 低（仅切换CSS属性） |
| 初始渲染 | 条件为false时省渲染开销 | 始终需要渲染，初始成本高 |
| 适用场景 | 条件很少改变时（如权限控制） | 频繁切换显示/隐藏时（如Tab切换） |
| 性能影响 | 频繁切换会造成性能问题 | 大量隐藏元素会影响初始渲染 |
| 选择建议 | 运行时条件很少改变时使用 | 需要频繁切换可见性时使用 |

---

### v-bind vs v-model

| 对比维度 | v-bind | v-model |
|---------|--------|---------|
| 核心定位 | 单向数据绑定，父组件到子组件 | 双向数据绑定，数据自动同步 |
| 数据流向 | 单向：数据源 -> 视图 | 双向：数据源 <-> 视图 |
| 语法糖 | 直接绑定属性 | v-bind + v-on 的语法糖 |
| 修饰符 | .prop、.attr、.camel | .lazy、.number、.trim |
| 适用场景 | 父组件向子组件传递数据 | 表单输入控件的数据绑定 |
| 组件通信 | props单向传递 | 父子组件间双向绑定 |
| 选择建议 | 大多数场景使用v-bind单向绑定 | 表单控件使用v-model双向绑定 |

### computed vs watch

| 对比维度 | computed | watch |
|---------|----------|-------|
| 核心定位 | 声明式计算属性，依赖变化自动重新计算 | 监听响应式数据变化，执行副作用 |
| 缓存机制 | 有缓存，依赖不变时不会重新计算 | 无缓存，每次依赖变化都执行回调 |
| 返回值 | 返回计算结果，可以像数据一样使用 | 无返回值，执行副作用操作 |
| 异步支持 | 不支持异步操作 | 支持异步操作 |
| 执行时机 | 懒执行，被访问时才计算 | 依赖变化时立即执行 |
| 适用场景 | 模板中需要使用计算后的值 | 数据变化后执行异步请求、DOM操作 |
| 选择建议 | 需要基于现有数据计算新值时使用 | 需要在数据变化时执行副作用时使用 |
