# 企业后台管理系统实战 - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从源文件避坑指南提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 权限判断只用前端路由守卫，用户可直接访问 API | 前端权限只是 UI 控制，不能替代后端安全校验 | 后端必须做接口级权限校验，前端权限仅作为体验优化 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| Token 刷新时多个请求同时 401 导致多次刷新 | 并发请求同时触发刷新逻辑，旧 Token 失效 | 用 isRefreshing 标记 + pendingRequests 队列缓存，只刷新一次 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 动态路由重复添加导致控制台报警告 | 每次路由跳转都调用 addRoute，未做重复判断 | 用 hasAddedRoutes 标记判断是否已添加，防止重复注册 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 大列表直接渲染导致页面卡顿 | 大量 DOM 节点同时渲染，浏览器渲染线程阻塞 | 使用虚拟列表（el-table-v2）或后端分页加载 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 表单校验不完整导致后端收到无效数据 | 只做了简单的 required 校验，未覆盖业务规则 | 使用 async-validator 做完整校验，包含格式、范围、业务规则 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| localStorage 存储敏感信息导致 Token 被 XSS 窃取 | localStorage 可被 JS 直接读取，XSS 攻击可获取 Token | 使用 HttpOnly Cookie 存储 Token，或部署严格 CSP 策略 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 路由守卫未处理异步失败导致登录后白屏 | getUserInfo 请求失败后未捕获异常，后续逻辑无法执行 | beforeEach 中用 try-catch 包裹异步操作，失败时清除状态并跳转登录页 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 组件库全局引入导致打包体积过大 | Element Plus 全量引入，包含大量未使用的组件 | 用 unplugin-vue-components 实现按需引入，仅打包使用的组件 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 侧边栏菜单与路由不同步导致刷新后高亮错误 | default-active 使用静态值，未与当前路由绑定 | 用 useRoute() 动态获取当前路由路径，computed 计算高亮菜单项 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 暗黑模式切换后第三方组件颜色异常 | 第三方组件（如 ECharts）硬编码颜色，未跟随主题变化 | 主题切换时调用第三方组件的主题 API 或重新 setOption | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| v-if 和 v-permission 同时控制按钮导致闪烁或权限判断失效 | v-if 和自定义指令的执行时机不同，可能产生冲突 | 统一使用 v-permission 控制按钮显隐，避免与 v-if 混用 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
