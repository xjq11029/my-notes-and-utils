# 企业后台管理系统实战 - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从源文件避坑指南提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 权限判断只用前端路由守卫，用户可直接访问 API | 前端权限只是 UI 控制，不能替代后端安全校验 | 后端必须做接口级权限校验，前端权限仅作为体验优化 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| Token 刷新时多个请求同时 401 导致多次刷新 | 并发请求同时触发刷新逻辑，旧 Token 失效 | 用 isRefreshing 标记 + pendingRequests 队列缓存，只刷新一次 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 动态路由重复添加导致控制台报警告 | 每次路由跳转都调用 addRoute，未做重复判断 | 用 hasAddedRoutes 标记判断是否已添加，防止重复注册 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 大列表直接渲染导致页面卡顿 | 大量 DOM 节点同时渲染，浏览器渲染线程阻塞 | 使用虚拟列表（el-table-v2）或后端分页加载 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 表单校验不完整导致后端收到无效数据 | 只做了简单的 required 校验，未覆盖业务规则 | 使用 async-validator 做完整校验，包含格式、范围、业务规则 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| localStorage 存储敏感信息导致 Token 被 XSS 窃取 | localStorage 可被 JS 直接读取，XSS 攻击可获取 Token | 使用 HttpOnly Cookie 存储 Token，或部署严格 CSP 策略 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 路由守卫未处理异步失败导致登录后白屏 | getUserInfo 请求失败后未捕获异常，后续逻辑无法执行 | beforeEach 中用 try-catch 包裹异步操作，失败时清除状态并跳转登录页 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 组件库全局引入导致打包体积过大 | Element Plus 全量引入，包含大量未使用的组件 | 用 unplugin-vue-components 实现按需引入，仅打包使用的组件 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 侧边栏菜单与路由不同步导致刷新后高亮错误 | default-active 使用静态值，未与当前路由绑定 | 用 useRoute() 动态获取当前路由路径，computed 计算高亮菜单项 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 暗黑模式切换后第三方组件颜色异常 | 第三方组件（如 ECharts）硬编码颜色，未跟随主题变化 | 主题切换时调用第三方组件的主题 API 或重新 setOption | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| v-if 和 v-permission 同时控制按钮导致闪烁或权限判断失效 | v-if 和自定义指令的执行时机不同，可能产生冲突 | 统一使用 v-permission 控制按钮显隐，避免与 v-if 混用 | [企业后台管理系统实战导览](./01-企业后台管理系统实战-导览.md) |
| 大促期间库存扣减出现超卖 | 先查库存再更新，两步操作非原子 | 用 Redis Lua 脚本，或数据库 `UPDATE ... WHERE stock >= n` 原子扣减 | [电商平台实战导览](./02-电商平台实战-导览.md) |
| 用户被重复扣款或重复发货 | 支付回调被多次调用，未做幂等 | 根据 `trade_no` 判断是否已处理，并用分布式锁防并发 | [电商平台实战导览](./02-电商平台实战-导览.md) |
| 订单状态错乱（已取消又变成已支付） | 两个操作并发修改同一条订单状态 | 用乐观锁 `WHERE status = oldStatus` 更新，失败则重试或提示 | [电商平台实战导览](./02-电商平台实战-导览.md) |
| 用户登录后购物车被清空 | 登录后仅从服务端加载，直接覆盖了本地数据 | 登录后先把本地购物车合并到服务端，再清除本地数据 | [电商平台实战导览](./02-电商平台实战-导览.md) |
| 数据库连接池被耗尽，接口大面积超时 | 事务内执行了外部 API 调用，长事务长期占用连接 | 事务内只做数据库操作，外部调用放到事务外 | [电商平台实战导览](./02-电商平台实战-导览.md) |
| 商品价格显示旧数据，与数据库不一致 | 先更新数据库后删缓存，删缓存失败导致脏读 | 用 Canal 监听 binlog 异步更新缓存，或设置合理 TTL 兜底 | [电商平台实战导览](./02-电商平台实战-导览.md) |
| 商品列表页加载慢，单张原图数 MB | 列表页直接加载原图，未做尺寸裁剪 | 上传时生成多尺寸缩略图，列表用小图、详情用大图 | [电商平台实战导览](./02-电商平台实战-导览.md) |
| 用户评价区被注入脚本，可窃取登录态 | 富文本内容未过滤就渲染 | 用 DOMPurify 过滤 HTML，并用 CSP 限制脚本来源 | [电商平台实战导览](./02-电商平台实战-导览.md) |
| 秒杀接口被刷导致服务崩溃 | 接口无频率限制 | Nginx `limit_req` + BFF 层令牌桶限流 | [电商平台实战导览](./02-电商平台实战-导览.md) |
| 前端请求长时间挂起，页面一直转圈 | 下游服务响应慢，BFF 未设置超时 | 设置合理请求超时（如 5s），超时后返回降级数据 | [电商平台实战导览](./02-电商平台实战-导览.md) |
| 订单超时未取消，库存被永久锁定 | 缺少定时任务扫描超时订单 | 用 Redis 过期事件或定时任务（如 XXL-JOB）取消超时订单 | [电商平台实战导览](./02-电商平台实战-导览.md) |
| 组件库被使用方引入后样式全丢 | `sideEffects: false` 表示所有模块无副作用，CSS 也被 Tree Shaking 消除 | 写成 `"sideEffects": ["**/*.css"]` 或明确列出样式文件 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| 组件库产物体积翻倍，甚至出现 `provide` 失效 | Vue 被打进产物，使用方出现两份 Vue 实例 | `rollupOptions.external` 排除 `vue`，同时放入 `peerDependencies` | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| A 项目的样式覆盖影响了 B 项目 | 组件库样式没有命名空间隔离 | 统一前缀 + BEM + CSS 变量，避免全局选择器 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| 低代码平台一次拖拽要按两次撤销 | 拖拽被拆成"删除 + 插入"两条命令 | 用复合命令把关联操作合并为一条命令 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| 低代码拖拽元素总是插到错误位置 | 只判断了鼠标在哪个容器内，没算子节点 index | 遍历子节点用 `getBoundingClientRect()` 与中线比较，算出插入位 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| 低代码预览区配置的样式把编辑器 UI 也改了 | 预览与编辑器渲染在同一文档中 | 预览放 iframe，用 `postMessage` 通信并校验来源 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| 低代码出码结果语法错误，导出的代码无法编译 | 字符串拼接在复杂嵌套时拼错 | 改用 AST 生成代码，输出后接 Prettier 格式化 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| 可视化大屏布局跟着缩放，图表仍是原尺寸 | Canvas 内容不响应 rem 变化 | 用 `transform: scale` 统一缩放，或监听尺寸变化调 `chart.resize()` | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| 大屏长时间运行后内存持续增长直至卡死 | ECharts 实例未销毁，Canvas 与事件监听未释放 | `onBeforeUnmount` 中 `dispose()` 并断开 `ResizeObserver` | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| ECharts 图表更新时明显掉帧 | 用 `ref` 包裹实例，深度响应式代理了超大对象 | 用 `shallowRef` 包裹 ECharts 实例 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| 大屏组件卸载后仍在请求接口 | `setInterval` 未在卸载时清理 | 统一封装 `useInterval`，组件卸载时清理定时器 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| 拔掉网线后 IM 界面一直显示"已连接" | 只依赖 `onclose` 判断断线，TCP 假死不触发 `onclose` | 实现应用层心跳，超时主动断开并重连 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| 服务端重启后被所有客户端同时重连打垮 | 重连无退避、无抖动 | 指数退避 + 随机抖动 + 封顶 30s | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| IM 消息重发后出现重复气泡 | 消息缺少幂等标识 | 客户端生成唯一 `msgId`，收发两侧都按 msgId 去重 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| IM 消息顺序错乱 | 用本地时间排序，客户端时钟不可信 | 使用服务端分配的会话内递增 `seq` 排序 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| IM 消息渲染后触发 XSS，Token 被窃取 | 消息内容直接 `v-html` 渲染，未消毒 | `DOMPurify.sanitize` + 协议白名单 + 外链 `rel` 加固 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
| IM 已读回执逐条上报把服务端压垮 | 上报粒度过细，请求量爆炸 | 会话级上报 `readSeq` + 防抖 + 只增不减 | [高频项目类型实战导览](./04-高频项目类型实战-导览.md) |
