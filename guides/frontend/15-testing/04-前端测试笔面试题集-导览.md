# 04-前端测试笔面试题集 - 导览

---

## 选择题部分（20 题）

| 维度 | 内容 |
|---|---|
| 是什么 | 20 道选择题覆盖单元测试（3 题：测试金字塔 / vi.mock / 覆盖率）、组件测试（3 题：查询优先级 / userEvent vs fireEvent / MSW）、E2E 测试（4 题：Playwright 架构 / E2E 适用场景 / 视觉回归 API / 自动等待），以及新增的性能测试与 CI 执行优化（5 题：k6 vs Lighthouse CI / VU 与到达率模型 / Lighthouse 断言级别 / 测试分片 / 增量选择）、契约测试（3 题：Pact 流程 / 匹配器 / 与 Mock、E2E 的分工）、单元与组件测试补充（2 题：快照测试 / Vitest Browser Mode），每题附逐项解析 |
| 能做什么 | 快速检验对前端测试核心概念的掌握程度；模拟面试中的选择题环节；识别常见误区（如"k6 能测 LCP""契约测试可以替代 E2E""快照能验证正确性"） |
| 怎么用 | 先独立完成所有题目，再对照解析检查答案，标记错题重点复习对应原理章节 |
| 原理和工作流程 | 每道题考查一个核心知识点，解析中说明正确选项的原因和错误选项的误区，并标注难度（★/★★/★★★） |
| 缺点 | 选择题只能覆盖知识点，无法考察实际编码和测试设计能力 |

## 简答题部分（15 题）

| 维度 | 内容 |
|---|---|
| 是什么 | 15 道简答题覆盖测试金字塔、Vitest vs Jest、查询优先级、userEvent vs fireEvent、MSW 原理、自动等待机制、视觉回归、测试策略设计，以及新增的 k6 与 Lighthouse CI 分工、测试分片与报告合并、增量测试选择三条纪律、Flaky 治理、消费者驱动契约（Pact）完整流程、契约测试与 Mock、E2E 的分工、快照测试原理与适用场景 |
| 能做什么 | 模拟面试中的简答环节；提供标准化的答题要点和思路；补齐 03 补充章节（性能测试 / CI 优化 / 契约测试）的知识缺口 |
| 怎么用 | 先尝试口头回答，再对照答案要点补充遗漏，反复练习直到流畅表达 |
| 原理和工作流程 | 每道题从"是什么"、"为什么"、"怎么做"三个维度组织答案，包含代码示例、对比表格与纪律清单 |
| 缺点 | 简答题答案仅供参考，实际面试中需要结合项目经验展开 |

## 场景设计题部分（8 题）

| 维度 | 内容 |
|---|---|
| 是什么 | 8 道场景设计题：测试策略设计（电商购物车）、组件测试编写（搜索筛选）、E2E 场景设计（多步骤注册）、Mock 策略设计（第三方支付 SDK）、视觉回归方案（设计系统组件库），以及新增的性能测试与性能门禁设计（k6 + Lighthouse CI）、大型测试套件的 CI 优化方案（分片 / 增量 / 缓存 / Flaky 治理）、前后端接口契约测试落地（Pact + Broker + can-i-deploy） |
| 能做什么 | 模拟面试中的场景设计/系统设计环节；培养测试策略思维和方案设计能力；提供可复用的测试模板与落地路径 |
| 怎么用 | 先独立设计方案（画出测试金字塔、列出各层测试用例与门禁），再对照答案要点补充和优化 |
| 原理和工作流程 | 每道题从需求分析 → 测试分层 → 用例设计 → 工具选择 → CI 策略逐步展开，包含完整的代码示例 |
| 缺点 | 场景设计题的答案具有开放性，实际项目中需要结合更多约束条件 |
