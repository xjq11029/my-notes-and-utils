# uni-app 跨端开发 - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 页面数据在 mounted 中请求，小程序端偶尔数据不显示 | 小程序端 mounted 触发时机不稳定，可能在页面渲染完成前数据还未返回 | 将数据请求放在 `onLoad` 生命周期中，onLoad 由框架保证在页面加载时触发且只执行一次 | [uniapp跨端开发基础导览](./01-uniapp跨端开发基础-导览.md) |
| 条件编译代码在小程序端仍然执行，导致报错 | 条件编译注释语法错误（如 `#ifdef` 漏写 `#` 写成 `ifdef`、`#endif` 遗漏或配对错误） | 检查条件编译注释的拼写和配对，确保 `<!-- #ifdef -->` 和 `<!-- #endif -->` 正确闭合；使用 HBuilderX 的条件编译高亮功能验证 | [uniapp跨端开发基础导览](./01-uniapp跨端开发基础-导览.md) |
| 使用 navigateTo 跳转页面失败，小程序端无任何反应 | 页面栈深度超出平台限制（小程序通常 10 层，App 端 5-10 层） | 超过页面栈限制时改用 `uni.redirectTo` 关闭当前页跳转，或使用 `uni.reLaunch` 关闭所有页面后跳转；避免在循环中连续 navigateTo | [uniapp跨端开发基础导览](./01-uniapp跨端开发基础-导览.md) |
| nvue 页面中 CSS 样式不生效，布局错乱 | nvue 页面仅支持 flexbox 布局子集，不支持百分比、vw/vh、CSS 动画、float 等 | 在 nvue 页面中只使用 flexbox 布局；用 750rpx 基准值替代百分比；用 `transition` 属性（nvue 支持的子集）替代 CSS 动画；优先使用 vue 页面，仅在性能要求极高的场景使用 nvue | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| 小程序端 scroll-view 中频繁 setData 导致页面卡顿 | 在 scroll 事件中高频调用 setData，每次调用都触发跨线程通信和视图层重渲染 | 对 scroll 事件使用节流（throttle）控制触发频率（如 100ms 一次）；减少单次 setData 的数据量，只传递必要的变化字段；使用 `wx.nextTick` 合并多次渲染 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| 图片加载完成后页面发生抖动，内容位置偏移 | 未给 `<image>` 组件设置固定宽高，图片加载完成后撑开容器导致重排 | 为所有 `<image>` 组件设置 `mode="aspectFill"` 或 `mode="widthFix"`，并指定固定的宽高或宽高比；使用占位容器预先占据空间 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| 分包页面跳转后白屏或 404 | 分包配置中 root 路径或 pages 路径与实际文件路径不一致，或分包页面未正确注册 | 检查 `pages.json` 中 `subPackages` 配置的 root 和 pages 路径是否与文件系统路径完全一致；确保分包目录下的页面文件存在；使用绝对路径跳转分包页面 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| 使用 uni.request 请求时小程序端提示"不在以下 request 合法域名列表中" | 未在小程序后台配置服务器 request 合法域名，或域名未备案 | 在微信小程序后台"开发管理 → 开发设置 → 服务器域名"中配置 request 合法域名；开发阶段可在开发者工具中勾选"不校验合法域名"临时绕过 | [uniapp跨端开发基础导览](./01-uniapp跨端开发基础-导览.md) |
| nvue 页面和 vue 页面之间无法通过 Vuex 共享状态 | nvue 和 vue 页面运行在不同的 JS 执行环境中（App 端），各自维护独立的 Vuex store 实例 | 使用 `uni.$on` / `uni.$emit` 全局事件总线通信；或将共享数据持久化到 `uni.setStorageSync`，在 onShow 中读取最新数据 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| 使用 `v-if` 频繁切换大组件导致小程序端白屏 | 小程序端 `v-if` 切换涉及完整的组件创建和销毁，大量 DOM 操作在渲染层耗时过长 | 用 `v-show` 替代 `v-if` 进行频繁切换（v-show 仅切换 CSS display 属性）；将大组件拆分为更小的子组件，减少单次渲染的 DOM 数量 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| H5 端正常显示的 CSS 渐变在小程序端不生效 | 小程序 WXSS 对 CSS 渐变的支持有限，部分渐变语法（如 `radial-gradient`、`conic-gradient`）不被支持 | 使用小程序支持的 `linear-gradient` 语法；复杂渐变效果使用图片替代；或通过条件编译为小程序端单独编写样式 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| 页面 onShow 中请求数据导致重复请求和性能浪费 | onShow 在页面每次显示时都会触发（包括从后台切回、从其他页面返回），但开发者未做去重处理 | 在 onShow 中判断是否需要重新请求数据（如设置刷新标记）；首次加载的数据请求放在 onLoad 中；使用缓存机制避免短时间内的重复请求 | [uniapp跨端开发基础导览](./01-uniapp跨端开发基础-导览.md) |
| 使用 `position: fixed` 在 iOS 小程序中弹出键盘时元素位置异常 | iOS 小程序中键盘弹出时 WebView 会整体上移，fixed 定位的元素相对于移动后的视口定位 | 避免在键盘弹出的输入场景中使用 fixed 定位；使用 `input` 的 `adjust-position` 属性控制页面是否上移；将 fixed 元素改为 absolute 并配合 scroll-view 使用 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| 跨端项目中使用 `document`、`window` 等浏览器 API 导致小程序端报错 | 开发者直接使用了浏览器特有的全局对象，小程序运行环境（JSCore）中不存在这些对象 | 避免在公共代码中直接使用浏览器 API；通过条件编译将平台特有代码隔离：`// #ifdef H5` 中使用浏览器 API；使用 `uni.getSystemInfoSync()` 等 uni API 替代 | [uniapp跨端开发基础导览](./01-uniapp跨端开发基础-导览.md) |
| 在小程序 `<text>` 组件中嵌套 `<view>`，渲染异常 | 小程序 `<text>` 内只能嵌套 `<text>`，不支持嵌套 `<view>` | 把 `<text>` 内的 `<view>` 改为 `<text>`，或调整结构 | [uniapp跨端开发基础导览](./01-uniapp跨端开发基础-导览.md) |
| 使用 `v-html` 指令后小程序端渲染为空 | 小程序使用自定义渲染引擎，不支持 `v-html` | 使用 `<rich-text>` 组件替代，或使用 `mp-html` 等第三方富文本插件 | [uniapp跨端开发基础导览](./01-uniapp跨端开发基础-导览.md) |
| 在 `onLoad` 中获取节点信息为 null | `onLoad` 时页面尚未渲染完成，DOM 节点不存在 | 把节点查询放到 `onReady` 生命周期中 | [uniapp跨端开发基础导览](./01-uniapp跨端开发基础-导览.md) |
| 在 `<scroll-view>` 内使用 `position: fixed`，小程序端定位失效 | `<scroll-view>` 会创建新的层叠上下文，fixed 相对于 scroll-view 定位 | 把 fixed 元素移到 `<scroll-view>` 外部 | [uniapp跨端开发基础导览](./01-uniapp跨端开发基础-导览.md) |
| TabBar 页面跳转后 TabBar 消失 | TabBar 页面必须用 `uni.switchTab` 跳转，用 `navigateTo` 会丢 TabBar | TabBar 页面用 `uni.switchTab`，非 TabBar 页面用 `uni.navigateTo` | [uniapp跨端开发基础导览](./01-uniapp跨端开发基础-导览.md) |
| 弹窗、提示被 video/map/canvas 遮挡，`z-index` 无效 | 小程序原生组件层级最高，普通元素无法覆盖 | 使用 `cover-view` / `cover-image` 覆盖原生组件，或显示弹窗时先隐藏原生组件 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| `setData` 传递大量数据导致页面卡顿、操作延迟 | 每次 setData 都涉及跨线程通信和数据序列化，数据量大时开销巨大 | 只传递变化的数据，使用数据路径精确更新，不把非渲染数据放在 data 中 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| 同一帧内多次调用 setData，页面渲染抖动 | 多次 setData 会触发多次渲染 | 合并 setData 调用，并用节流控制频率 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| 用 `overflow: scroll` 实现滚动，小程序端不滚动 | 小程序不支持 CSS `overflow` 滚动 | 使用 `<scroll-view>` 组件替代 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |
| 长列表数据多时页面卡顿、白屏 | 大量 DOM 节点同时渲染，内存和渲染开销巨大 | 使用虚拟滚动，只渲染可视区域内的元素 | [渲染差异与性能优化导览](./02-uniapp渲染差异与性能优化-导览.md) |

| 事件监听器中 `event.target` 返回宿主元素而非实际点击的内部元素 | Shadow DOM 的事件重定向机制，用于保护内部实现细节 | 使用 `event.composedPath()` 获取完整事件路径，或设置 `composed: true` 让事件穿透边界 | [PWA与WebComponents导览](./03-PWA与WebComponents-导览.md) |
