# TypeScript - 概念对比速查

---

### type vs interface

| 对比维度 | type | interface |
|---------|------|-----------|
| 核心定位 | 类型别名，可以表示任意类型 | 接口声明，用于描述对象结构 |
| 扩展方式 | 使用交叉类型 & 扩展 | 使用 extends 继承 | 
| 声明合并 | 不支持同名合并 | 同名接口自动合并 |
| 可表示的类型 | 任意类型（联合、交叉、元组、原始类型） | 只能描述对象结构 |
| 映射类型 | 支持使用in keyof创建映射类型 | 不支持直接映射类型 |
| 重名处理 | 报错 | 声明合并 |
| 适用场景 | 复杂类型别名、联合类型、工具类型 | 对象结构定义、类实现契约、库的公共API |
| 选择建议 | 优先使用interface定义对象结构，需要联合类型等复杂类型时使用type | 默认使用interface定义对象类型 |

### any vs unknown vs never

| 对比维度 | any | unknown | never |
|---------|-----|---------|-------|
| 核心定位 | 任意类型，关闭类型检查 | 安全的顶层类型，需要类型收窄 | 永远不存在的类型，底层类型 |
| 类型安全 | 不安全，跳过所有检查 | 安全，不经收窄不可使用 | 绝对安全，因为不可接收任何值赋值 |
| 可赋值给 | 任何类型 | 只能赋值给any和unknown | 任何类型（作为协变） |
| 可接收赋值 | 任何类型 | 任何类型 | 无法接收任何值 |
| 成员访问 | 允许访问任意成员 | 不允许访问任何成员 | 无成员可访问 |
| 适用场景 | 遗留代码迁移、快速原型 | 未知来源的数据（API响应、JSON.parse） | 永远不会返回的函数、穷举检查 |
| 选择建议 | 尽量避免，逐步迁移到具体类型 | 作为any的安全替代，处理未知类型首选 | 用于表示不可能发生的状态 |

### 泛型类型 vs 泛型函数

| 对比维度 | 泛型类型 | 泛型函数 |
|---------|---------|---------|
| 核心定位 | 定义可接受类型参数的接口或类型 | 定义可接受类型参数的函数签名 |
| 定义位置 | 类型定义中（类型别名、接口） | 函数签名中 |
| 类型参数位置 | 紧随类型名之后 | 紧随函数名之后 |
| 使用方式 | 作为类型注解使用 | 调用时推断或显式指定 |
| 典型示例 | `type Container<T> = { value: T }` | `function identity<T>(arg: T): T` |
| 适用场景 | 定义可复用的组件类型、容器类型 | 定义可处理多种类型的函数 |
| 选择建议 | 当需要定义具有类型参数的结构时使用 | 当函数需要接受和处理多种类型时使用 |

### readonly vs const

| 对比维度 | readonly | const |
|---------|----------|-------|
| 核心定位 | 属性修饰符，限制属性只读 | 变量声明，常量绑定 |
| 作用范围 | 类型系统中属性级别 | 值空间中的变量声明 |
| 保证级别 | 编译时检查，运行时无防护 | 不可重新赋值，编译时+运行时 |
| 可修饰内容 | 接口属性、类属性、数组、元组类型 | 变量声明 |
| 嵌套对象 | 仅浅层只读，嵌套属性仍可修改 | 仅绑定不可变，嵌套属性仍可修改 |
| as const | 配合as const使所有层级变为只读 | 直接声明常量 |
| 选择建议 | 需要定义只读属性的类型时使用 | 声明不可重新赋值的变量时使用 |
