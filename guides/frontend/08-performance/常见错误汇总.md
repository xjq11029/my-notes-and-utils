# 前端性能优化 - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 首屏核心内容加载延迟，LCP 偏高 | 对 LCP 元素使用了 `loading="lazy"`，延迟了首屏核心内容的加载 | LCP 元素不使用懒加载，改用 preload 或 fetchpriority="high" 优先加载 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 页面加载时内容跳动，CLS 偏高 | 未给图片设置宽高，浏览器无法预留空间，图片加载后撑开布局 | 为所有 `<img>` 设置 width/height 属性或使用 aspect-ratio CSS | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 全局 CSS 样式在构建后丢失 | package.json 中 `sideEffects: false` 导致 CSS 文件被 Tree Shaking 移除 | 在 sideEffects 数组中排除 CSS 文件，如 `"sideEffects": ["*.css"]` | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 浏览器控制台警告 preload 资源未使用 | preload 的资源在 3 秒内未被页面消费，浪费带宽 | 只 preload 确定会立即使用的关键资源，删除未使用的 preload 声明 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| HTML 更新后用户看不到新版本 | HTML 被强缓存，浏览器不请求新版本 | HTML 使用协商缓存（Cache-Control: no-cache），JS/CSS 使用文件名哈希 + 强缓存 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 用户网络差时页面白屏 | 动态 import 未加错误处理，chunk 加载失败未被捕获 | 使用 .catch() 处理加载失败，或使用框架的错误边界组件 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 字体加载期间文字不可见（FOIT） | 未设置 font-display，浏览器默认行为是字体加载期间隐藏文字 | 设置 `font-display: swap`，立即使用后备字体，加载完成后替换 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 资源体积大于预期，压缩效果不佳 | 仅依赖 Gzip，未启用更高效的 Brotli 压缩 | Nginx/CDN 配置 Brotli 压缩，配合 vite-plugin-compression 预生成 .br 文件 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 防抖回调中获取到的值是函数创建时的旧值 | 闭包捕获了过时的变量引用 | 使用 ref 存储最新值，或使用 useCallback + useRef 组合 | [运行时优化导览](./02-运行时优化-导览.md) |
| 列表超过 1000 条时页面卡顿 | 大量 DOM 节点直接渲染导致内存占用高、渲染慢 | 使用虚拟列表（react-window 或 vue-virtual-scroller）只渲染可视区域 | [运行时优化导览](./02-运行时优化-导览.md) |
| 页面出现布局抖动（Layout Thrashing） | 频繁交替读取布局属性（offsetTop 等）和写入样式，触发强制同步布局 | 批量读取布局属性，再批量写入，读写分离 | [运行时优化导览](./02-运行时优化-导览.md) |
| 控制台报错"Can't perform state update on unmounted component" | 异步操作完成时组件已卸载，仍尝试更新状态 | 使用 useEffect cleanup 函数清理，或使用 AbortController 取消请求 | [运行时优化导览](./02-运行时优化-导览.md) |
| Web Worker 中传递大量数据后主线程仍卡顿 | postMessage 使用结构化克隆，大数据复制开销大 | 使用 Transferable Objects 转移数据所有权，或使用 SharedArrayBuffer 共享内存 | [运行时优化导览](./02-运行时优化-导览.md) |
| 所有页面都用 SSR 导致服务器负载过高 | 不必要的服务端渲染浪费服务器资源 | 根据页面特性选择渲染模式：内容型页面用 SSG，个性化页面用 SSR，后台管理用 CSR | [运行时优化导览](./02-运行时优化-导览.md) |
| useMemo 滥用导致代码可读性下降 | 对简单计算使用 useMemo，缓存开销超过计算收益 | 只在计算开销大、依赖变化频繁的场景使用 useMemo | [运行时优化导览](./02-运行时优化-导览.md) |
| 虚拟列表快速滚动时出现白屏 | 未设置缓冲区（overscan），新节点渲染跟不上滚动速度 | 设置 overscan 参数（如 react-window 的 overscanCount），预渲染额外几项 | [运行时优化导览](./02-运行时优化-导览.md) |
