# 前端性能优化 - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 首屏核心内容加载延迟，LCP 偏高 | 对 LCP 元素使用了 `loading="lazy"`，延迟了首屏核心内容的加载 | LCP 元素不使用懒加载，改用 preload 或 fetchpriority="high" 优先加载 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 页面加载时内容跳动，CLS 偏高 | 未给图片设置宽高，浏览器无法预留空间，图片加载后撑开布局 | 为所有 `<img>` 设置 width/height 属性或使用 aspect-ratio CSS | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 全局 CSS 样式在构建后丢失 | package.json 中 `sideEffects: false` 导致 CSS 文件被 Tree Shaking 移除 | 在 sideEffects 数组中排除 CSS 文件，如 `"sideEffects": ["*.css"]` | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 浏览器控制台警告 preload 资源未使用 | preload 的资源在 3 秒内未被页面消费，浪费带宽 | 只 preload 确定会立即使用的关键资源，删除未使用的 preload 声明 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| HTML 更新后用户看不到新版本 | HTML 被强缓存，浏览器不请求新版本 | HTML 使用协商缓存（Cache-Control: no-cache），JS/CSS 使用文件名哈希 + 强缓存 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 用户网络差时页面白屏 | 动态 import 未加错误处理，chunk 加载失败未被捕获 | 使用 .catch() 处理加载失败，或使用框架的错误边界组件 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 字体加载期间文字不可见（FOIT） | 未设置 font-display，浏览器默认行为是字体加载期间隐藏文字 | 设置 `font-display: swap`，立即使用后备字体，加载完成后替换 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 资源体积大于预期，压缩效果不佳 | 仅依赖 Gzip，未启用更高效的 Brotli 压缩 | Nginx/CDN 配置 Brotli 压缩，配合 vite-plugin-compression 预生成 .br 文件 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 防抖回调中获取到的值是函数创建时的旧值 | 闭包捕获了过时的变量引用 | 使用 ref 存储最新值，或使用 useCallback + useRef 组合 | [运行时优化导览](./02-运行时优化-导览.md) |
| 列表超过 1000 条时页面卡顿 | 大量 DOM 节点直接渲染导致内存占用高、渲染慢 | 使用虚拟列表（react-window 或 vue-virtual-scroller）只渲染可视区域 | [运行时优化导览](./02-运行时优化-导览.md) |
| 页面出现布局抖动（Layout Thrashing） | 频繁交替读取布局属性（offsetTop 等）和写入样式，触发强制同步布局 | 批量读取布局属性，再批量写入，读写分离 | [运行时优化导览](./02-运行时优化-导览.md) |
| 控制台报错"Can't perform state update on unmounted component" | 异步操作完成时组件已卸载，仍尝试更新状态 | 使用 useEffect cleanup 函数清理，或使用 AbortController 取消请求 | [运行时优化导览](./02-运行时优化-导览.md) |
| Web Worker 中传递大量数据后主线程仍卡顿 | postMessage 使用结构化克隆，大数据复制开销大 | 使用 Transferable Objects 转移数据所有权，或使用 SharedArrayBuffer 共享内存 | [运行时优化导览](./02-运行时优化-导览.md) |
| 所有页面都用 SSR 导致服务器负载过高 | 不必要的服务端渲染浪费服务器资源 | 根据页面特性选择渲染模式：内容型页面用 SSG，个性化页面用 SSR，后台管理用 CSR | [运行时优化导览](./02-运行时优化-导览.md) |
| useMemo 滥用导致代码可读性下降 | 对简单计算使用 useMemo，缓存开销超过计算收益 | 只在计算开销大、依赖变化频繁的场景使用 useMemo | [运行时优化导览](./02-运行时优化-导览.md) |
| 虚拟列表快速滚动时出现白屏 | 未设置缓冲区（overscan），新节点渲染跟不上滚动速度 | 设置 overscan 参数（如 react-window 的 overscanCount），预渲染额外几项 | [运行时优化导览](./02-运行时优化-导览.md) |
| 只写 `srcset` 不写 `sizes`，浏览器总是选最大的图片 | 缺少 `sizes` 时默认按 `100vw` 计算 | 补全 `sizes`，媒体条件与真实布局对齐 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 图片完全不显示 | `<picture>` 自身不渲染，必须由内部 `<img>` 承载 | 始终保留带 `alt` 的 `<img>` 兜底 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 部分用户拿到错误格式的图片 | CDN 的格式协商结果被缓存复用，未区分 `Accept` | 响应头加 `Vary: Accept` | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 老浏览器图片裂开 | 只提供了 AVIF 单一格式，Safari 16.4 以下不支持 | 用 `<picture>` + `type` 逐级降级到 WebP / JPEG | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 内联用户上传的 SVG 造成 XSS | SVG 可以包含 `<script>` | 服务端清洗后再内联，或改用 `<img src>` 引用 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 首屏被占位图拖慢 | LQIP 占位图未压缩到 1-2KB 以内 | 占位图压到约 20px 宽 + 高压缩率，或改用 BlurHash 字符串 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 字体被下载两次且控制台告警 | 字体 preload 缺少 `crossorigin`，凭据模式不一致导致 preload 未被复用 | 加 `crossorigin`（同源也要写） | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 首屏卡在字体下载 | 中文全量字体动辄 5-10MB，直接上线 | 用 `fonttools` 子集化 + `unicode-range` 拆分 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 正文文字长时间不可见（FOIT） | 正文使用了 `font-display: block`，阻塞期约 3s | 正文改用 `font-display: swap` | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 首屏带宽被字体占满 | 一次 preload 了多个字重 / 多个子集 | 只 preload 首屏必需的那一个字体文件 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 字体与设计稿不一致 | `local()` 命中了用户系统里的旧版字体 | 品牌场景去掉 `local()`，直接走网络字体 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 字体 `swap` 后布局跳动，CLS 偏高 | 后备字体与 Web 字体度量不一致 | 用 `size-adjust` / `ascent-override` 做度量覆盖 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| 子集化后部分文字显示为方框 | 构建期扫描不到运行时动态生成的字符 | 额外补一批常用字，或对动态内容使用系统字体 | [加载性能优化导览](./01-加载性能优化-导览.md) |
| INP 依旧很高，只在事件回调里做优化没用 | INP 包含输入延迟与呈现延迟，不只是回调耗时 | 用 Performance 面板做三段归因，分别处理 | [运行时优化导览](./02-运行时优化-导览.md) |
| 用 `setTimeout(0)` 做大量分片后总耗时成倍增长 | 每个分片至少多等 1-4ms 且会被插队 | 改用 `scheduler.yield()`，并保留 `setTimeout` 降级 | [运行时优化导览](./02-运行时优化-导览.md) |
| 在 `startTransition` 里做同步重计算，输入依旧卡顿 | 并发特性只让渲染可中断，不会切碎同步计算 | 重计算移到 Web Worker，或按时间片拆分 | [运行时优化导览](./02-运行时优化-导览.md) |
| 认为 `requestIdleCallback` 一定会执行，任务长时间不执行 | 只在浏览器空闲时触发，交互密集时不空闲 | 用 `timeout` 兜底，或改用 `scheduler.postTask` | [运行时优化导览](./02-运行时优化-导览.md) |
| 把 50ms 当成优化目标值 | 50ms 是长任务的定义线，不是目标 | 单次任务控制在 50ms 以内，交互路径上尽量压到 20ms 以内 | [运行时优化导览](./02-运行时优化-导览.md) |
| 本地流畅，用户侧 INP 却很差 | 只测了桌面端，移动端 CPU 性能远低于桌面端 | 用 CPU 节流（4x-6x）或真机测试 | [运行时优化导览](./02-运行时优化-导览.md) |
| 首屏点击无响应 | 首屏 JS 执行本身就是长任务 | 用 `loadState` 区分归因，优化首屏 JS 执行与代码分割 | [运行时优化导览](./02-运行时优化-导览.md) |
| 关键更新被延后 | `postTask` 优先级用错，把关键更新标成了 `background` | 按语义选择：`user-blocking` 关键、`user-visible` 默认、`background` 可延后 | [运行时优化导览](./02-运行时优化-导览.md) |
| 移动端内存暴涨、页面被系统回收 | 给大量元素加了 `will-change`，每个合成层都要独立内存缓冲 | 只对即将动画的元素临时加，动画结束立即移除 | [运行时优化导览](./02-运行时优化-导览.md) |
| 移动端滚动迟滞、掉帧 | 滚动监听未声明 `passive`，浏览器必须等监听器执行完才能滚动 | 加 `{ passive: true }`，或改用 `touch-action` | [运行时优化导览](./02-运行时优化-导览.md) |
| 手势响应变慢 | 用 JS `preventDefault()` 阻止滚动，手势处理被拉到主线程 | 改用 CSS `touch-action` / `overscroll-behavior` | [运行时优化导览](./02-运行时优化-导览.md) |
| 移动端点击有 300ms 延迟，布局缩放异常 | 缺少 viewport 声明，浏览器保留双击缩放判定 | 设置 `width=device-width, initial-scale=1` | [运行时优化导览](./02-运行时优化-导览.md) |
| 移动端滚动时明显掉帧 | 大面积 `backdrop-filter` 的合成与绘制填充率开销极高 | 低端机降级为半透明纯色背景 | [运行时优化导览](./02-运行时优化-导览.md) |
| 用模拟器测性能，结论与真机严重不符 | 模拟器使用桌面 CPU 与 GPU | 性能结论以真机为准，配合 CPU / 网络节流 | [运行时优化导览](./02-运行时优化-导览.md) |
| 图片模糊或体积过大 | 忽略 DPR 影响，同等 CSS 尺寸下移动端像素数是桌面端的 2-4 倍 | 用 `srcset` + `sizes` 按 DPR 选择资源 | [运行时优化导览](./02-运行时优化-导览.md) |
| 新 API 在 App 内直接报错 | 假设 WebView 内核是最新版，实际内核跟随宿主 App 打包版本 | 明确最低内核版本，使用前做特性检测并降级 | [运行时优化导览](./02-运行时优化-导览.md) |
| Server Component 中使用 `useState` 编译报错 | 服务端组件运行在服务端，无法保持客户端状态 | 把需要交互的部分提取为客户端组件，并在文件顶部加 `'use client'` | [渲染架构深度导览](./04-渲染架构深度-导览.md) |
| ISR `revalidate` 设置过短导致服务器 CPU 飙升、构建队列堆积 | revalidate 间隔短于实际构建时间，上一个构建未完成下一个已触发 | 确保 revalidate 间隔 > 页面构建时间；用 On-Demand Revalidation 替代定时重新生成 | [渲染架构深度导览](./04-渲染架构深度-导览.md) |
| Streaming 未设置 Suspense 边界，整个页面等待最慢组件 | 没有 Suspense 边界时，整页必须等所有异步组件渲染完才发送 | 用 Suspense 包裹每个异步组件并配骨架屏；优先发送静态外壳，动态内容逐步填充 | [渲染架构深度导览](./04-渲染架构深度-导览.md) |
