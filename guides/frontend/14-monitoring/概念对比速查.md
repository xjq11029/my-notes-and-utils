## 一、监控方案对比

| 维度 | Sentry | 自建 SDK | Datadog RUM |
|---|---|---|---|
| 部署方式 | SaaS / 私有化部署 | 自建 | SaaS |
| 错误监控 | 优秀（fingerprint 分组、Sourcemap 还原） | 定制化程度高 | 优秀 |
| 性能监控 | 良好（Tracing） | 灵活（可自定义指标） | 优秀（RUM + APM 联动） |
| Session Replay | 支持 | 需自建 | 支持 |
| 成本 | 免费版有限制，付费版按事件量计费 | 开发成本高，运维成本可控 | 按数据量计费，价格较高 |
| 接入难度 | 低（5 分钟接入） | 高（需要前后端开发） | 中 |
| 数据隐私 | 数据存储在 Sentry 服务器 | 数据完全自主可控 | 数据存储在 Datadog 服务器 |
| 社区生态 | 活跃，文档完善 | 无 | 活跃，企业级支持 |
| 适用场景 | 中小团队快速接入 | 大厂、数据合规要求高 | 已有 Datadog 基础设施的企业 |

**选择建议**：
- 中小团队、快速接入 → **Sentry**
- 大厂、数据合规要求高、需要深度定制 → **自建 SDK**
- 已有 Datadog 基础设施、需要前后端全链路 → **Datadog RUM**

## 二、部署策略对比

| 维度 | 灰度发布（Canary） | 蓝绿部署（Blue-Green） | 滚动更新（Rolling Update） |
|---|---|---|---|
| 原理 | 新版本部署到少量实例，逐步增加流量比例 | 维护两套完整环境，切换流量瞬间完成 | 逐个替换运行实例 |
| 回滚速度 | 中（修改流量比例） | 快（秒级切换） | 慢（逐个回滚） |
| 资源成本 | 低（极少额外资源） | 高（资源翻倍） | 低（无额外资源） |
| 停机时间 | 无 | 无 | 无 |
| 观察期 | 长（逐步放量） | 短（切换后观察） | 中（替换过程中观察） |
| 新旧版本混用 | 有（灰度期间） | 无（瞬间切换） | 有（短暂混用） |
| 数据库兼容性 | 需要向后兼容 | 需要向后兼容 | 需要向后兼容 |
| 适用场景 | 重大功能上线、高风险变更 | 对可用性要求极高的服务 | 常规版本迭代、K8s 集群 |

**选择建议**：
- 重大功能上线、需要逐步验证 → **灰度发布**
- 核心服务、不能有任何风险 → **蓝绿部署**
- 常规迭代、资源有限 → **滚动更新**

## 三、上报方式对比

| 维度 | sendBeacon | fetch keepalive | img beacon |
|---|---|---|---|
| 请求方法 | 仅 POST | GET/POST/PUT/DELETE | 仅 GET |
| 数据量限制 | 无限制 | 64KB（Chrome 限制） | ~2KB（URL 长度限制） |
| 跨域支持 | 需 CORS | 需 CORS | 天然支持 |
| 页面卸载可靠性 | 高（浏览器保证） | 中（需 keepalive 标志） | 中（可能被取消） |
| 响应处理 | 不返回响应 | 可获取响应 | 不返回响应 |
| 浏览器兼容 | Chrome 39+、不支持 IE | Chrome 66+（keepalive） | 全兼容 |
| 适用场景 | 页面卸载、批量上报 | 正常运行时上报 | 简单埋点、跨域场景 |

**选择建议**：
- 页面卸载时保证送达 → **sendBeacon**
- 正常运行时，需要 POST 大数据 → **fetch keepalive**
- 简单跨域场景、极致兼容性 → **img beacon**

## 四、Feature Flags 工具对比

| 维度 | LaunchDarkly | Unleash | Flagsmith |
|---|---|---|---|
| 部署方式 | SaaS | 自建 / SaaS | 自建 / SaaS |
| 开源 | 否 | 是（Apache 2.0） | 是（BSD 3-Clause） |
| Flag 类型 | 布尔、多变量、JSON | 布尔、多变量 | 布尔、多变量 |
| 用户分群 | 丰富（属性、行为、百分比） | 策略驱动（逐步放量、用户 ID、自定义） | 基于特征（Trait） |
| A/B 测试 | 内置 | 通过变体支持 | 通过多变量支持 |
| 实时更新 | WebSocket 实时推送 | WebSocket 实时推送 | 轮询 / SSE |
| SDK 语言 | 多语言（20+） | 多语言（15+） | 多语言（10+） |
| 成本 | 付费（按 MAU 计费） | 免费（自建）/ 付费（SaaS） | 免费（自建）/ 付费（SaaS） |
| 适用场景 | 企业级、需要高级分析 | 中小团队、预算有限 | 中等规模、需要灵活性 |

**选择建议**：
- 企业级、预算充足 → **LaunchDarkly**
- 中小团队、追求性价比 → **Unleash**
- 需要灵活部署方式 → **Flagsmith**
