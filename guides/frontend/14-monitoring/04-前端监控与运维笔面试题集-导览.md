# 04-前端监控与运维笔面试题集 - 导览

---

## 选择题部分（20 题）

| 维度 | 内容 |
|---|---|
| 是什么 | 20 道选择题覆盖前端监控（4 题：错误捕获 / Core Web Vitals / sendBeacon / Promise 异常）、部署策略（3 题：灰度与蓝绿 / Feature Flags / Nginx 分流）、可观测性（3 题：三支柱 / Trace Context / 告警策略）、补充的埋点体系（5 题：三种埋点方式 / 曝光埋点 / 点击埋点 / 数据模型 / 线上排查）、A/B 实验与上报可靠性（5 题：分流哈希 / 分层正交 / 卸载上报 / 上报方式 / 采样策略），每题附逐项解析 |
| 能做什么 | 快速检验对前端监控与运维核心概念的掌握程度；模拟面试中的选择题环节；识别常见误区（如"随机数可以用于分流""threshold 不需要包含 0"） |
| 怎么用 | 先独立完成所有题目，再对照解析检查答案，标记错题重点复习对应原理章节 |
| 原理和工作流程 | 每道题考查一个核心知识点，解析中说明正确选项的原因和错误选项的误区，并标注难度（★/★★/★★★） |
| 缺点 | 选择题只能覆盖知识点，无法考察实际编码和架构设计能力 |

## 简答题部分（15 题）

| 维度 | 内容 |
|---|---|
| 是什么 | 15 道简答题覆盖监控 SDK 架构设计、Sourcemap 安全使用、Feature Flags 类型、部署策略对比、白屏检测、可观测性三支柱、告警策略设计、链路追踪实现，以及新增的埋点三种方式与选型、曝光埋点原理、全站点击埋点、埋点质量保障、A/B 实验分流与分层正交、SRM 排查与预防、页面关闭上报与离线补发 |
| 能做什么 | 模拟面试中的简答环节；提供标准化的答题要点和思路；补齐 01 补充埋点章节与 05 新章节的知识缺口 |
| 怎么用 | 先尝试口头回答，再对照答案要点补充遗漏，反复练习直到流畅表达 |
| 原理和工作流程 | 每道题从"是什么"、"为什么"、"怎么做"三个维度组织答案，辅以对比表格、判定清单与代码要点 |
| 缺点 | 简答题答案仅供参考，实际面试中需要结合项目经验展开 |
