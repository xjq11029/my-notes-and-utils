# JavaScript核心 - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 变量提升导致变量未定义报错 | 使用var声明变量不注意提升规则 | 使用let/const替代var；let/const 在块级作用域下存在提升但受 TDZ（暂时性死区）限制，声明前访问会报错 | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| 闭包导致循环变量引用错误 | 循环中创建闭包引用了同一个变量引用 | 使用let声明循环变量，每个迭代都会创建新的绑定 | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| 原型链修改不当导致继承失效 | 直接重写原型会丢失constructor | 修正constructor指向或增量修改原型而不重写 | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| 忽略this绑定规则导致this指向错误 | 不理解箭头函数绑定规则和隐式绑定丢失 | 使用箭头函数、bind/call/apply显式绑定，或箭头函数不绑定this | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| typeof null错误判断为object | JavaScript历史遗留问题 | 使用Array.isArray、Object.prototype.toString.call判断类型 | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| 忽略分号导致ASI自动插入错误 | 行首是(或[等字符时ASI不插入分号 | 不要省略必要分号，或者明确了解ASI规则 | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| 回调地狱嵌套过深难以维护 | 多个异步操作层层嵌套导致代码横向发展 | 使用Promise链式调用，最终改用async/await扁平化 | [异步编程与ES6+特性导览](./02-异步编程与ES6+特性-导览.md) |
| Promise.then中未返回新Promise导致链式断裂 | 忘记返回Promise导致后续then无法接收结果 | 在then中显式return新Promise保持链式调用 | [异步编程与ES6+特性导览](./02-异步编程与ES6+特性-导览.md) |
| async函数中忘记await导致Promise未执行 | async函数默认返回Promise但未等待 | 需要等待异步结果时必须添加await关键字 | [异步编程与ES6+特性导览](./02-异步编程与ES6+特性-导览.md) |
| 解构赋值默认值使用不当 | 混淆undefined和null对默认值的影响 | 只有严格等于undefined时才会使用默认值 | [异步编程与ES6+特性导览](./02-异步编程与ES6+特性-导览.md) |
| 箭头函数误用导致this指向错误 | 箭头函数不绑定this，继承外层词法作用域 | 需要动态this时（如对象方法、构造函数）不使用箭头函数 | [异步编程与ES6+特性导览](./02-异步编程与ES6+特性-导览.md) |
| 扩展运算符拷贝对象不完全深拷贝 | 扩展运算符只能做浅拷贝，嵌套对象仍引用原对象 | 对于嵌套对象需要递归拷贝或使用structuredClone | [异步编程与ES6+特性导览](./02-异步编程与ES6+特性-导览.md) |
| 防抖节流使用时机错误导致性能问题 | 将防抖当节流或反过来使用 | 频繁触发需要最后一次执行用防抖，需要固定间隔执行用节流 | [常用API与手写原理导览](./03-常用API与手写原理-导览.md) |
| 柯里化参数收集不完全导致函数不执行 | 柯里化需要判断参数数量是否足够 | 使用闭包保存参数，参数足够时才执行原函数 | [常用API与手写原理导览](./03-常用API与手写原理-导览.md) |
| EventEmitter内存泄漏未移除监听 | 添加监听后不再使用但没有移除 | 不再使用的事件监听器需要调用removeListener移除 | [常用API与手写原理导览](./03-常用API与手写原理-导览.md) |
| JSON.stringify循环引用报错 | 对象存在循环引用无法序列化 | 使用WeakMap检测循环引用，使用第三方库处理循环引用 | [常用API与手写原理导览](./03-常用API与手写原理-导览.md) |
| new Promise构造函数中throw错误未捕获 | Promise内部抛出错误会被捕获变为reject | 需要在链式调用末尾添加catch捕获错误 | [JavaScript核心笔面试题集导览](./04-JavaScript核心笔面试题集-导览.md) |
| typeof不能正确识别所有类型 | 对于null、数组、对象都返回object | 使用Array.isArray判断数组，使用typeof判断基础类型 | [JavaScript核心笔面试题集导览](./04-JavaScript核心笔面试题集-导览.md) |
| 浅拷贝后修改原对象也被修改 | 浅拷贝只复制引用不复制嵌套对象 | 使用JSON.parse(JSON.stringify)或structuredClone做深拷贝 | [JavaScript核心笔面试题集导览](./04-JavaScript核心笔面试题集-导览.md) |
| 在声明前使用 `let`/`const` 变量报 ReferenceError | 暂时性死区（TDZ），声明前访问直接抛错 | 始终先声明后使用，把声明提到作用域顶部 | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| `const` 声明的对象属性被意外修改 | `const` 只锁定引用，不冻结对象内容 | 需要真正不可变时使用 `Object.freeze()` | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| `switch` 的多个 case 中重复声明 `let` 报 SyntaxError | 所有 case 共享同一个块级作用域 | 为每个 case 添加 `{}` 包裹成独立块 | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| 递归过深报 `RangeError: Maximum call stack size exceeded` | 调用栈超出浏览器限制 | 改用迭代，或使用尾递归优化 | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| 混淆 `prototype` 和 `__proto__`，原型链指向错误 | 前者是函数独有的属性，后者是对象独有的属性 | 记住：`prototype` 是函数属性，`__proto__` 是对象属性 | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| 原型上的引用类型属性被所有实例共享 | 引用类型属性定义在原型上，实例间共享同一份引用 | 把引用类型属性放在构造函数内部初始化 | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| `for...in` 遍历到不期望的原型属性 | `for...in` 会沿原型链遍历可枚举属性 | 用 `hasOwnProperty` 过滤，或改用 `Object.keys` | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| `setTimeout` 回调中 `this` 指向 `window` | 隐式绑定丢失 | 使用箭头函数或 `bind` 固定 this | [语法基础与执行机制导览](./01-语法基础与执行机制-导览.md) |
| 回调中 `throw` 的错误无法被外层 `try/catch` 捕获 | 回调在下一个 tick 执行，已脱离当前 try 块 | 改用 Promise 的 reject 或 async/await 传播错误 | [异步编程与ES6+特性导览](./02-异步编程与ES6+特性-导览.md) |
