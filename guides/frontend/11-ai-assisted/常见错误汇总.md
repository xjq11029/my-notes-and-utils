# AI 辅助开发 - 常见错误汇总

> 模块：11-ai-assisted | 共 28 条常见错误

| 编号 | 错误现象 | 错误原因 | 正确做法 | 关联导览 |
|:--:|---------|---------|---------|---------|
| 1 | AI 生成的代码运行报错"xxx is not defined" | AI 胡编了不存在的 API 或变量名 | 在 Prompt 中约束 API 使用范围，运行前检查 import 是否正确 | [Prompt 工程-导览](./02-Prompt工程与代码生成-导览.md) |
| 2 | 搜索框输入后显示上一次搜索的结果 | 未使用 AbortController 取消旧请求，新请求先返回但旧请求后覆盖 | 使用 AbortController + cleanup 取消旧请求 | [AI 代码审查-导览](./03-AI代码审查与质量管控-导览.md) |
| 3 | 组件卸载后控制台报"Can't perform a React state update" | useEffect 中未返回 cleanup 函数，异步操作完成后尝试 setState 到已卸载组件 | useEffect 中使用 ignore 标记或 AbortController | [AI 代码审查-导览](./03-AI代码审查与质量管控-导览.md) |
| 4 | AI 使用 Vue 2 语法（如 this.$set）在 Vue 3 项目中 | 训练数据中 Vue 2 内容占比高，AI 未感知当前项目版本 | Prompt 中明确指定"Vue 3.4+，使用 `<script setup>` 语法" | [Prompt 工程-导览](./02-Prompt工程与代码生成-导览.md) |
| 5 | AI 生成的代码中充满 `any` 类型 | 未在 Prompt 中要求 TypeScript 严格模式 | 在 Prompt 和项目规则中明确要求"禁用 any 类型" | [Prompt 工程-导览](./02-Prompt工程与代码生成-导览.md) |
| 6 | 快速点击提交按钮导致表单重复提交 | AI 未生成防重复提交逻辑 | 添加 loading 状态，提交中禁用按钮 | [AI 代码审查-导览](./03-AI代码审查与质量管控-导览.md) |
| 7 | 代码中包含 `debugger` 语句或无限循环 | AI 从训练数据中学习了防调试代码 | ESLint `no-debugger` 规则 + CI 扫描拦截 | [AI 代码审查-导览](./03-AI代码审查与质量管控-导览.md) |
| 8 | AI 生成的 Prompt 太长导致关键约束被忽略 | 上下文窗口有限，长 Prompt 末尾内容可能被遗忘 | 将关键约束放在 Prompt 开头和结尾，使用分步策略 | [Prompt 工程-导览](./02-Prompt工程与代码生成-导览.md) |
| 9 | Cursor Agent 生成的文件结构不符合项目规范 | 未配置 `.cursorrules` 项目规则文件 | 在项目根目录创建 `.cursorrules` 文件定义规范 | [AI 编程工具-导览](./01-AI编程工具与工作流-导览.md) |
| 10 | AI 生成的 import 路径不存在 | AI 猜想了模块路径而非读取实际项目结构 | 使用 @file 引用提供项目文件结构上下文 | [AI 编程工具-导览](./01-AI编程工具与工作流-导览.md) |
| 11 | 自定义 ESLint 规则产生大量误报 | 黑名单模式过于宽泛或白名单不完整 | 逐步添加 blockedPatterns，提供 allowedAPIs 白名单 | [AI 代码审查-导览](./03-AI代码审查与质量管控-导览.md) |
| 12 | AI 审查报告过于冗长，淹没关键问题 | Prompt 未限制输出范围和优先级 | 在审查 Prompt 中要求"只报告严重和高优先级问题" | [AI 代码审查-导览](./03-AI代码审查与质量管控-导览.md) |
| 13 | AI 生成的代码看起来正确但实际运行出错 | AI 基于训练数据生成，不保证运行时正确 | 必须运行测试验证，不要直接合并 AI 生成的代码 | [AI 编程工具-导览](./01-AI编程工具与工作流-导览.md) |
| 14 | AI 编造了不存在的第三方库或包名 | 训练数据包含虚构或过时内容 | 限定允许使用的库列表，要求 AI 引用来源 | [Prompt 工程-导览](./02-Prompt工程与代码生成-导览.md) |
| 15 | AI 生成的页面没有 loading、错误提示和空状态 | AI 默认生成"快乐路径"代码 | 在 Prompt 中要求"必须包含 loading、error、empty 三种状态" | [Prompt 工程-导览](./02-Prompt工程与代码生成-导览.md) |
| 16 | Few-shot 示例被 AI 原样复制到业务代码里 | 示例与任务过于相似，AI 把示例内容当成了答案 | 使用不同领域的示例，让示例只体现"格式"而非"内容" | [Prompt 工程-导览](./02-Prompt工程与代码生成-导览.md) |
| 17 | 长对话进行到一半时 AI 违反了最初定下的约束 | 上下文窗口限制导致早期约束被挤出 | 在每轮对话开始时重申关键约束，或用规则文件固化 | [Prompt 工程-导览](./02-Prompt工程与代码生成-导览.md) |
| 18 | 复杂表单一次性生成，AI 抓不住重点、反复漏字段 | 单个 Prompt 信息密度过高 | 拆解为多个子 Prompt 分步生成（先结构、再校验、最后样式） | [Prompt 工程-导览](./02-Prompt工程与代码生成-导览.md) |
| 19 | 用 AbortController 取消了请求，控制台仍报卸载后 setState | 只调用了 abort()，未在 `.then` 中检查 `signal.aborted` | 在回调中显式判断 `if (controller.signal.aborted) return` | [AI 代码审查-导览](./03-AI代码审查与质量管控-导览.md) |
| 20 | 静态 AST 规则通过，但线上仍出现运行时崩溃 | AST 是静态分析，检测不到动态代码与运行时行为 | 结合单元测试和 E2E 测试覆盖运行时场景 | [AI 代码审查-导览](./03-AI代码审查与质量管控-导览.md) |
| 21 | 团队把 AI 生成的防调试代码当成正常业务逻辑合并了 | 审查者不熟悉防调试代码模式 | 按检查清单逐项排查（debugger、死循环、环境判断后自毁） | [AI 代码审查-导览](./03-AI代码审查与质量管控-导览.md) |
| 22 | MCP Server 连上后立即断开，提示协议解析失败 | stdio 传输下 stdout 是协议通道，Server 却往 stdout 打了日志 | 所有日志改写到 stderr（用 `console.error`） | [MCP 协议与 Agent 工作流-导览](./05-MCP协议与Agent工作流-导览.md) |
| 23 | Agent 频繁选错工具或传错参数 | 工具描述写得含糊，而工具描述本身就是 Prompt | 描述中写明使用时机、返回边界、与相似工具的区别 | [MCP 协议与 Agent 工作流-导览](./05-MCP协议与Agent工作流-导览.md) |
| 24 | Agent 一次工具调用就把上下文吃满，后续推理丢失约束 | 工具直接返回超长内容，全量进上下文 | 只返回关键字段的紧凑 JSON，超长时截断并附提示 | [MCP 协议与 Agent 工作流-导览](./05-MCP协议与Agent工作流-导览.md) |
| 25 | Agent 陷入死循环，token 成本失控 | 没有终止条件，缺少步数上限 | 设 `maxSteps`（8-15），超限升级为人工确认（HITL） | [MCP 协议与 Agent 工作流-导览](./05-MCP协议与Agent工作流-导览.md) |
| 26 | Agent 工具调用失败后直接中断，无法自我修正 | 错误信息没有回填上下文，Agent 看不到失败原因 | 把错误作为 Observation 回填，重试时附上失败原因 | [MCP 协议与 Agent 工作流-导览](./05-MCP协议与Agent工作流-导览.md) |
| 27 | 上下文压缩后 Agent 违反"不要修改 XX 文件"的要求 | 摘要 Prompt 未要求保留约束 | 在摘要 Prompt 中明确列出必须保留的内容（决策、待办、文件路径、禁忌） | [MCP 协议与 Agent 工作流-导览](./05-MCP协议与Agent工作流-导览.md) |
| 28 | AI 流式输出时页面卡顿、掉帧 | 按 token 直接更新视图，token 到达频率远高于帧率 | 用 `requestAnimationFrame` 节流，每帧最多更新一次 | [MCP 协议与 Agent 工作流-导览](./05-MCP协议与Agent工作流-导览.md) |
