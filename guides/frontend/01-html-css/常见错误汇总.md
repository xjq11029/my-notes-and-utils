# HTML与CSS - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 使用已弃用的HTML标签或属性 | 不了解HTML5标准变化，沿用旧写法 | 查阅HTML5规范，用语义化标签替代div嵌套，用CSS替代表现型标签 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 滥用div标签导致页面结构混乱 | 不了解语义化标签的用途 | 使用header/nav/main/article/section/footer等语义化标签构建页面骨架 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 表单缺少name属性导致后端无法获取数据 | 忘记给表单控件添加name属性 | 每个需要提交的表单控件必须添加name属性 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 图片缺少alt属性影响可访问性 | 忽视无障碍访问规范 | 为所有img标签添加有意义的alt属性，装饰性图片使用空字符串 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 链接使用空的href="#"而不是语义正确的URL | 占位链接填写不当 | 使用真实的URL，或使用href="javascript:void(0)"配合按钮角色 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 浮动元素未清除导致父容器高度塌陷 | 使用float布局后忘记清除浮动 | 使用clearfix清除浮动，或改用flex/grid布局替代float | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 盒模型计算错误导致元素宽度超出预期 | 混淆content-box和border-box模式 | 统一使用box-sizing: border-box，让宽度包含padding和border | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 外边距合并导致间距异常 | 不了解垂直外边距合并规则 | 使用padding代替外边距，或使用border/padding触发BFC隔离 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 绝对定位元素参照物错误 | 忘记给父元素设置position: relative | 绝对定位元素的参照物是最近的非static定位祖先元素 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| z-index层级混乱不生效 | 不了解层叠上下文规则 | 确保元素处于同一层叠上下文中，或创建新的层叠上下文 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 频繁逐条修改DOM样式导致卡顿 | 每次样式修改都可能触发重排 | 使用className批量修改样式，避免逐条修改style属性 | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 循环中读取offsetWidth触发强制同步回流 | 读取布局属性时浏览器强制同步计算 | 先统一读取所有尺寸，再统一修改样式，避免读写交替 | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 使用top/left做动画导致频繁重排 | top/left修改触发Layout阶段 | 使用transform和opacity做动画，利用合成线程跳过Layout和Paint | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 过渡效果不起作用或动画卡顿 | 未正确设置过渡属性或动画性能不佳 | 确保变化属性可过渡，使用will-change提示浏览器优化，优先使用transform | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 媒体查询断点选择不当导致响应式失效 | 不了解常见设备断点范围 | 使用移动优先策略，从最小屏幕开始设计，逐步增加断点 | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 选择器权重计算错误导致样式覆盖混乱 | 不了解CSS选择器优先级计算规则 | 使用BEM命名规范降低选择器嵌套深度，避免滥用!important | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| vh/vw单位在移动端出现滚动条导致布局异常 | 移动端浏览器的地址栏会影响vh计算 | 使用dvh（动态视口高度）或使用百分比布局替代vh | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 动画结束后状态回弹 | 未设置animation-fill-mode | 设置animation-fill-mode: forwards保持动画结束状态 | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 移动端页面被缩放，字号与设计稿不符 | 缺少 `<meta name="viewport">` 声明 | 在 `<head>` 中添加 `width=device-width, initial-scale=1` 的 viewport meta | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| SEO 评分因标题层级扣分 | 页面出现多个 `h1`，标题层级跳跃 | 每个页面只保留一个 `h1` 作主标题，其余按 `h2`~`h6` 递进 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 大体积 script 放在 head 中导致首屏白屏时间长 | 浏览器解析到 script 标签会暂停 DOM 构建 | 使用 `defer`，或把 script 放到 body 底部 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 加了 padding 后元素变宽撑破布局 | 默认 `content-box`，padding 在宽度之外额外增加 | 全局设置 `*, *::before, *::after { box-sizing: border-box; }` | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| Flex 布局中 align-items 不生效 | 交叉轴方向没有可用空间，容器高度未确定 | 给 Flex 容器设置明确的高度，或改用 `align-content` | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| `position: sticky` 不生效，元素不粘顶 | 祖先元素设置了 `overflow: hidden/auto/scroll`，sticky 需要滚动容器 | 确保 sticky 元素的祖先链上没有 overflow 裁剪 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 用 margin 累加做列表间距，间距比预期小 | 相邻兄弟的 `margin` 发生合并，取较大者 | 改用 Flex/Grid 的 `gap` 统一间距 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 子元素 `margin-top` 顶不动，父元素整体下移 | 父子外边距合并 | 父元素加 `display: flow-root` 或 `padding-top` | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 用 `overflow: hidden` 解决外边距合并后下拉菜单被裁 | `overflow: hidden` 会裁剪溢出内容，只是掩盖了问题 | 改用 `display: flow-root` 触发 BFC 且不裁剪 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 用 `!important` 堆叠解决覆盖问题，样式表越来越难维护 | 误以为 `!important` 提升权重，实际是改变级联层级 | 用 `@layer` 管理层级或提高选择器权重，只在覆盖第三方库时使用 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 以为 `:is(.a, .b)` 权重是 `(0,2,0)` | `:is()` 只取参数中权重最高者，不累加 | 需要高权重时显式写出选择器，理解"取最高"规则 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 用通配符重置样式后全局字号、颜色继承失效 | 通配符是直接声明，会覆盖继承值 | 通配符只用于 `box-sizing`、`margin: 0` 等，避免设置可继承属性 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 在容器上随意使用 `transform` 导致弹窗被遮挡、fixed 失效 | `transform` 同时创建层叠上下文和包含块 | 动画元素与定位容器分离，或把弹窗渲染到 `body` 下 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 用 `z-index: -1` 让元素垫底，元素直接消失 | 负 `z-index` 位于背景层，被父级/祖先背景遮挡 | 改为 `z-index: 0` 并调整背景层级，或给元素设置背景 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 加 `will-change` 做优化后层级错乱 | `will-change: transform` 会创建层叠上下文 | 动画结束后移除 `will-change`，或用 `isolation` 统一管理 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 嵌套元素字号越来越大 | `em` 参照父元素，多层嵌套会累积 | 使用 `rem` 替代 `em`，或仅在浅层嵌套使用 `em` | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 大量使用 `box-shadow` 做动画时卡顿 | `box-shadow` 触发重绘，开销大 | 用伪元素 + `opacity` 模拟阴影动画 | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 用 `@import` 引入 CSS 导致页面加载变慢 | `@import` 会阻塞并行下载 | 使用 `<link>` 标签替代 `@import` | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 物理属性与逻辑属性混用，某个方向的样式"莫名其妙"失效 | 两者映射到同一物理属性，后声明覆盖前者 | 同一组件内统一使用一套写法（全物理或全逻辑） | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| `clamp(MIN, VAL, MAX)` 写成 MIN > MAX，尺寸恒定不变 | `clamp()` 等价于 `max(MIN, min(VAL, MAX))`，MIN 最终胜出 | 检查参数顺序，保证 `MIN <= MAX` | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 用纯 `vw` 做字号，用户放大浏览器字号无效 | `vw` 与视口绑定，不响应默认字号变化 | 首选值用 `rem + vw` 混合表达式，如 `clamp(1rem, 4vw + 8px, 3rem)` | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 用 `clamp()` 替代所有断点，移动端布局结构未变只是元素变小 | `clamp()` 只控制尺寸，不改变布局结构 | 布局结构变化仍用媒体查询或 Container Queries | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 全局把动效时长设为 `0s`，依赖 `transitionend` 的逻辑失效 | `0s` 不触发过渡事件 | 使用 `0.01ms` 而非 `0s`，并同时设置 `animation-iteration-count: 1` | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 减弱动效时把 `scroll-behavior: smooth` 漏掉，长距离滚动引起不适 | 平滑滚动也属于动效 | 在 `prefers-reduced-motion: reduce` 分支中把 `scroll-behavior` 重置为 `auto` | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 同时写标准滚动条属性与 WebKit 伪元素，圆角、悬停色不生效 | Chrome 中标准属性优先，WebKit 伪元素被忽略 | 用 `@supports not selector(::-webkit-scrollbar)` 分流两套写法 | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 用 `overflow: overlay` 隐藏滚动条占位，样式不生效 | `overflow: overlay` 已被废弃 | 改用 `scrollbar-gutter: stable` | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| Tailwind 中拼接类名后样式不生效 | 构建期静态扫描无法识别拼接结果 | 用完整类名映射表或 `safelist` 声明 | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 运行时 CSS-in-JS 未做 SSR 提取，首屏闪烁（FOUC） | 样式在客户端 JS 执行后才注入 | 配置关键 CSS 提取，如 emotion 的 `extractCritical` | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 在 RSC 中使用运行时 CSS-in-JS，构建报错或样式丢失 | RSC 不支持 `useInsertionEffect`、Context 等客户端能力 | 改用 CSS Modules / Tailwind / vanilla-extract | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| Canvas 图形变形或被裁剪 | CSS 设置宽高不等于 Canvas 像素尺寸，默认 300x150 | 在 `<canvas>` 标签上设置 `width` 和 `height` 属性 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| Canvas 在高 DPI 屏幕绘制内容模糊 | 设备像素比 > 1，Canvas 未做适配 | 宽高乘以 `devicePixelRatio`，再用 CSS 缩回显示尺寸 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 动态创建的 SVG 元素不显示 | 使用 `createElement` 而非 `createElementNS`，命名空间错误 | 用 `document.createElementNS('http://www.w3.org/2000/svg', 'rect')` | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 页面加载时所有空必填字段都显示红色错误 | `:invalid` 在页面加载时立即生效 | 使用 `:user-invalid`，或通过 JS 添加 `.touched` 类控制 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 使用正数 `tabindex` 后 Tab 导航顺序混乱 | 正数 tabindex 覆盖了 DOM 自然顺序 | 只使用 `tabindex="0"` 或 `-1`，避免正数 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 屏幕阅读器不朗读错误提示 | 输入框与错误提示元素之间没有建立关联 | 为 `<input>` 添加 `aria-describedby="errorId"`，错误提示元素设置对应 `id` | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| Skip Link 键盘用户无法访问 | `display: none` 会把元素从可访问性树中移除 | 用 `position:absolute; top:-100px` 配合 `:focus { top: 0 }` 实现 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
