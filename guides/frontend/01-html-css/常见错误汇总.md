# HTML与CSS - 常见错误汇总

> 汇总本模块所有知识点的常见错误，从各源文件避坑指南提取。

---

| 错误现象 | 产生原因 | 正确做法 | 关联导览 |
|---------|---------|---------|---------|
| 使用已弃用的HTML标签或属性 | 不了解HTML5标准变化，沿用旧写法 | 查阅HTML5规范，用语义化标签替代div嵌套，用CSS替代表现型标签 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 滥用div标签导致页面结构混乱 | 不了解语义化标签的用途 | 使用header/nav/main/article/section/footer等语义化标签构建页面骨架 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 表单缺少name属性导致后端无法获取数据 | 忘记给表单控件添加name属性 | 每个需要提交的表单控件必须添加name属性 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 图片缺少alt属性影响可访问性 | 忽视无障碍访问规范 | 为所有img标签添加有意义的alt属性，装饰性图片使用空字符串 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 链接使用空的href="#"而不是语义正确的URL | 占位链接填写不当 | 使用真实的URL，或使用href="javascript:void(0)"配合按钮角色 | [HTML核心与语义化导览](./01-HTML核心与语义化-导览.md) |
| 浮动元素未清除导致父容器高度塌陷 | 使用float布局后忘记清除浮动 | 使用clearfix清除浮动，或改用flex/grid布局替代float | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 盒模型计算错误导致元素宽度超出预期 | 混淆content-box和border-box模式 | 统一使用box-sizing: border-box，让宽度包含padding和border | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 外边距合并导致间距异常 | 不了解垂直外边距合并规则 | 使用padding代替外边距，或使用border/padding触发BFC隔离 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 绝对定位元素参照物错误 | 忘记给父元素设置position: relative | 绝对定位元素的参照物是最近的非static定位祖先元素 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| z-index层级混乱不生效 | 不了解层叠上下文规则 | 确保元素处于同一层叠上下文中，或创建新的层叠上下文 | [CSS布局核心导览](./02-CSS布局核心-导览.md) |
| 频繁逐条修改DOM样式导致卡顿 | 每次样式修改都可能触发重排 | 使用className批量修改样式，避免逐条修改style属性 | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 循环中读取offsetWidth触发强制同步回流 | 读取布局属性时浏览器强制同步计算 | 先统一读取所有尺寸，再统一修改样式，避免读写交替 | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 使用top/left做动画导致频繁重排 | top/left修改触发Layout阶段 | 使用transform和opacity做动画，利用合成线程跳过Layout和Paint | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 过渡效果不起作用或动画卡顿 | 未正确设置过渡属性或动画性能不佳 | 确保变化属性可过渡，使用will-change提示浏览器优化，优先使用transform | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 媒体查询断点选择不当导致响应式失效 | 不了解常见设备断点范围 | 使用移动优先策略，从最小屏幕开始设计，逐步增加断点 | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 选择器权重计算错误导致样式覆盖混乱 | 不了解CSS选择器优先级计算规则 | 使用BEM命名规范降低选择器嵌套深度，避免滥用!important | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| vh/vw单位在移动端出现滚动条导致布局异常 | 移动端浏览器的地址栏会影响vh计算 | 使用dvh（动态视口高度）或使用百分比布局替代vh | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
| 动画结束后状态回弹 | 未设置animation-fill-mode | 设置animation-fill-mode: forwards保持动画结束状态 | [CSS进阶与性能导览](./03-CSS进阶与性能-导览.md) |
