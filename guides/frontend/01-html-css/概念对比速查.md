# HTML与CSS - 概念对比速查

---

### div vs span

| 对比维度 | div | span |
|---------|-----|------|
| 核心定位 | 块级容器元素，用于布局和分组 | 行内容器元素，用于文本片段包裹 |
| 默认显示 | block（独占一行） | inline（与其他行内元素同行） |
| 适用场景 | 页面布局、区块划分、结构容器 | 文本高亮、图标包裹、行内样式修饰 |
| 宽高设置 | 可直接设置width/height | 不可直接设置宽高，需转为inline-block或block |
| 语义化替代 | header、nav、main、section、article、footer | em、strong、mark、code、abbr |
| 选择建议 | 用于需要块级容器的布局场景，优先使用语义化标签替代 | 用于行内文本包裹，无对应语义化标签时使用 |

---

### inline vs block vs inline-block

| 对比维度 | inline | block | inline-block |
|---------|--------|-------|-------------|
| 核心定位 | 行内元素，不换行 | 块级元素，独占一行 | 行内块元素，兼具两者特性 |
| 宽度 | 由内容决定，不可设置 | 默认占满父容器，可设置 | 由内容决定，可设置 |
| 高度 | 由内容决定，不可设置 | 由内容决定，可设置 | 由内容决定，可设置 |
| margin/padding | 水平方向有效，垂直方向仅影响自身不影响布局 | 四个方向均有效 | 四个方向均有效 |
| 与其他元素关系 | 与其他行内元素共享一行 | 独占一行，前后换行 | 与其他inline-block元素共享一行 |
| 典型元素 | span、a、em、strong、img | div、p、h1-h6、section | 通过CSS设置的display值 |
| 选择建议 | 用于文本级别的标记和修饰 | 用于页面结构性布局 | 用于需要设置宽高但保持行内排列的组件 |

### 盒模型 content-box vs border-box

| 对比维度 | content-box（标准盒模型） | border-box（IE盒模型） |
|---------|--------------------------|------------------------|
| 核心定位 | W3C标准盒模型，width仅包含内容区域 | 更直观的盒模型，width包含内容+padding+border |
| width计算 | width = content宽度 | width = content宽度 + padding + border |
| 实际占用宽度 | width + padding + border + margin | width + margin |
| 适用场景 | 传统标准场景 | 现代布局推荐模式 |
| 优点 | 语义清晰，内容区域独立 | 布局计算直观，设置width后无需额外计算 |
| 缺点 | 设置width后需要额外计算padding和border | 修改padding/border会影响内容区域大小 |
| 选择建议 | 在需要精确控制内容宽度的场景使用 | 全局使用，通过`*, *::before, *::after { box-sizing: border-box; }`统一设置 |

### flex vs grid

| 对比维度 | Flexbox | Grid |
|---------|---------|------|
| 核心定位 | 一维布局方案，沿主轴或交叉轴排列 | 二维布局方案，同时控制行和列 |
| 布局方向 | 单方向（主轴+交叉轴） | 双方向（行+列） |
| 适用场景 | 导航栏、工具栏、卡片列表、居中、弹性伸缩 | 整页布局、仪表盘、图片画廊、表单布局 |
| 对齐控制 | justify-content、align-items、align-self | justify-items、align-items、justify-content、align-content |
| 响应式能力 | flex-wrap换行、flex-basis基础尺寸 | 显式定义列宽、auto-fill/auto-fit、minmax() |
| 嵌套能力 | 支持嵌套，子元素可再作为flex容器 | 支持嵌套，子网格(subgrid)更灵活 |
| 选择建议 | 组件级别的排列和居中场景优先使用 | 页面级别的整体布局优先使用 |
