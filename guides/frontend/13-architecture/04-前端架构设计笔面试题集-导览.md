# 04-前端架构设计笔面试题集 - 导览

---

## 选择题部分（20 题）

| 维度 | 内容 |
|---|---|
| 是什么 | 20 道选择题覆盖微前端（3 题：JS 沙箱 / Module Federation / wujie）、设计系统（3 题：DTCG 令牌 / Headless UI / @layer）、架构管理（4 题：分层职责 / ADR / 技术债 / DIP）、补充的微前端与渲染架构（2 题：CSS 隔离 / Island 与 Partial Hydration）、BFF 与权限架构（5 题：Gateway 边界 / 聚合降级 / RBAC-ABAC-ReBAC / 权限四层 / IDOR 防护）、国际化与多端同构（3 题：ICU 复数 / SSR 注水 / RTL 逻辑属性），每题附逐项解析 |
| 能做什么 | 快速检验对前端架构核心概念的掌握程度；模拟面试中的选择题环节；识别常见认知误区（如"前端权限是安全边界""拼接字符串可以替代 i18n 模板"） |
| 怎么用 | 先独立完成所有题目，再对照解析检查答案，标记错题重点复习对应原理章节 |
| 原理和工作流程 | 每道题考查一个核心知识点，解析中说明正确选项的原因和错误选项的误区，并标注难度（★/★★/★★★） |
| 缺点 | 选择题只能覆盖知识点，无法考察实际编码和架构设计能力 |

## 简答题部分（15 题）

| 维度 | 内容 |
|---|---|
| 是什么 | 15 道简答题覆盖微前端价值与迁移策略、方案隔离机制对比、Design Tokens 三层架构、Headless UI 对比、依赖倒置、技术债管理、技术选型平衡，以及新增的 BFF 与 Gateway 边界、BFF 粒度与反模式、RBAC/ABAC/ReBAC 选型、前端四级权限与不可信原则、动态路由实现、多租户隔离、i18n 架构与 ICU MessageFormat |
| 能做什么 | 模拟面试中的简答环节；提供标准化的答题要点和思路；补齐 05/06 新章节的知识缺口 |
| 怎么用 | 先尝试口头回答，再对照答案要点补充遗漏，反复练习直到流畅表达 |
| 原理和工作流程 | 每道题从"是什么"、"为什么"、"怎么做"三个维度组织答案，辅以对比表格与代码示例 |
| 缺点 | 简答题答案仅供参考，实际面试中需要结合项目经验展开 |

## 场景设计题部分（8 题）

| 维度 | 内容 |
|---|---|
| 是什么 | 8 道场景设计题：微前端架构设计、设计系统规划、技术选型评估、分层架构重构、技术债管理方案，以及新增的中后台权限体系设计（RBAC + 四级权限 + 越权防护 + 多租户）、BFF 架构设计（粒度 + 聚合降级 + 缓存分层）、国际化与多端同构架构设计（i18n + RTL + 同构分层 + SSR 注水） |
| 能做什么 | 模拟面试中的场景设计/系统设计环节；培养架构思维和方案设计能力；提供可复用的架构方案模板 |
| 怎么用 | 先独立设计方案（画出架构图、列出关键决策），再对照答案要点补充和优化 |
| 原理和工作流程 | 每道题从需求分析 → 方案选择 → 架构设计 → 关键决策 → 实施策略逐步展开 |
| 缺点 | 场景设计题的答案具有开放性，实际项目中需要结合更多约束条件 |
