# 综合场景一：大型电商平台从单体前端到微前端架构的演进

> 场景：大型电商平台从单体前端到微前端架构的演进
> 涉及知识点：微前端架构、设计系统、分层架构、技术选型
> 前置知识：01-03 全部内容

---

## 一、场景背景

**项目概况**：
- 某中型电商平台（年 GMV 50 亿），当前使用 Vue 2 单体应用
- 前端团队 30 人，分为 4 个业务小组（商品、订单、用户、营销）
- 当前痛点：构建时间 15 分钟、每次发布需全量回归、多小组并行开发 Git 冲突严重
- 技术升级目标：Vue 3 迁移、构建速度优化、支持多团队独立发布

**痛点分析**：

| 痛点 | 具体表现 | 根本原因 |
|---|---|---|
| 构建缓慢 | 开发环境 HMR 5 秒+，生产构建 15 分钟 | 单体应用代码量 50 万行+，Webpack 4 未优化 |
| 发布耦合 | 一个小组的 Bug 阻塞全量发布 | 所有模块在一个仓库，共用一条 CI/CD 流水线 |
| 协作冲突 | 每天 5+ 次 Git 冲突，解决耗时 | 多小组同时修改同一仓库，代码耦合度高 |
| 技术债堆积 | 无法升级 Vue 3，因为改动范围太大 | 技术栈锁定在 Vue 2，升级需要全量迁移 |

### 微前端方案选型

| 方案 | 匹配度 | 分析 |
|---|---|---|
| **qiankun** | ★★★★★ | 存量 Vue 2 项目需要改造；多技术栈（Vue 2 → Vue 3）；中文社区成熟；团队已有 qiankun 经验 |
| Module Federation | ★★★☆☆ | 需要统一技术栈（Vue），但迁移过程中存在 Vue 2 和 Vue 3 混用期 |
| wujie | ★★★★☆ | 零改造优势明显，但 iframe 内存开销较大，部分 UI 组件（弹窗）可能有问题 |

**最终决策：qiankun**（原因：多技术栈共存、团队熟悉、社区成熟）

### 4.2 全局状态共享

```typescript
// main-app/src/shared-store/index.ts
import { initGlobalState } from 'qiankun';
import { reactive } from 'vue';

// ========================
// 全局状态定义
// ========================
interface GlobalState {
  user: {
    id: string;
    name: string;
    token: string;
    permissions: string[];
  } | null;
  theme: 'light' | 'dark';
  cart: {
    count: number;
    totalPrice: number;
  };
  notification: {
    unreadCount: number;
  };
}

const initialState: GlobalState = {
  user: null,
  theme: 'light',
  cart: { count: 0, totalPrice: 0 },
  notification: { unreadCount: 0 },
};

// ========================
// 初始化全局状态
// ========================
const actions = initGlobalState(initialState);

// 主应用级状态（响应式）
const globalState = reactive<GlobalState>({ ...initialState });

// 监听全局状态变化
actions.onGlobalStateChange((state, prev) => {
  console.log('[主应用] 全局状态变化:', state, prev);
  Object.assign(globalState, state);
});

// ========================
// 状态操作方法
// ========================
export function setUser(user: GlobalState['user']) {
  const newState = { ...globalState, user };
  actions.setGlobalState(newState);
}

export function setTheme(theme: GlobalState['theme']) {
  const newState = { ...globalState, theme };
  actions.setGlobalState(newState);
  document.documentElement.setAttribute('data-theme', theme);
}

export function updateCart(cart: Partial<GlobalState['cart']>) {
  const newState = {
    ...globalState,
    cart: { ...globalState.cart, ...cart },
  };
  actions.setGlobalState(newState);
}

// 挂载到 window 供子应用访问
window.__sharedStore = { globalState, setUser, setTheme, updateCart };

export { globalState, actions };
```

### 4.5 应用间通信 - 跨子应用购物车同步

```typescript
// packages/shared-events/src/eventBus.ts
// 独立的事件总线，主子应用共享

type EventHandler = (data: any) => void;

class EventBus {
  private events: Map<string, Set<EventHandler>> = new Map();

  on(event: string, handler: EventHandler): () => void {
    if (!this.events.has(event)) {
      this.events.set(event, new Set());
    }
    this.events.get(event)!.add(handler);

    // 返回取消订阅函数
    return () => {
      this.events.get(event)?.delete(handler);
    };
  }

  emit(event: string, data?: any): void {
    this.events.get(event)?.forEach((handler) => {
      try {
        handler(data);
      } catch (error) {
        console.error(`[EventBus] 事件 ${event} 处理异常:`, error);
      }
    });
  }

  off(event: string, handler?: EventHandler): void {
    if (handler) {
      this.events.get(event)?.delete(handler);
    } else {
      this.events.delete(event);
    }
  }

  // 清除所有事件（用于子应用卸载时清理）
  clear(): void {
    this.events.clear();
  }
}

// 单例挂载到 window
const eventBus = new EventBus();

// 在 qiankun 环境中挂载到 window
if (typeof window !== 'undefined') {
  window.__eventBus = eventBus;
}

export { eventBus, EventBus };


// ========================
// 使用示例：购物车跨子应用同步
// ========================

// 商品管理子应用：添加商品到购物车
window.__eventBus?.emit('cart:add-item', {
  productId: 'P001',
  name: 'iPhone 15',
  price: 6999,
  quantity: 1,
});

// 主应用：监听购物车变化，更新导航栏角标
window.__eventBus?.on('cart:add-item', (item) => {
  // 更新全局购物车状态
  updateCart({
    count: globalState.cart.count + 1,
    totalPrice: globalState.cart.totalPrice + item.price * item.quantity,
  });
  // 触发导航栏角标更新
  window.__eventBus?.emit('nav:cart-badge', { count: globalState.cart.count });
});

// 订单管理子应用：监听购物车变化
window.__eventBus?.on('cart:add-item', (item) => {
  console.log('[订单子应用] 购物车新增商品:', item);
  // 刷新订单列表（如果有相关联的推荐）
  refreshOrderRecommendations();
```

# 综合场景二：设计系统从零搭建实战

---

## 一、场景背景

**项目概况**：
- 某零售科技公司拥有 3 个产品线：管理后台（SaaS）、商家端（B 端 Portal）、C 端商城（H5 + 小程序）
- 当前各产品线 UI 风格不一致，品牌色五花八门，按钮/表单/表格等基础组件各有各的实现
- 设计团队 5 人，前端团队 20 人，分布在 3 个产品小组
- 核心痛点：设计稿还原度低（60%）、组件重复造轮子（3 套按钮组件）、品牌升级时需改动 3 个仓库

**痛点分析**：

| 痛点 | 具体表现 | 根本原因 |
|---|---|---|
| 视觉不一致 | 品牌色有 4 种不同的蓝，圆角有的 4px 有的 8px | 无统一 Design Tokens，设计师和开发各自定义 |
| 重复开发 | 3 个产品线各有一套按钮/表格/弹窗组件 | 无跨产品线组件库，团队各自维护 |
| 主题切换困难 | 暗黑模式需要逐个产品线实现，累计 120h+ | 样式硬编码，缺乏主题变量体系 |
| 设计还原度低 | 设计稿 vs 实际页面差距大，返工率 30% | 设计与开发使用不同的设计语言，缺少文档对齐 |

```typescript
import React, { useState, useMemo } from 'react';
import { Table } from '../../base/Table';

export interface DataTableColumn<T> {
  key: keyof T;
  title: string;
  dataIndex: keyof T;
  width?: number;
  sortable?: boolean;
  render?: (value: T[keyof T], record: T, index: number) => React.ReactNode;
}

export interface DataTableProps<T extends Record<string, unknown>> {
  columns: DataTableColumn<T>[];
  dataSource: T[];
  loading?: boolean;
  pagination?: {
    current: number;
    pageSize: number;
    total: number;
    onChange: (page: number, pageSize: number) => void;
  };
  rowKey?: keyof T | ((record: T) => string);
  onRowClick?: (record: T) => void;
  emptyText?: string;
}

export function DataTable<T extends Record<string, unknown>>({
  columns,
  dataSource,
  loading,
  pagination,
  rowKey = 'id' as keyof T,
  onRowClick,
  emptyText = '暂无数据',
}: DataTableProps<T>) {
  const [sortField, setSortField] = useState<keyof T | null>(null);
  const [sortOrder, setSortOrder] = useState<'asc' | 'desc'>('asc');

  const sortedData = useMemo(() => {
    if (!sortField) return dataSource;
    return [...dataSource].sort((a, b) => {
      const aVal = a[sortField];
      const bVal = b[sortField];
      if (aVal < bVal) return sortOrder === 'asc' ? -1 : 1;
      if (aVal > bVal) return sortOrder === 'asc' ? 1 : -1;
      return 0;
    });
  }, [dataSource, sortField, sortOrder]);

  const handleSort = (field: keyof T) => {
    if (sortField === field) {
      setSortOrder(sortOrder === 'asc' ? 'desc' : 'asc');
    } else {
      setSortField(field);
      setSortOrder('asc');
    }
  };

  return (
    <div className="data-table-wrapper">
      <Table loading={loading} emptyText={emptyText}>
        <Table.Header>
          {columns.map((col) => (
            <Table.Cell
              key={String(col.key)}
              width={col.width}
              sortable={col.sortable}
              sortOrder={sortField === col.key ? sortOrder : undefined}
              onSort={() => col.sortable && handleSort(col.key)}
            >
              {col.title}
            </Table.Cell>
          ))}
        </Table.Header>

        <Table.Body>
          {sortedData.map((record, index) => (
            <Table.Row
              key={typeof rowKey === 'function' ? rowKey(record) : String(record[rowKey])}
              onClick={() => onRowClick?.(record)}
              clickable={!!onRowClick}
            >
              {columns.map((col) => (
                <Table.Cell key={String(col.key)}>
                  {col.render
                    ? col.render(record[col.dataIndex], record, index)
                    : String(record[col.dataIndex] ?? '')}
                </Table.Cell>
              ))}
            </Table.Row>
          ))}
        </Table.Body>
      </Table>

      {pagination && (
        <div className="pagination">
          <span>共 {pagination.total} 条</span>
          <button
            disabled={pagination.current <= 1}
            onClick={() => pagination.onChange(pagination.current - 1, pagination.pageSize)}
          >
            上一页
          </button>
          <span>{pagination.current} / {Math.ceil(pagination.total / pagination.pageSize)}</span>
          <button

            onClick={() => pagination.onChange(pagination.current + 1, pagination.pageSize)}
          >
            下一页
          </button>
        </div>
      )}
    </div>
  );
}
```

### 4.4 主题切换实现

```typescript
// ========================
// 主题定义
// packages/shared-components/src/theme/types.ts
// ========================

export type ThemeMode = 'light' | 'dark';

export interface ThemeConfig {
  mode: ThemeMode;
  // 支持自定义覆盖，例如某个客户需要自己的品牌色
  customTokens?: Record<string, string>;
}

// ========================
// 主题上下文
// packages/shared-components/src/theme/ThemeProvider.tsx
// ========================

import React, { createContext, useContext, useEffect, useState, useCallback } from 'react';
import type { ThemeMode, ThemeConfig } from './types';

interface ThemeContextValue {
  mode: ThemeMode;
  toggleTheme: () => void;
  setTheme: (mode: ThemeMode) => void;
  setCustomTokens: (tokens: Record<string, string>) => void;
}

const ThemeContext = createContext<ThemeContextValue | null>(null);

export function ThemeProvider({
  children,
  defaultMode = 'light',
  storageKey = 'app-theme',
  customTokens,
}: {
  children: React.ReactNode;
  defaultMode?: ThemeMode;
  storageKey?: string;
  customTokens?: Record<string, string>;
}) {
  const [mode, setMode] = useState<ThemeMode>(() => {
    // 从 localStorage 读取持久化的主题
    if (typeof window !== 'undefined') {
      const stored = localStorage.getItem(storageKey);
      if (stored === 'light' || stored === 'dark') return stored;
    }
    return defaultMode;
  });

  // 应用主题到 DOM
  const applyTheme = useCallback((themeMode: ThemeMode) => {
    const root = document.documentElement;
    root.setAttribute('data-theme', themeMode);
    // 同时设置 class 以便 Tailwind 暗黑模式
    if (themeMode === 'dark') {
      root.classList.add('dark');
    } else {
      root.classList.remove('dark');
    }
  }, []);

  const toggleTheme = useCallback(() => {
    setMode((prev) => {
      const next = prev === 'light' ? 'dark' : 'light';
      localStorage.setItem(storageKey, next);
      applyTheme(next);
      return next;
    });
  }, [storageKey, applyTheme]);

  const setTheme = useCallback((newMode: ThemeMode) => {
    setMode(newMode);
    localStorage.setItem(storageKey, newMode);
    applyTheme(newMode);
  }, [storageKey, applyTheme]);

  const setCustomTokens = useCallback((tokens: Record<string, string>) => {
    const root = document.documentElement;
    Object.entries(tokens).forEach(([key, value]) => {
      root.style.setProperty(`--${key}`, value);
    });
  }, []);

  // 初始化时应用主题
  useEffect(() => {
    applyTheme(mode);
  }, []); // 仅在挂载时执行

  // 应用自定义 Token
  useEffect(() => {
    if (customTokens) {
      setCustomTokens(customTokens);
    }
  }, [customTokens, setCustomTokens]);

  return (
    <ThemeContext.Provider value={{ mode, toggleTheme, setTheme, setCustomTokens }}>
      {children}
    </ThemeContext.Provider>
  );
}

export function useTheme() {
  const context = useContext(ThemeContext);
  if (!context) {
    throw new Error('useTheme 必须在 ThemeProvider 内部使用');
  }
  return context;
}
```

### 4.6 Figma 插件 —— Design Tokens 同步

```typescript
// ========================
// Figma 插件：读取 tokens.json 同步到 Figma Variables
// packages/figma-plugin/src/main.ts
// ========================

// 插件工作流程：
// 1. 前端开发更新 design-tokens 后，运行 pnpm build:tokens 生成 tokens.json
// 2. 设计师在 Figma 中运行插件，选择 tokens.json 文件
// 3. 插件自动将 tokens.json 中的值同步到 Figma Variables
// 4. 设计师在 Figma 中使用的颜色、间距、字号与代码完全一致

// 关键代码：
figma.ui.onmessage = async (msg: { type: string; tokens: Record<string, any> }) => {
  if (msg.type === 'sync-tokens') {
    const tokens = msg.tokens;
    const collection = figma.variables.getLocalVariableCollections()[0];

    for (const [key, value] of Object.entries(tokens)) {
      const variable = figma.variables.getVariableById(key);
      if (variable) {
        // 更新已有的 Variable
        variable.setValueForMode(collection.modes[0].modeId, value);
      } else {
        // 创建新的 Variable
        const newVar = figma.variables.createVariable(
          key,
          collection,
          'COLOR' // 或 'FLOAT'（间距/字号）
        );
        newVar.setValueForMode(collection.modes[0].modeId, value);
      }
    }

    figma.notify('Design Tokens 同步完成！');
    figma.closePlugin();
  }
};
```
