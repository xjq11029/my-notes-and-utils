## 快速开始

### 3 步开始使用 AI 编程助手

1. **准备环境**：打开您的项目，确保 AI 可以访问代码库
2. **清晰描述**：明确告诉 AI 您需要做什么
3. **验证迭代**：检查生成的代码，根据需要调整

---

## 准备工作

### 1. 了解项目概况

在开始之前，建议先让 AI 了解您的项目：

```
帮我分析一下这个项目的结构和技术栈。
```

### 2. 提供项目信息

让 AI 知道以下信息（如果适用）：

- **技术栈**：框架、语言、库
- **代码规范**：ESLint、Prettier 等配置
- **包管理器**：npm、yarn、pnpm、pip、cargo 等
- **测试框架**：Jest、Mocha、pytest、unittest 等
- **构建工具**：Webpack、Vite、Make、CMake 等

## 如何提问

### 1. 提供充分的上下文

**❌ 不好的例子：**
```
帮我写个函数
```

**✅ 好的例子：**
```
在 src/utils/ 目录下创建一个工具函数，用于格式化日期，接受 Date 对象和格式字符串作为参数，返回格式化后的字符串。项目使用 TypeScript，请添加类型定义。
```

### 2. 明确目标和约束

告诉 AI：
- 你要做什么（目标）
- 有什么限制条件
- 偏好的技术方案

**示例：**
```
帮我实现一个用户登录功能，要求：
1. 使用 JWT 进行身份验证
2. 密码需要 bcrypt 加密
3. 包含登录、注册、登出三个接口
4. 使用 Express.js 框架
5. 数据库使用 MongoDB
```

### 3. 分步骤解决复杂问题

对于大型任务，可以分解为多个小步骤：

1. **分析阶段**：让 AI 分析现有代码
2. **设计阶段**：让 AI 提供实现方案
3. **实现阶段**：分步编写代码
4. **测试阶段**：生成测试用例

## 最佳实践

### 1. 代码审查与优化

让 AI 帮您审查代码质量：

```
帮我审查一下 [文件路径]，看看有哪些可以优化的地方，特别是：
- 代码可读性
- 性能优化
- 错误处理
- 安全隐患
```

### 2. 理解现有代码

当您不理解某段代码时：

```
帮我解释一下 [文件路径] 这个文件的功能和实现逻辑。
```

### 3. 生成测试代码

```
为 [文件路径] 文件中的函数生成单元测试，使用 [测试框架]。
```

### 4. 重构建议

```
我觉得 [文件路径] 这个文件有点复杂，帮我看看如何重构它，让代码更清晰、更易维护。
```

### 5. Bug 排查

```
我遇到了一个问题：[描述问题]
错误信息：[粘贴错误信息]
帮我分析一下可能的原因，并提供调试建议。
```

### 6. 文档生成

```
为 [文件路径/函数/类] 生成详细的文档注释，包含：
- 功能描述
- 参数说明
- 返回值说明
- 使用示例
```

## 注意事项

### 1. 验证 AI 生成的代码

- AI 生成的代码可能存在错误或不适合您的项目
- 始终检查和测试生成的代码
- 确保代码符合项目的代码风格和规范

### 2. 保护敏感信息

- 不要在对话中分享 API 密钥、密码等敏感信息
- 如果需要展示配置文件，可以先脱敏处理

### 3. 了解项目限制

每个项目都有特定的配置和约定，让 AI 知道：
- 使用的包管理器
- 代码规范工具
- 提交信息规范
- 类型检查要求

### 4. 逐步迭代

不要期望一次就能得到完美的解决方案，可以：
1. 先生成一个基础版本
2. 测试并发现问题
3. 根据反馈进行改进
4. 重复上述步骤直到满意

### 5. 保持对话简洁

- 一次只问一个主要问题
- 如果需要问多个问题，分开发送
- 提供相关的代码片段，而不是整个文件

## 常见问题

### Q1: AI 生成的代码有错误怎么办？

**A:** 
1. 仔细检查错误信息
2. 告诉 AI 具体的错误
3. 让 AI 修复问题

**示例：**
```
这段代码有错误，错误信息是：[错误信息]
请帮我修复它。
```

### Q2: 如何让 AI 遵循项目的代码风格？

**A:** 
1. 让 AI 先查看项目的现有代码
2. 提供代码规范配置文件（如 .eslintrc、.prettierrc）
3. 指定参考文件

**示例：**
```
请参考 [参考文件路径] 的代码风格，帮我编写 [功能]。
```

### Q3: AI 不理解我的需求怎么办？

**A:**
1. 重新组织语言，更清晰地描述
2. 提供更多上下文
3. 分解成更小的问题
4. 使用示例来说明

### Q4: 如何处理大型代码库？

**A:**
1. 让 AI 先分析项目结构
2. 聚焦于特定的文件或模块
3. 分步骤进行修改
4. 提供相关文件的路径

### Q5: AI 生成的代码太复杂怎么办？

**A:**
```
这个实现太复杂了，请帮我简化一下，保持功能不变但代码更简洁易懂。
```

## 总结

AI 编程助手是一个强大的工具，但关键在于如何有效地使用它。记住：

1. **清晰表达**：明确告诉 AI 您的需求
2. **提供上下文**：让 AI 了解项目背景
3. **逐步迭代**：不要期望一蹴而就
4. **验证结果**：始终检查和测试生成的代码
5. **持续学习**：从 AI 的代码中学习新的技巧和模式

希望这份指南能帮助您更好地利用 AI 编程助手，提升开发效率！
