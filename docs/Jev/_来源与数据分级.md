## 一、分级定义

| 标签 | 含义 | 可信度处理 |
|---|---|---|
| 【官方】 | `docs.typesafe.ai` 官方文档、官方发布页、官方 playground | 视为该时点的权威口径；但**商业宣传数字**（倍数、成本）需与【三方】并列呈现 |
| 【一手】 | 论文、源码、原始署名页等**非 TypeSafe** 的一手材料（如 arXiv 署名） | 用于核实身份 / 归属类事实；与【官方】冲突时并列呈现 |
| 【三方】 | 独立媒体、第三方评测机构、一线开发者的公开反馈 | 与【官方】冲突时**两者都写出来**，不取平均、不择一 |
| 【社区】 | 开源复刻项目、论坛讨论、个人博客的推断 | 仅作为「存在这种说法 / 存在这个项目」登记，**不作为事实断言** |
| ⚠️ 疑似非官方 | 域名不在 `typesafe.ai` 下、但自称官方或官方风格的站点 | **不作为依据**；若其数字与【官方】冲突，以【官方】为准，并在正文中标注分歧 |

## 四、⚠️ 疑似非官方站点（仅登记，不作依据）

以下域名**不在 `typesafe.ai` 下**，但站点标题/自述使用「Jev by TypeSafe AI」一类措辞。其内容可与官方口径互相印证的部分已并入【三方】，**冲突的部分不采纳**：

| 站点 | 冲突点 |
|---|---|
| https://jevtypesafeai.com/ | 称定价「每百万输入 token $0.25–$0.42」——与官方文档的 **$0.042/Mtok 相差一个数量级**；正文一律采用官方口径 |
| https://jevmodel.org/ | 自称官方风格，未在官方文档中被引用 |
| https://www.typesafeai.org/guides/jev-pricing | 转述「$0.042 per million input tokens」，与官方一致，但域名非官方 |
| https://fluxbbs.com/ 、 https://jev.kuhung.me/ | 论坛/个人博客，仅作【社区】参考 |

> 结论：**凡涉及定价、限流、上下文长度、API 字段，一律以 `docs.typesafe.ai` 为准**；涉及倍数、成本节省这类商业宣传数字，一律同时给出【官方】与【三方】两套口径。
