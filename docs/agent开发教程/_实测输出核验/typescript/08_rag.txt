============================================================
① 文档加载器：所有 Loader 都只做一件事——文件 → Document
============================================================
  [TextLoader]  notes.txt → 1 个 Document
      page_content = "RAG 的第一条铁律：检索质量决定生成质量。 / 如果检索回来的片段本身不相关，再..."
      metadata     = {"source":"notes.txt"}
      → 整个文件是一整条 page_content：Loader 不做任何切分。

  [CSVLoader]   orders.csv → 2 个 Document（每行一条）
      "order_id: A-1001 / product: 机械键盘 / status..."
      → 列名被拼进了 page_content，行号落在 metadata 里。

  [JSONLoader]  faq.json → 2 个 Document（JSON Pointer）
      "检索增强生成，提问前先把相关资料塞进上下文。"
      "为了控制单次进上下文的文本长度，并提高检索命中率。"
      → 指针决定「取哪几条」「哪部分是正文」。

② 文档切分器：为什么切、怎么切
============================================================
CharacterTextSplitter        → 3 块
  [1] "LangChain 是一个用于构建大模型应用的框架。"
  [2] "它提供模型、工具、检索三块能力。\n其中检索能力用于把外部知识接进模型。"
  [3] "向量数据库负责存储这些知识的向量表示。"

RecursiveCharacterTextSplitter → 3 块
  [1] "LangChain 是一个用于构建大模型应用的框架。"
  [2] "它提供模型、工具、检索三块能力。\n其中检索能力用于把外部知识接进模型。"
  [3] "向量数据库负责存储这些知识的向量表示。"

  → CharacterTextSplitter 只认一个分隔符，超长段落会硬切；
    RecursiveCharacterTextSplitter 按「段落 → 句子 → 词」逐级回退，
    尽量在自然边界断开，所以它是默认选择。

③ 嵌入 + 向量库：写入与检索
============================================================
  ③-0 手写二维玩具（人工坐标系：第 1 维=动物性，第 2 维=机械性）
      「猫在晒太阳」 → (0.90, 0.10)
      「狗在打盹」 → (0.85, 0.15)
      「汽车在高速公路上飞驰」 → (0.05, 0.95)
      查询「小狗在睡觉」 → (0.80, 0.20)
      距离「小狗在睡觉」 0.07 ← 狗在打盹
      距离「小狗在睡觉」 0.14 ← 猫在晒太阳
      距离「小狗在睡觉」 1.06 ← 汽车在高速公路上飞驰
     → 狗最近、汽车最远：语义相近 = 距离近。真实嵌入模型 = 自动学出来的高维坐标系。
embedQuery('退换货') → 维度 4，前 4 位 [0.1,0.2,0.3,0.4]
  → 真实嵌入模型的向量有语义（近义词距离近）；FakeEmbeddings 是随机但确定的，
    所以下面检索到的内容不代表相关，只说明链路通了。

similaritySearch('退换货怎么处理', 2) → 2 条
  [1] faq.txt | 退换货政策：签收后 7 天内可无理由退换。
  [2] faq.txt | 运费规则：单笔订单满 99 元免运费。

④ 检索器包成工具，交给 agent
============================================================
工具名 = search_docs
直接调用 = "退换货政策：签收后 7 天内可无理由退换。\n运费规则：单笔订单满 99 元免运费"...

agent 的消息轨迹：
  1. [HumanMessage] "退换货怎么规定的？"
  2. [AIMessage] ""  tool_calls=[["search_docs",{"query":"退换货"}]]
  3. [ToolMessage] "退换货政策：签收后 7 天内可无理由退换。\n运费规则：单笔订单满 99 元免运费。"
  4. [AIMessage] "商品签收后 7 天内可无理由退换。"

  → 检索器只是普通工具的一种；agent 自己决定什么时候去查。
    真实 RAG 的上限由检索质量决定——检索不到，模型再好也答不出。
