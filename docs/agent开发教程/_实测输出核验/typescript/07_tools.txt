① 工具的 schema 从哪来
========================================================================
  工具名: search_orders
  工具描述: "按关键词搜索订单。"
  → 模型看到的就只有 名称 / 描述 / 参数 schema 三样东西；
    description 写得含糊，模型就会选错工具。

  ⚠️ 与 Python 的差异：Python 用 @tool 装饰器 + 类型注解 + docstring；
     JS 用 tool(fn, { name, description, schema }) —— schema 是必填的。

④ 工具出错怎么办：wrapToolCall 把异常变成 ToolMessage
========================================================================
  [中间件] 捕获到异常：Error，转成 ToolMessage
  1. [HumanMessage] "1 除以 0"
  2. [AIMessage] ""  tool_calls=[["divide",{"a":1,"b":0}]]
  3. [ToolMessage] "工具执行失败：division by zero。请换一个参数再试。"
  4. [AIMessage] "除数不能为 0，我换个数再算。"

  ⚠️ 注意：v1 已经**不再**使用 ToolException / handleToolError 这套旧 API。
     要么像上面这样自己写 wrapToolCall，要么用内置的 toolErrorMiddleware。
