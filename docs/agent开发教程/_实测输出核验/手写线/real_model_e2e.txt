③ 真实 token 计费：手写模型层到底有没有把 usage 带出来
==============================================================================

---- 模型 glm-4-plus ----
  非流式 raw.usage          = {'completion_tokens': 2, 'prompt_tokens': 18, 'total_tokens': 20, 'completion_tokens_details': None, 'prompt_tokens_details': None}
  非流式 message['usage']   = None   message 里有 usage 键? False
  流式   raw（装配器不设）  = None
  → 结论：InvokeResult.raw 在流式路径被显式置为 None（model.py:82），而 _normalize_message 与 _StreamAssembler 都**不读 usage 字段**。
    也就是说：手写线当前**拿不到 token 账**，要计费和缓存命中率必须自己补一处。
