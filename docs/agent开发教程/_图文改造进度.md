cd /d/ProjectCode/my-notes-and-utils

import re, os

    s = open(f"docs/agent开发教程/{name}", encoding="utf-8").read()

import subprocess, sys, hashlib

subprocess.run([sys.executable, "docs/agent开发教程/_build_html.py"], check=True, capture_output=True)

## 七、口味判据（用户三次反馈的沉淀，比"写得好一点"可执行）

| 用户原话 | 可执行的判据 |
|---|---|
| "缺少对应的图标" | 图要**承担解释**，不是装饰：每张图必须画出"谁在什么时候动了什么"或"两条路的差别"。贴图就走的段落不合格 |
| "例子也不多" | 每个抽象概念后跟一个具象场景，格式固定两行；**不许全堆在第三节** |
| "不够简单直白" | 一句一个意思，超 35 字就拆；术语首现给白话；先结论后论证 |
| "内容不够丰富" | 宁可加图、加例子、加"为什么不是别的方案"，不可用删细节换篇幅 |

**反例（改造前的典型句）**：
> 归错的直接后果是：如果它是 Chatbot，评价标准就变成"回答得像不像人"，注意力全在提示词上，忽略权限、评测、运营这些真正决定能否上线的部分。

> 当成聊天机器人 → 只看回答像不像人 → 整天调提示词，忽略权限、评测、运营。

## 八、容易踩的坑（本轮实际踩过的）

1. **图号必须与正文出现顺序一致**。有两次因为顺序和编号不符，做了整组文件重映射（要用 `TMP_` 临时名，否则互相覆盖）。
2. **`_build_html.py` 已改造**，支持 `章号-序号` 命名（`5-1_xxx`），内部编码 `501`。不要改回全局连续编号，否则锚点会撞。
3. **SVG 与 PNG 必须成对**，构建脚本找不到同名 SVG 会直接 `SystemExit`。
4. **中文路径下 `cv2.imread` 会失败**，读图要用 `np.fromfile + cv2.imdecode`。
5. **`×` 之类的符号要放在列间隙**，列宽不足会压在边框上（a02 返工过一次）。
6. **子代理并行时不要让它们碰 README 和构建脚本**，否则互相覆盖。
