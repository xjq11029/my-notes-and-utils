### 手写线逐章大纲（要点）

- **S1 契约**：请求/响应/流式三种形态；`finish_reason` 两值；思考字段厂商差异（`reasoning_content`/`reasoning` 双兼容）；client 可注入（duck-typing）

- **S3 会话**：失忆对照实验；历史重传实测（1→3 条）；两条纪律（只追加/保思维链）
- **S4 tools 裸流程**：手动 Schema 逐字段；厂商把 tools 渲染成 TS 签名塞进 system prompt 末尾（A1）；globals().get 原始做法的四个问题；tool 消息回填格式
- **S5 封装**：inspect + create_model 动态参数模型；异常→堆栈文本回喂；registry 与 None 终止信号
- **S6 ReAct**：三通道九事件 + COMPLETE；实测事件序列；流式 arguments 分片拼接；三轮轨迹
- **S7 Agent**：五层编排 + 事件总线（A1 第 21 章同构）；max_turns 安全阀实测；监听器异常会沿 emit 传播（教学实现未隔离）

- **S9 子代理**：上下文防火墙；主上下文 5 条 vs 子代理 7 条实测；串行 vs 并发；与框架线 ch16 isolated/fork 对照
