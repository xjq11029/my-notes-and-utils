## 一、P0：必须修正（概念错误 / 逻辑错误）

### P0-1　ch10：把 CNN 归类为"全连接神经网络"

**位置**：`ch10_training_mode.md` 第 66 行

```markdown
| **全连接神经网络（CNN 早期等）** | 现在已很少用；早期主要处理图片 |
```

**问题**：**CNN（Convolutional Neural Network，卷积神经网络）不是全连接网络**。CNN 的核心特征恰恰是"局部连接 + 权重共享"，是与全连接相对立的设计。此行还存在**跨章自相矛盾**——ch07 第 2.8 节的表格里，CNN 被正确归类为"局部连接 + 权重共享"，与本行冲突。

**建议改为**：

```markdown
| **全连接神经网络（FC / MLP，多层感知机）** | 结构最简单；早期用于处理小规模数据，现已很少单独作为主干 |
| **CNN（卷积神经网络）** | 局部连接 + 权重共享，图像领域的经典架构 |
```

### P0-2　ch10 + README："预测对了就不需要反向传播"

**位置**：`ch10_training_mode.md` 第 79 行、第 140 行；`README.md` 第 122 行

```markdown
- 训练框架同时包含前向传播与反向传播（预测不对才需要反向传播调整；**预测对了就不需要反向传播**）；
- **推理 = 只跑前向传播**（预测对了不需要反向传播）。
| Inference | 推理——只跑前向传播（预测对了不需要反向传播） | ch10 |
```

**问题**：这是**因果倒置的逻辑错误**。训练阶段**无论预测对错都必须跑反向传播**——反向传播是计算梯度的唯一途径，只要 loss 不为 0 就要继续更新参数；"预测对了"不产生任何"跳过反向传播"的效果。真正区分正误的界限是**训练 vs 推理**，而不是"预测对不对"。

此错误在 3 处复现（ch10 正文、ch10 要点回顾、README 术语表），会互相加固错误认知，风险较高。

**建议改为**：

```markdown
- 训练阶段每个 batch 都要跑「前向 → 反向 → 更新」，与预测对错无关；
- 推理阶段只跑前向传播，**不做任何参数更新**——这才是训练与推理的分界线。
| Inference | 推理——只跑前向传播、不更新参数（区别于训练阶段的「前向+反向」） | ch10 |
```
