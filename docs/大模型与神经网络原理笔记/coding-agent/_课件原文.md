```mermaid
sequenceDiagram
    participant User as 用户
    participant Agent as Agent
    participant MCP as MCP Server
    participant Model as 大模型
    Note over User,MCP: 启动MCP服务
    Note over Agent,MCP: 发现工具
    Agent->>MCP: 工具列表?

    Note over User,Model: 新会话
    Agent->>Model: 各种提示词 + MCP工具提示
    loop 对话循环
        User->>Agent: 用户消息
        Agent->>Model: 用户消息
        loop MCP调用循环
            Model->>Agent: 用户消息
            Agent->>MCP: 调用工具
            【补全】MCP-->>Agent: 调用结果
            【补全】Agent->>Model: 调用结果
        end
        【补全】Model->>Agent: 回复
        【补全】Agent->>User: 回复
    end
```

## 最佳实践

1. 每一个会话应该保持独立和连续
2. 提示词始终保持精简
3. 文档尽量的细粒度拆分
4. skill数量不宜超过12个
5. 独立、并行任务适合使用子代理完成
6. 奖罚分明，有利于形成长期记忆
